<p class="p1"><span data-style="line-height: 1.42857;">Fortiguard’s behavior-based system designed to identify new malware has detected a German targeted ransomware. We named it </span><i data-style="line-height: 1.42857;">Herbst,</i><span data-style="line-height: 1.42857;"> a German word which in English means Autumn. </span><br></p><h3>Ransom Note</h3><p class="p6">The Herbst ransom note appears in German in a dedicated window from its own running process. It demands that a ransom be paid in bitcoin. We have also been able to determine the bitcoin address. Ransome note details are listed below:</p><blockquote><p class="p6">File encryption: AES 256 bit</p><p class="p6">Ransom Price: 0.1 Bitcoin or approximately USD $53.80 as of today.</p><p class="p8"><span class="s1">Bitcoin </span>Address: 18uM9JA1dZgvsgAaeeW2XZK13dTbk1jzWq</p></blockquote><p class="p9" data-style="text-align: center; "><img src="/content/dam/fortinet-blog/new-images/uploads/cooking-up-autumn-herbst-ransomware-911.png" data-style="width: 332px;"><br></p><p class="p10" data-style="text-align: center; "><i>Figure 01: Ransom Note</i></p><h3>Key Preparation</h3><p class="p4">The key is prepared by concatenating two random numbers from 0 to 99999999. Next, it concatenates strings in random positions from the <i>text</i> variable, <i>text.length</i> times, as seen below. This key is hashed later and used as the AES key.</p><p class="p5" data-style="text-align: center; "><img src="/content/dam/fortinet-blog/new-images/uploads/cooking-up-autumn-herbst-ransomware-912.png" data-style="width: 1013px;"><br></p><p class="p10" data-style="text-align: center; "><i>Figure 02: Key Preparation Function</i></p><h3>Targeted Directories</h3><p class="p12">After preparing the key, Herbst proceeds to enumerate files from the StartupPath. It encrypts all kinds of files in this directory, as shown by <b>“*.*”</b>.</p><p class="p11">It encrypts file in the following special folders:</p><p class="p11">Desktop, MyPictures, MyMusic, and Personal</p><p class="p9" data-style="text-align: center; "><span data-style="font-style: italic;"><img src="/content/dam/fortinet-blog/new-images/uploads/cooking-up-autumn-herbst-ransomware-913.png" data-style="width: 584px;"><br></span></p><p class="p10" data-style="text-align: center; "><span data-style="font-style: italic;">Figure 03: File Enumeration</span></p><h3>Encrypted File</h3><p class="p4">The ransomware encrypts files and appends the extension to <i>.herbst</i>.</p><p class="p9" data-style="text-align: center; "><img src="/content/dam/fortinet-blog/new-images/uploads/cooking-up-autumn-herbst-ransomware-914.png" data-style="width: 588px;"><br></p><p class="p10" data-style="text-align: center; "><i>Figure 04: Encrypted File Sample</i></p><h3>File Encryption</h3><p class="p11">The encryption starts by reading the file and calling the function <i>AES_Encrypt.</i></p><p class="p5" data-style="text-align: center; "><img src="/content/dam/fortinet-blog/new-images/uploads/cooking-up-autumn-herbst-ransomware-915.png" data-style="width: 694px;"><br></p><p class="p10" data-style="text-align: center; "><i>Figure 05: Encryption Function</i></p><p class="p11">The malware then proceeds to hash the <i>key </i>generated from the previous function, and this is used as the AES key for encrypting the files. After the file is encrypted with AES 256 bit, the malware then converts it to Base64String. </p><p class="p9" data-style="text-align: center;"><img src="/content/dam/fortinet-blog/new-images/uploads/cooking-up-autumn-herbst-ransomware-916.png" data-style="width: 752px;"><br></p><p class="p10" data-style="text-align: center; "><i>Figure 06: AES Encryption Function</i></p><p class="p9" data-style="text-align: center;"><img src="/content/dam/fortinet-blog/new-images/uploads/cooking-up-autumn-herbst-ransomware-917.png" data-style="width: 615px;"><br></p><p class="p10" data-style="text-align: center; "><i>Figure 07: File Structure Before and After Encryption</i></p><h3>Unfinished Business</h3><p class="p11">This malware, written in C#, shows it’s unfinished because it has the following functions, but never calls them in the main function:</p><p class="p11"></p><ul><li><i data-style="line-height: 1.42857;">Encrypt</i><span data-style="line-height: 1.42857;"> – believed to be the function in encrypting the AES key used before sending to the Command and Control (C&C.)</span><br></li><li><i data-style="line-height: 1.42857;">Unlock</i><span data-style="line-height: 1.42857;"> – believed to be the decryption of the incoming traffic from the C&C.</span><br></li><li><i data-style="line-height: 1.42857;">Http</i><span data-style="line-height: 1.42857;"> – believed to be used to send and receive encrypted messages to the C&C.</span><br></li></ul><p></p><p class="p5" data-style="text-align: center; "><img src="/content/dam/fortinet-blog/new-images/uploads/cooking-up-autumn-herbst-ransomware-918.png" data-style="width: 306px;"><br></p><p class="p10" data-style="text-align: center; "><i>Figure 08: Malware Functions</i></p><p class="p11">Yes, the malware encrypts files and shows the decryption note; however ,it doesn’t send the AES key used to its C&C, and doesn’t verify the transaction ID when used in the ransom window, making this an unfinished ransomware.</p><h3>Conclusion</h3><p class="p11">Our analysis shows that cybercriminals could be cooking a ransomware targeting a German audience. From the analysis, we conclude that Herbst is a beta version which is still under development. The malware doesn’t provide any details on its C&Cs because it doesn’t call the HTTP function. We speculate that this version could just be a test to check AV vendors’ ability to detect it without giving away their C&C. </p><p class="p11">Fortiguard will continue to monitor Herbst future activities and developments.</p><p class="p11">File detection: W32/Herbst.A!tr</p><p class="p14"><span class="s2">SHA256: </span>18605f7a5a47ac16f722e3ec8a42121035bb95f731aaad5090c5e11104fc3185</p><p class="p5"><br></p><p>
