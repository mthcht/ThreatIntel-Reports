<div id="sblogs">

<p>Over the past few days, <a href="https://www.fortinet.com/fortiguard/threat-intelligence/threat-research.html">FortiGuard Labs</a> captured a number of JS (JavaScript) scripts. Based on my analysis, they were being used to spread the new GlobeImposter ransomware variants.&nbsp; I picked one of them and did a quick analysis. The version of the variant I reviewed is &ldquo;726&rdquo;.</p>

<p>Figure 1 shows part of the JS file list that we captured.&nbsp; As you can see, the files with name that start with &ldquo;IMG_&rdquo; and &ldquo;NIC&rdquo; are all GlobeImposter downloaders.</p>

<p><img alt="" src="/content/dam/fortinet-blog/article-images/individual-images/globel1.png" data-style="width: 684px; height: 559px;"/></p>

<p align="center">Figure 1. Captured JS file list</p>

<p>&nbsp;</p>

<p><strong>Download and Execution</strong></p>

<p>When the JS &ldquo;IMG_8798.js&rdquo; is executed, it downloads GlobeImposter from &ldquo;hxxp://wendybull.com.au/87wefhi??JWbXSIl=JWbXSIl&rdquo; and runs it. In my test environment, the downloaded file name is 87wefhi.txt.exe. &nbsp;Next we&rsquo;ll look at how it works on a victim&rsquo;s machine.</p>

<p>When GlobeImposter is launched, it dynamically extracts code into a heap space. It then creates its child process with the flag &ldquo;CREATE_SUSPENDED&rdquo;. It creates a suspended process, and later the code of the child process will be replaced with previously extracted code. This extracted code will be executed when the child process resumes its execution. This behavior is the main part of GlobeImposter&rsquo;s functionality.</p>

<p>The screenshot in Figure 2 shows the process tree when GlobeImposter is executed.</p>

<p><img alt="" src="/content/dam/fortinet-blog/new-images/uploads/analysis-of-new-globeimposter-ransomware-variant-978.png" data-style="width: 900px; height: 363px;"/></p>

<p align="center">Figure 2. The Process Tree</p>

<p>The initial process resumes the execution of its child process by calling &ldquo;ResumeThread&rdquo;, and then exits. All the analysis below is about that child process.</p>

<p><strong>The Child Process</strong></p>

<p>First, it calls the API function SetThreadExecutionState and passes 0x80000041H to it. With the parameter 0x80000041H, the Windows system will never sleep while the ransomware is encrypting the files. The function is called again with 0x80000000 after its work is done.</p>

<p>To prevent it from being analyzed easily, most strings and part of its APIs are encrypted. They are decrypted dynamically when running. Afterwards, it decrypts the exclusion folder and file extension names. In this version, it sets two exclusion lists. While the ransomware goes through all the folders and files on the victim&rsquo;s machine, it skips those files in the folders whose names are in an exclusion folder list and those files whose extension names are in an exclusion extension list.&nbsp;(In this version, it does do the extension name checking, it ignores the checking result though. Maybe it&rsquo;s a bug).</p>

<p>Below are the exclusion lists:</p>

<p>Folder exclusion list: (44 in total)</p>

<p><em>Windows, Microsoft, Microsoft Help, Windows App Certification Kit, Windows Defender, ESET, COMODO, Windows NT, Windows Kits, Windows Mail, Windows Media Player, Windows Multimedia Platform, Windows Phone Kits, Windows Phone Silverlight Kits, Windows Photo Viewer, Windows Portable Devices, Windows Sidebar, WindowsPowerShell, Temp, NVIDIA Corporation, Microsoft.NET, Internet Explorer, Kaspersky Lab, McAfee, Avira, spytech software, sysconfig, Avast, Dr.Web, Symantec, Symantec_Client_Security, system volume information, AVG, Microsoft Shared, Common Files, Outlook Express, Movie Maker, Chrome, Mozilla Firefox, Opera, YandexBrowser, ntldr, Wsus, ProgramData.</em></p>

<p>Extension exclusion list: (170 in total)</p>

<p><em>.$er .4db .4dd .4d .4mp .abs .abx .accdb .accdc .accde .accdr .accdt .accdw .accft .adn .adp .aft .ahd .alf .ask .awdb .azz .bdb .bib .bnd .bok .btr .cdb .cdb .cdb .ckp .clkw .cma .crd .daconnections .dacpac .dad .dadiagrams .daf .daschema .db .db-shm .db-wa .db2 .db3 .dbc .dbf .dbf .dbk .dbs .dbt .dbv .dbx .dcb .dct .dcx .dd .df1 .dmo .dnc .dp1 .dqy .dsk .dsn .dta .dtsx .dx .eco .ecx .edb .emd .eq .fcd .fdb .fic .fid .fi .fm5 .fmp .fmp12 .fmps .fo .fp3 .fp4 .fp5 .fp7 .fpt .fzb .fzv .gdb .gwi .hdb .his .ib .idc .ihx .itdb .itw .jtx .kdb .lgc .maq .mdb .mdbhtm .mdf .mdn .mdt .mrg .mud .mwb .myd .ndf .ns2 .ns3 .ns4 .nsf .nv2 .nyf .oce .odb .oqy .ora .orx .owc .owg .oyx .p96 .p97 .pan .pdb .pdm .phm .pnz .pth .pwa .qpx .qry .qvd .rctd .rdb .rpd .rsd .sbf .sdb .sdf .spq .sqb .sq .sqlite .sqlite3 .sqlitedb .str .tcx .tdt .te .teacher .tmd .trm .udb .usr .v12 .vdb .vpd .wdb .wmdb .xdb .xld .xlgc .zdb .zdc</em></p>

<p><strong>Relocation and Startup Group</strong></p>

<p>Afterwards, it copies itself into &ldquo;%AllUserProfile%\Public\&rdquo; and adds the new file in the startup group in the victim&rsquo;s Windows registry. This allows it to be executed automatically whenever the system starts. Figure 3 shows that GlobeImposter has been added (&hellip;.RunOnce\CerificatesCheck) into the startup group in the Windows registry.</p>

<p><img alt="" src="/content/dam/fortinet-blog/new-images/uploads/analysis-of-new-globeimposter-ransomware-variant-979.png" data-style="width: 900px; height: 364px;"/></p>

<p align="center">Figure 3. Startup Group in Windows Registry</p>

<p><strong>Preparatory Work</strong></p>

<p>To prevent the victim from restoring encrypted files from the Shadow Volume copies, it calls &ldquo;vssadmin.exe Delete Shadows /All /Quiet&rdquo; in an executable batch file to delete all shadows. In that batch file it also cleans up Remote Desktop information saved in the system registry as well as the file %UserProfile%\Documents\Default.rdp. The batch file is called again after the file encryption work is done.</p>

<p>Figure 4 shows the content of the batch file.</p>

<p><img alt="" src="/content/dam/fortinet-blog/new-images/uploads/analysis-of-new-globeimposter-ransomware-variant-980.png" data-style="width: 899px; height: 341px;"/></p>

<p align="center">Figure 4. The Batch File</p>

<p>Next, it initializes encryption related keys, data, etc. for encrypting files 2048-bit RSA. Part of the key related data is saved in a newly created file &ldquo;%AllUserProfile%\Public\{hex numbers}&rdquo;. The name of {hex numbers} is made from the hardware information of victim&rsquo;s machine.</p>

<p><strong>Before Encrypting Files</strong></p>

<p>Killing some running processes and generating an html file are the last two steps before its starts encrypting files.</p>

<p>It calls taskkill.exe to kill running processes whose names include &quot;sql&quot;, &quot;outlook&quot;, &quot;ssms&quot;, &quot;postgre&quot;, &quot;1c&quot;, &quot;excel&quot; and &quot;word&quot;. Killing these processes might cause them to release the files they are using, which could result in this ransomware encrypting more files.</p>

<p>Figure 5 shows the pseudo code used to do this.</p>

<p><img alt="" src="/content/dam/fortinet-blog/new-images/uploads/analysis-of-new-globeimposter-ransomware-variant-981.png" data-style="width: 898px; height: 437px;"/></p>

<p align="center">Figure 5. Kill Matched Processes</p>

<p>An HTML file (RECOVER-FILES-726.html) is then generated and dropped in the folder where the files are encrypted. Opening the HTML file informs the victim that the system&rsquo;s files have been encrypted and provides instructions on how to pay to get them back. The HTML file consists of the decrypted resources of this exe as well as a &ldquo;personal ID&rdquo;.</p>

<p>This &ldquo;personal ID&rdquo; is sent to the server when you see the payment page. That ID allows the attacker to identify you and to generate the decryption key. Figure 6 is the screenshot of this HTML file content.</p>

<p><img alt="" src="/content/dam/fortinet-blog/new-images/uploads/analysis-of-new-globeimposter-ransomware-variant-982.png" data-style="width: 856px; height: 486px;"/></p>

<p align="center">Figure 6. RECOVER-FILES-726.html Content</p>

<p><strong>Encryption Process</strong></p>

<p>When GlobeImposter starts encrypting, it first scans files in all of the partitions on the victim&rsquo;s machine. It then encrypts almost every file as long as its folder name is not in the folder exclusion list&nbsp;as mentioned before. It reads the file and then encrypts the file content using the RSA algorithm and then overwrites the original content with encrypted content. The &ldquo;personal ID&rdquo; is also appended after encrypted content has been added to the file.</p>

<p>Figure 7 shows the content of an encrypted file.</p>

<p><img alt="" src="/content/dam/fortinet-blog/new-images/uploads/analysis-of-new-globeimposter-ransomware-variant-983.png" data-style="width: 615px; height: 613px;"/></p>

<p align="center">Figure 7. File Content of Encrypted config.sys</p>

<p>It then appends &ldquo;..726&rdquo; to every encrypted file name to identify that the file has been encrypted.</p>

<p>The screenshot in Figure 8, below, shows that it is about to rename an encrypted file by calling API MoveFileExW.</p>

<p><img alt="" src="/content/dam/fortinet-blog/new-images/uploads/analysis-of-new-globeimposter-ransomware-variant-984.png" data-style="width: 899px; height: 486px;"/></p>

<p align="center">Figure 8. Rename Encrypted File</p>

<p>Figure 9 shows the screenshot of encrypted files (including exe files) in the python installation folder.</p>

<p><img alt="" src="/content/dam/fortinet-blog/new-images/uploads/analysis-of-new-globeimposter-ransomware-variant-985.png" data-style="width: 836px; height: 435px;"/></p>

<p align="center">Figure 9. Encrypted Files in python Folder</p>

<p><strong>Open RECOVER-FILES-726.html </strong></p>

<p>Figure 10 shows how you go to the payment page by opening the RECOVER-FILES-726.html. file.</p>

<p><img alt="" src="/content/dam/fortinet-blog/new-images/uploads/analysis-of-new-globeimposter-ransomware-variant-986.png" data-style="width: 899px; height: 685px;"/></p>

<p align="center">Figure 10. Open RECOVER-FILES-726.html</p>

<p><strong>Solution</strong></p>

<p>Through this analysis, we know how GlobeImposter is downloaded onto a victim&rsquo;s machine, and how it works to encrypt the files on victim&rsquo;s machine. We also observed that many new JS samples are spreading this ransomware. Since it uses an RSA 2048-bit key to encrypt files, it&rsquo;s very hard to decrypt them without the decryption key.</p>

<ul>
	<li>The URL in the JS file used to download the GlobeImposter has been rated as a &ldquo;<strong>Malicious Website</strong>&rdquo; by the FortiGuard Webfilter service.</li>
	<li>The JS file is detected as <strong><span data-style="color:#000000;">JS/GlobeImposter.A!tr&nbsp;</span></strong>by the FortiGuard Antivirus service.</li>
	<li>The downloaded GlobeImposter is detected as <span data-style="color:#000000;"><strong>W32/GlobeImposter.A!tr</strong></span><strong> </strong>by the FortiGuard Antivirus service.</li>
</ul>
