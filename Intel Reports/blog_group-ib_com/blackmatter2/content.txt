                            <h1 class="header__title title-h2 mb-24 mt-md-48 mt-lg-64 mt-xl-64">The Darker Things</h1><p class="header__text mb-xs-48 mb-64 mb-lg-96 mb-xl-96">BlackMatter and their victims</p><div class="post-info__date mb-24 mb-lg-32 mb-xl-48"><div class="body2">November 3, 2021 · <span id="reading-time"></span> min to read · Ransomware</div></div><div class="post-info__image mb-24 mb-lg-32 mb-xl-48"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/img-1440-69.jpg.webp" type="image/webp"><img src="https://www.group-ib.com/wp-content/uploads/img-1440-69.jpg" alt="" class="webpexpress-processed"></picture></div><div class="post-info__tags"><div class="post-info__tag body2">BlackMatter</div><div class="post-info__tag body2">Digital Forensics</div><div class="post-info__tag body2">Incident Response</div></div>                        </div>
                    </div>
                </div>
                <div class="blog-post-content" id="blog-post-content">
                    <div class="blog-post-content__section--text"><p>Today, on November 3, <strong>BlackMatter gang</strong> announced it was shutting its <a href="https://www.group-ib.com/resources/knowledge-hub/raas/" target="_blank" rel="noopener">Ransomware-as-a-Service</a> program due to the &#8220;pressure from the authorities&#8221;.</p>
<p>However, it doesn&#8217;t mean that BlackMatter&#8217;s affiliates will stop malicious activity. They will most likely join other RaaS programs. In addition, this might just be an attempt to have a fresh start under a different name. Just like BlackMatter was a rebranding of DarkSide, a new successor may appear soon. Therefore, given the similarities that we <a href="/blog/blackmatter-ransomware/" target="_blank" rel="noopener">observed</a> between DarkSide and BlackMatter ransomware back in August, it&#8217;s important to be aware of the latest ransomware versions&#8217; features: malware configuration, encryption mechanisms in use etc.</p>
<p>For this purpose the experts from Group-IB&#8217;s Digital Forensics and Incident Response Team analyzed <strong>new BlackMatter samples</strong> for Windows and Linux, Andrey Zhdanov, Group-IB&#8217;s threat hunter, will share new data on his findings.</p>
<p>A US architectural firm was among the first to fall victim to BlackMatter in late July 2021. Since then, t<strong>he BlackMatter operators&#8217; appetites have grown considerably</strong>, the frequency of attacks has increased, and the threat actors seem to have been constantly improving their tools. The average ransom demand is <strong>$5.3 million</strong>, with the maximum, which the attackers demanded from Japan&#8217;s Olympus Corporation, <strong>reaching $30 million</strong>.</p>
<p><picture><source srcset="https://www.group-ib.com/wp-content/uploads/1-min-10.png.webp" type="image/webp"><img decoding="async" class="alignnone size-full wp-image-25527 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/1-min-10.png" alt="blackmatter ransomware in numbers" width="1680" height="900"></picture></p>
<p><strong>BlackMatter</strong> affiliates try their best to pick their victims carefully, so as not to draw too much attention, but they are not exactly succeeding. Since the first BlackMatter attacks were reported, they have received a lot of very close attention from threat researchers. And on 18 October 2021, the CISA, FBI, and NSA issued joint recommendations, naming BlackMatter ransomware responsible for attacks on U.S. critical infrastructure that had begun in July 2021. As of November 2021, the list of BlackMatter victims consists of more than 50 companies based in the US, Austria, Italy, France, Japan, and other countries.</p>
<p><picture><source srcset="https://www.group-ib.com/wp-content/uploads/2-min-13.png.webp" type="image/webp"><img decoding="async" class="alignnone size-full wp-image-25526 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/2-min-13.png" alt="geography of blackmatter ransomware attacks" width="1680" height="900"></picture></p>
<p><picture><source srcset="https://www.group-ib.com/wp-content/uploads/3-min-14.png.webp" type="image/webp"><img decoding="async" class="alignnone size-full wp-image-25524 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/3-min-14.png" alt="distribution of blackmatter ransomware attacks by industry" width="1680" height="900"></picture></p>
<h2>BlackMatter for Windows</h2>
<p>Depending on command line parameters, ransomware for Windows can operate in five different modes. We were able to obtain command line arguments based on analysis of their hashes.</p>
<p>&#8211;<em>path [PATH]</em> – encryption of the specified object (directory, file, network resource).</p>
<p>&#8211;<em>safe</em> – self-registration in the RunOnce key of system registry, reboot for file encryption in safe mode.</p>
<p>&#8211;<em>wall</em> – creating a BMP image with information about encryption of files and setting it as the desktop wallpaper.</p>
<p><em>[PATH]</em> – encryption of a specified directory/file.</p>
</div>
                            <div class="blog-post-content__section--text"><p>When other parameters are set or any parameters are absent, the system is fully encrypted according to the configuration settings. Upon completing the encryption, the ransomware creates a BMP image alerting that files have been encrypted, which it then sets as the desktop wallpaper. Starting from version 1.4, the ransomware can also print the text of the demand for ransom on the victim&#8217;s default printer.</p>
<p>When <strong>BlackMatter</strong> launches, it checks the rights of the current user and, if necessary, tries to bypass the UAC (User Account Control) through privilege escalation using the ICMLuaUtil COM interface. Also, if the appropriate flag is set in the configuration, it attempts to authenticate using the credentials contained in the configuration data.</p>
<p>Before starting the encryption, BlackMatter deletes shadow copies of partitions using WQL queries (WMI Query Language).</p>
<p>To encrypt files, BlackMatter uses the most efficient multithreading implementation based on the use of the I/O (input/output) completion port. The malware also sets the highest priority (THREAD_PRIORITY_HIGHEST) for the file enumeration and encryption streams. By default, only the first megabyte of file contents is encrypted. In earlier versions, data was encrypted using Salsa20. Apparently, the authors of BlackMatter, just like the authors of another extortionist Petya five years ago, made mistakes in the implementation of the Salsa20 algorithm. Starting from version 1.9, the contents of the files are encrypted already using a modified version of the implementation of the ChaCha20 algorithm, presumably taken from CryptoPP library. Furthermore, the ChaCha20 encryption algorithm is implemented using SSSE3 processor instructions. ChaCha20 keys are encrypted using the RSA-1024 public key. A data block with an encrypted key is appended to the end of the file. The names of the encrypted files are as follows:</p>
</div>
                            
                            <div class="blog-post-content__section"><div class="code"><div class="code__wrapper">[FILENAME].[VICTIM_ID]</div></div></div><div class="blog-post-content__section--text"><p><em>FILENAME</em> – is the original name of the file.</p>
<p><em>VICTIM_ID</em> – is the victim ID generated on the basis of the string contained in the MachineGuid value of the HKLM\SOFTWARE\Microsoft\Cryptography registry key.</p>
<p><strong>The BlackMatter configuration contains the names of directories, files and extensions skipped during the encryption process as lists of checksums (hashes).</strong></p>
<p>In each processed directory, the ransomware creates text files containing the demand for ransom:</p>
</div>
                            
                            <div class="blog-post-content__section"><div class="code"><div class="code__wrapper">[VICTIM_ID].README.txt</div></div></div><div class="blog-post-content__section--text"><p><picture><source srcset="https://www.group-ib.com/wp-content/uploads/4-min-13.png.webp" type="image/webp"><img decoding="async" class="alignnone size-full wp-image-25525 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/4-min-13.png" alt="text files containing the demand for ransom" width="981" height="996"></picture></p>
<h3>Configuration</h3>
<p>The <strong>BlackMatter</strong> configuration data for Windows is contained in a section disguised as a &#8220;.rsrc&#8221; resource section, but there are no resources in it.</p>
<p><picture><source srcset="https://www.group-ib.com/wp-content/uploads/5-min-13.png.webp" type="image/webp"><img decoding="async" class="alignnone size-full wp-image-25537 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/5-min-13.png" alt="BlackMatter configuration data for Windows" width="776" height="353"></picture></p>

Prior to encryption, the configuration data was pre-compressed using the aPLib compression algorithm, which is popular among ransomware developers. Previously, this algorithm was found, for example, in such ransomware families as DarkSide, DoppelPaymer, Clop, and others.</p>

</div></div></div><div class="blog-post-content__section--text"><h2>BlackMatter for Linux</h2>
<p><strong>BlackMatter</strong> <strong>ransomware for Linux targets VMware ESXi servers</strong>. According to the settings in the configuration data, the ransomware can stop virtual machines and terminate specified processes before data encryption. The ransomware also disables the firewall. To encrypt virtual machine files, the ransomware uses the esxcli utility to obtain a list of storages with &#8220;vmfs&#8221;, &#8220;vffs&#8221; and &#8220;nfs&#8221; file systems.</p>
<p>BlackMatter for Linux implements multithreaded file encryption with the extensions specified in the configuration. Data is encrypted in blocks that are multiples of one megabyte using the HC-256 stream encryption algorithm. HC-256 keys are encrypted using the RSA-4096 public key. The CryptoPP crypto library is used to implement encryption algorithms.</p>
<p>Data transferring to the attacker-controlled resources on the internet is implemented in the malware using the libcurl library.</p>
<h3>Configuration</h3>
<p>BlackMatter configuration data for Linux is contained in the &#8220;.cfgETD&#8221; section of the ELF file. The data is encrypted, compressed using the zlib data compression library, and encoded using Base64.</p>
<p>Encrypted configuration data after Base64 decoding and zlib decompression:</p>
<p><picture><source srcset="https://www.group-ib.com/wp-content/uploads/7-min-11.png.webp" type="image/webp"><img decoding="async" class="alignnone size-full wp-image-25535 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/7-min-11.png" alt="BlackMatter configuration data for Linux" width="778" height="353"></picture></p>
<p>Configuration data is encrypted using a cyclic bytewise XOR operation using the key contained in the first 32 bytes.</p>
<p>After decryption, the configuration data is in JSON format.</p>
<p><picture><source srcset="https://www.group-ib.com/wp-content/uploads/8-min-10.png.webp" type="image/webp"><img decoding="async" class="alignnone size-full wp-image-25536 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/8-min-10.png" alt="the configuration data in JSON format" width="782" height="942"></picture></p>

</pre></div></div></div><div class="blog-post-content__section--text"><h2>How to protect your network against ransomware</h2>
<ul>
<li>Make your remote access tools secure. Use multifactor authentication or at least set complex passwords and change them regularly.</li>
<li>Eliminate vulnerabilities in publicly accessible apps as soon as possible, especially those that could allow attackers to bypass the external perimeter.</li>
<li>Implement comprehensive email protection to detect and stem the most sophisticated threats. <a href="/products/business-email-protection/">More</a></li>
<li>Monitor what your contractors do in your network. Providing them with remote access should be strictly regulated.</li>
<li>Instantly patch vulnerabilities on hosts on the internal network that attackers could leverage to escalate privileges or propagate across the network.</li>
<li>Monitor the use of dual-use tools that could help attackers conduct network reconnaissance, obtain authentication data, and much more.</li>
<li>Restrict access to cloud storage. This will help keep attackers from exfiltrating data from the corporate network.</li>
<li>Make sure all accounts have the least possible privileges on the systems. In case of an attack, this will make it difficult for threat actors to move laterally across the network.</li>
<li>Use separate accounts with multifactor authentication to access servers containing backups. Moreover, make sure that you have offline copies.</li>
<li>Implement a modern threat monitoring and blocking tool that will help contain and repel attacks at any stage of the kill chain. <a href="/products/managed-xdr/">More</a></li>
</ul>
<p>For more information about attacks using manually controlled ransomware, see the Group-IB report &#8220;Ransomware Uncovered 2021/2022&#8221;.</p>

    function positioningSidebar() {
        let sidebar = document.getElementById('sidebar');
        let sidebarHeight = sidebar.offsetHeight;
        let windowHeight = document.documentElement.clientHeight;
        if (windowHeight < (sidebarHeight + 48)) {
            let sidebarAuthors = sidebar.querySelector('.sidebar__authors');
            let sidebarMorePosts = sidebar.querySelector('.sidebar__more-posts');
            let authorsHeight = sidebarAuthors ? sidebarAuthors.offsetHeight : 0;
            let morePostsHeight = sidebarMorePosts ? sidebarMorePosts.offsetHeight : 0;
            let sidebarTop = authorsHeight + morePostsHeight + 140;
            jQuery(sidebar).css('top', -sidebarTop + 'px');
        } else {
            jQuery(sidebar).css('top', '72px');
        }
    }
    window.addEventListener('resize', positioningSidebar);
    positioningSidebar();

    if (localStorage.getItem('theme')) {
        if (localStorage.getItem('theme') == 'dark') {
            jQuery('body').addClass('theme--dark');
        } else if (localStorage.getItem('theme') == 'light') {
            jQuery('body').addClass('theme--white');
        }
    } else {
        localStorage.setItem('theme', 'dark');
        jQuery('body').addClass('theme--dark');
    }

    jQuery('.theme-toggle').click(function() {
        if (localStorage.getItem('theme') == 'dark') {
            localStorage.setItem('theme', 'light');
        } else {
            localStorage.setItem('theme', 'dark');
        }
        jQuery('body').toggleClass('no-transition');
        jQuery('body').toggleClass('theme--dark');
        jQuery('body').toggleClass('theme--white');
        setTimeout(() => {
            jQuery('body').toggleClass('no-transition');
        }, 250);
    });
    jQuery('.share-toggle').click(function() {
        jQuery('.share-toggle').toggleClass('active');
        jQuery('.share-widget').toggleClass('show');
    });
