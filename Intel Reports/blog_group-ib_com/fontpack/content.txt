                            <h1 class="header__title title-h2 mb-24 mt-md-48 mt-lg-64 mt-xl-64">FontPack: A dangerous update</h1><p class="header__text mb-xs-48 mb-64 mb-lg-96 mb-xl-96">Attribution secrets: Who is behind stealing credentials and bank card data by asking to install fake Flash Player, browser or font updates?</p><div class="post-info__date mb-24 mb-lg-32 mb-xl-48"><div class="body2">June 3, 2021 · <span id="reading-time"></span> min to read · Threat Intelligence</div></div><div class="post-info__image mb-24 mb-lg-32 mb-xl-48"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/img-1440-15.jpg.webp" type="image/webp"><img src="https://www.group-ib.com/wp-content/uploads/img-1440-15.jpg" alt="" class="webpexpress-processed"></picture></div><div class="post-info__tags"><div class="post-info__tag body2">Attribution</div><div class="post-info__tag body2">FontPack</div><div class="post-info__tag body2">Threat Intelligence</div></div>                        </div>
                    </div>
                </div>
                <div class="blog-post-content" id="blog-post-content">
                    <div class="blog-post-content__section--text"><p>Attribution is our main focus here at Group-IB <a href="/products/threat-intelligence/" target="_blank" rel="noopener">Threat Intelligence</a>, and it becomes harder every year. The number of unique malicious programs is decreasing while affiliate programs (collaborations between threat actors) are on the rise, with the number and quality of attacks both going up. Today <strong>Nikita Rostovtsev</strong>, an analyst at Group-IB Threat Intelligence, will show you attribution in practice by examining a malicious landing page that Group-IB specialists are tracking as <strong>FontPack</strong>. You will see what this page distributes and how it does so, as well as learn other interesting things that Group-IB has uncovered.</p>
<p>First and foremost we need to find out who is behind the landing page, down to the specific hacking group or particular threat actor. All we know so far is that the page is hosted on compromised websites by injecting JS scripts. The scripts imitate a website crashing and display a message saying that users must update their software, e.g., the browser, Adobe Flash Player, or fonts. The code name used by our team, FontPack, is based on the decoy methods employed in the campaign we will analyze in this report.</p>
<p><strong>Threat actors decide what particular fake to show their victim and how often to do so by changing relevant variables in the script code.</strong> According to our data, multiple unconnected hackers use the tool.</p>
<p>Let us focus on one campaign whose goal was to deliver the RedLine stealer to victim devices. When successful, threat actors were able to collect their victims&#8217; credentials, autocomplete field data, and bank card information. Our analysis revealed that, since November 2020, FontPack has infected at least 20 websites, including six that were involved in one campaign. But first things first.</p>
<h2>What is FontPack?</h2>
<p>By &#8220;landing page&#8221; we mean a target webpage that is shown to users and urges them to download a malicious file that will then be executed. The FontPack landing page has been known to Threat Intelligence researchers since 2018. <a href="https://www.malwarebytes.com/blog/news/2020/02/domen-toolkit-gets-back-to-work-with-new-malvertising-campaign" target="_blank" rel="nofollow noopener">Other specialists</a> may know it as &#8220;Domen toolkit&#8221; because of its variable called &#8220;var domen&#8221;.</p>
<h2>How is FontPack injected into websites?</h2>
<p>Attacks start with injecting FontPack-containing JS scripts into websites created and controlled by the threat actors. Compromised legitimate websites are also used for the same purpose.</p>
<div id="attachment_26016" style="width: 1006px" class="wp-caption alignnone"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/1-min-16.png.webp" type="image/webp"><img aria-describedby="caption-attachment-26016" decoding="async" class="size-full wp-image-26016 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/1-min-16.png" alt="A fake window urging the user to update their browser" width="996" height="976"></picture><p id="caption-attachment-26016" class="wp-caption-text">A fake window urging the user to update their browser, shown on top of a legitimate website</p></div>

When they do so, malware is downloaded to their computer.<strong> This type of attack is the most effective for threat actors and the most dangerous for regular users because victims do not suspect an infection from a website they trust.</strong> Readers who do not yet understand what such websites can look like might find the gif below helpful:</p>

<h2>What is RedLine Stealer capable of?</h2>
<p>The hacker community learned about <strong>RedLine Stealer</strong> in early 2020, when it was put up for sale for the first time on multiple underground forums.</p>
<p>RedLine quickly became popular and has involved over 230 C&amp;C servers since October 2020 according to our data. The stealer is written in C# and its functionality is typical for this type of malware:</p>
<ol>
<li>It collects credentials, cookies, autocomplete field data, and credit card information from all Chromium/Gecko-based browsers</li>
<li>It collects data from FTP and IM clients</li>
<li>It identifies countries where the stealer will not function</li>
<li>It collects information about the victim&#8217;s PC</li>
<li>It manages anti-duplicate logs settings in the admin panel</li>
<li>It deletes itself</li>
<li>It performs tasks in four different ways.</li>
</ol>
<p>These ways are:</p>
<ol>
<li>It downloads a file to a specified path through a direct link</li>
<li>It injects a 32-bit file downloaded through a direct link into another file, which must be specified</li>
<li>It downloads a file to a specified path through a direct link and later launches it</li>
<li>It opens a link in the default browser</li>
</ol>
<p>Interestingly, websites compromised as early as February 2021 still deliver payloads despite the stealer&#8217;s C&amp;C server no longer being available.</p>
<p>As a closing remark, the campaign is only one of many that involve this landing page. The fake updates are especially interesting considering that Flash Player support was discontinued in early 2021.</p>

    function positioningSidebar() {
        let sidebar = document.getElementById('sidebar');
        let sidebarHeight = sidebar.offsetHeight;
        let windowHeight = document.documentElement.clientHeight;
        if (windowHeight < (sidebarHeight + 48)) {
            let sidebarAuthors = sidebar.querySelector('.sidebar__authors');
            let sidebarMorePosts = sidebar.querySelector('.sidebar__more-posts');
            let authorsHeight = sidebarAuthors ? sidebarAuthors.offsetHeight : 0;
            let morePostsHeight = sidebarMorePosts ? sidebarMorePosts.offsetHeight : 0;
            let sidebarTop = authorsHeight + morePostsHeight + 140;
            jQuery(sidebar).css('top', -sidebarTop + 'px');
        } else {
            jQuery(sidebar).css('top', '72px');
        }
    }
    window.addEventListener('resize', positioningSidebar);
    positioningSidebar();

    if (localStorage.getItem('theme')) {
        if (localStorage.getItem('theme') == 'dark') {
            jQuery('body').addClass('theme--dark');
        } else if (localStorage.getItem('theme') == 'light') {
            jQuery('body').addClass('theme--white');
        }
    } else {
        localStorage.setItem('theme', 'dark');
        jQuery('body').addClass('theme--dark');
    }

    jQuery('.theme-toggle').click(function() {
        if (localStorage.getItem('theme') == 'dark') {
            localStorage.setItem('theme', 'light');
        } else {
            localStorage.setItem('theme', 'dark');
        }
        jQuery('body').toggleClass('no-transition');
        jQuery('body').toggleClass('theme--dark');
        jQuery('body').toggleClass('theme--white');
        setTimeout(() => {
            jQuery('body').toggleClass('no-transition');
        }, 250);
    });
    jQuery('.share-toggle').click(function() {
        jQuery('.share-toggle').toggleClass('active');
        jQuery('.share-widget').toggleClass('show');
    });
