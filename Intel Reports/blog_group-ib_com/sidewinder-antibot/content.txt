                            <h1 class="header__title title-h2 mb-24 mt-md-48 mt-lg-64 mt-xl-64">SideWinder.AntiBot.Script</h1><p class="header__text mb-xs-48 mb-64 mb-lg-96 mb-xl-96">APT SideWinder’s new tool that narrows their reach to Pakistan</p><div class="post-info__date mb-24 mb-lg-32 mb-xl-48"><div class="body2">June 1, 2022 · <span id="reading-time"></span> min to read · Advanced Persistent Threats</div></div><div class="post-info__image mb-24 mb-lg-32 mb-xl-48"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/img-1440-24-min.jpg.webp" type="image/webp"><img src="https://www.group-ib.com/wp-content/uploads/img-1440-24-min.jpg" alt="" class="webpexpress-processed"></picture></div><div class="post-info__tags"><div class="post-info__tag body2">APT group</div><div class="post-info__tag body2">Pakistan</div><div class="post-info__tag body2">SideWinder</div><div class="post-info__tag body2">Threat Intelligence</div></div>                        </div>
                    </div>
                </div>
                <div class="blog-post-content" id="blog-post-content">
                    <div class="blog-post-content__section--text"><p>Group-IB Threat Intelligence researchers have discovered a new malicious infrastructure and a custom tool of the APT group <strong>SideWinder (aka Rattlesnake, Hardcore Nationalist, RAZOR TIGER, T-APT-04 and APT-C-17)</strong>, <a href="https://attack.mitre.org/groups/G0121/" target="_blank" rel="nofollow noopener">a threat actor that is believed to be originating from India and primarily targeting Pakistan.</a> The newly discovered custom tool, codenamed SideWinder.AntiBot.Script, is being used in the gang’s phishing attack against Pakistani targets. Group-IB Threat Intelligence team shares its findings so that security teams can more effectively identify SideWinder attacks.</p>
<h2>Antibot script &#8211; Key findings</h2>
<ul class="checks">
<li>Over the last year, Group-IB <a href="/products/threat-intelligence/" target="_blank" rel="noopener">Threat Intelligence</a> system identified 92 IP addresses that have been used by SideWinder APT for phishing emails.</li>
<li>Pakistan remains the primary target for SideWinder. The attackers are especially interested in the Pakistani government organizations based on the discovered phishing document and public studies.</li>
<li>Phishing links in emails or posts that mimic legitimate notifications and services of government agencies and organizations in Pakistan are primary attack vectors of the gang.</li>
<li>SideWinder started using an anti-bot script to filter their victims &#8211; they are only interested in Pakistani users.</li>
<li>The group continues to distribute malicious files in ZIP archives with an LNK file inside, which downloads an HTA file from a remote server.</li>
<li>Upon discovery, Group-IB Threat Intelligence team notified relevant local authorities and shared its findings to make sure that the threat can be identified and contained at early stages.</li>
</ul>
<h2>SideWinder Profile</h2>
<p>The SideWinder APT (attlesnake, Hardcore Nationalist, RAZOR TIGER, T-APT-04 and APT-C-17) is believed to be an Indian nation-state threat actor.</p>
<p>In their attacks, SideWinder was seen targeting government, military, and economic sectors in Southeast Asia: in Afghanistan, Nepal, Sri Lanka, Bhutan, Myanmar, the Philippines, Bangladesh, Singapore, and China. However, since the discovery of the group in 2012, Pakistan has been the primary target of SideWinder. In the last year alone, several SideWinder’s attacks targeting Pakistan have been detected. SideWinder was particularly interested in the Pakistani military targets.</p>
<p>The Pakistani government even published an official <a href="https://cabinet.gov.pk/SiteImage/Misc/files/NTISB%20Advisories/2019/22-Advisory-No-22-2019.pdf" target="_blank" rel="nofollow noopener">advisory</a> about SideWinder <a href="https://download1.fbr.gov.pk/Docs/20204281542926630AdvisoryforRattlesnake.pdf" target="_blank" rel="noopener">activity</a>.</p>

<h3>SideWinder.AntiBot.Script</h3>
<p>As soon as the recipient clicks on the link, <strong>the new tool, dubbed SideWinder.AntiBot.Script by Group-IB researchers, comes into play.</strong> The script checks the client browser environment and, based on several parameters, decides whether to issue a malicious file or redirect to a legitimate resource.</p>
<p>For example, let&#8217;s take finance.pakgov[.]net which we have described a little already. The phishing link appears as follows &#8211; <em>hxxps://finance.pakgov[.]net/salary-a4222e91.</em></p>

<p>In one case the downloadable file (<em>SHA1- 4421f214c91a08ac0318871c6f918cfffe36d039</em>) was an archive named &#8220;<em>Pay and Pension Increase Circular_Finance Division.zip</em>&#8221;</p>

<li><em>64a889e35b10a902170abe092c6c6b8f16c66dd1 &#8211; Pay and Pension Increase Circular_Finance Division.pdf.lnk;</em></li>

<p>Unfortunately, the second stage of the payload turned out to be inactive, so we got a &#8220;<em>404 Not Found</em>&#8221; error.</p>
<div id="attachment_20459" style="width: 1186px" class="wp-caption alignnone"><img aria-describedby="caption-attachment-20459" decoding="async" class="size-full wp-image-20459" src="https://www.group-ib.com/wp-content/uploads/32.webp" alt="Screenshot of the error " width="1176" height="728" /><p id="caption-attachment-20459" class="wp-caption-text">Image 32. <p><strong>However, this attack is not unique to SideWinder group</strong>. HTAs typically contain PowerShell, VBScript, or JavaScript, and the latter has been seen more often in recent attacks.</p>
<p>HTAs are typically used to download files for later use by the DLL-sideloading technique. In some cases, HTAs also upload a decoy document, usually in PDF format, to put the victim&#8217;s attention down.</p>
<p>The use of this technique by this group was <a href="https://mp.weixin.qq.com/s/Kkta59k7r81uIBjJvE9pCw" target="_blank" rel="nofollow noopener">mentioned publicly</a> by researchers from <strong>weixin</strong>:</p>
<div id="attachment_20460" style="width: 652px" class="wp-caption alignnone"><img aria-describedby="caption-attachment-20460" decoding="async" class="size-full wp-image-20460" src="https://www.group-ib.com/wp-content/uploads/33.webp" alt="Fragment of Kill Chain" width="642" height="597" /><p id="caption-attachment-20460" class="wp-caption-text">Image 33. Fragment of Kill Chain taken from https://mp.weixin.qq.com/s/Kkta59k7r81uIBjJvE9pCw</p></div>
<p>When using this technique, HTA will load the &#8220;Duser.dll&#8221; file and copy the system file &#8220;credwiz.exe&#8221; into the same directory. The &#8220;credwiz.exe&#8221; loads &#8220;Duser.dll&#8221; with the Dll Side-Loading technique, which in turn downloads and executes the final backdoor.</p>
<p>The final backdoor allows the attacker:</p>
<ul>
<li>Collect system information;</li>
<li>Collect list of files and paths to them;</li>
<li>Collect selected files;</li>
<li>Update commands and C2 addresses.</li>
</ul>
<h2>Sidewinder antibot &#8211; Conclusion</h2>
<p>Given the <strong>SideWinder</strong>’s widespread activity deploying new command and control servers and the number of observed phishing links, Group-IB Threat Intelligence team decided to publish these findings so that potential targets in Pakistan identified as part of the research could check their networks and identify attacks by Sidewinder that are in early stages. If you believe you may be a victim of similar phishing campaigns or that you may be one of the attackers’ targets, please reach out.</p>

    window.addEventListener('scroll', () => {
        let current = '';
        sections.forEach((section) => {
            const sectionTop = section.offsetTop;
            const sectionHeight = section.clientHeight;
            if (pageYOffset >= sectionTop - sectionHeight / 10) {
                current = section.getAttribute('id');
            }
        });

        navItems.forEach((a) => {
            a.classList.remove('active');
            if (a.classList.contains(current)) {
                a.classList.add('active');
            }
        });
    });

    // SMOOTH SCROLL
    var $root = jQuery('html, body');


    jQuery('a[href^="#"].scrollto').click(function() {
        var href = jQuery.attr(this, 'href');
        var headerHeight = 100;

        $root.animate({
                scrollTop: jQuery(href).offset().top - headerHeight
            },
            300,
        );

        return false;
    });

    // SMOOTH SCROLL WITH NO HASH
    var $root = jQuery('html, body');


    jQuery('a[href^="#"].scrolltonohash').click(function() {
        var href = jQuery.attr(this, 'href');
        var headerHeight = 100;

        $root.animate({
                scrollTop: jQuery(href).offset().top - headerHeight
            },
            300
        );

        return false;
    });
</script>

<script>
    function readingTime() {
        const text = document.getElementById("blog-post-content").innerText;
        const wpm = 225;
        const words = text.trim().split(/\s+/).length;
        const time = Math.ceil(words / wpm);
        document.getElementById("reading-time").innerText = time;
    }
    readingTime();
</script>

    function positioningSidebar() {
        let sidebar = document.getElementById('sidebar');
        let sidebarHeight = sidebar.offsetHeight;
        let windowHeight = document.documentElement.clientHeight;
        if (windowHeight < (sidebarHeight + 48)) {
            let sidebarAuthors = sidebar.querySelector('.sidebar__authors');
            let sidebarMorePosts = sidebar.querySelector('.sidebar__more-posts');
            let authorsHeight = sidebarAuthors ? sidebarAuthors.offsetHeight : 0;
            let morePostsHeight = sidebarMorePosts ? sidebarMorePosts.offsetHeight : 0;
            let sidebarTop = authorsHeight + morePostsHeight + 140;
            jQuery(sidebar).css('top', -sidebarTop + 'px');
        } else {
            jQuery(sidebar).css('top', '72px');
        }
    }
    window.addEventListener('resize', positioningSidebar);
    positioningSidebar();

    if (localStorage.getItem('theme')) {
        if (localStorage.getItem('theme') == 'dark') {
            jQuery('body').addClass('theme--dark');
        } else if (localStorage.getItem('theme') == 'light') {
            jQuery('body').addClass('theme--white');
        }
    } else {
        localStorage.setItem('theme', 'dark');
        jQuery('body').addClass('theme--dark');
    }

    jQuery('.theme-toggle').click(function() {
        if (localStorage.getItem('theme') == 'dark') {
            localStorage.setItem('theme', 'light');
        } else {
            localStorage.setItem('theme', 'dark');
        }
        jQuery('body').toggleClass('no-transition');
        jQuery('body').toggleClass('theme--dark');
        jQuery('body').toggleClass('theme--white');
        setTimeout(() => {
            jQuery('body').toggleClass('no-transition');
        }, 250);
    });
    jQuery('.share-toggle').click(function() {
        jQuery('.share-toggle').toggleClass('active');
        jQuery('.share-widget').toggleClass('show');
    });
</script>
