                            <h1 class="header__title title-h2 mb-24 mt-md-48 mt-lg-64 mt-xl-64">The Art of Cyberwarfare</h1><p class="header__text mb-xs-48 mb-64 mb-lg-96 mb-xl-96">Chinese APTs attack Russia</p><div class="post-info__date mb-24 mb-lg-32 mb-xl-48"><div class="body2">August 3, 2021 · <span id="reading-time"></span> min to read · Advanced Persistent Threats</div></div><div class="post-info__image mb-24 mb-lg-32 mb-xl-48"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/img-1440-36.jpg.webp" type="image/webp"><img src="https://www.group-ib.com/wp-content/uploads/img-1440-36.jpg" alt="" class="webpexpress-processed"></picture></div><div class="post-info__tags"><div class="post-info__tag body2">APT</div><div class="post-info__tag body2">China</div><div class="post-info__tag body2">Malware</div></div>                        </div>
                    </div>
                </div>
                <div class="blog-post-content" id="blog-post-content">
                    <div class="blog-post-content__section--text"><p>In mid-May 2021, experts from SOLAR JSOC and the National Computer Incident Response &amp; Coordination Center (NCIRCC) released a joint report on a series of targeted attacks detected in 2020. According to the <a href="https://rt-solar.ru/analytics/reports/2203/" rel="nofollow">report</a>, the attackers targeted Russian federal executive authorities.</p>
<p>While analyzing the report, <strong>Anastasia Tikhonova</strong> (Head of APT Research at Group-IB) and <strong>Dmitry Kupin</strong> (Senior Malware Analyst) noticed that they had already come across similar tools in earlier attacks.</p>
<p><strong>Chinese APTs are one of the most numerous and aggressive hacker communities.</strong> Several dozen groups conduct attacks in countries all over the world, and Russia is no exception. Hackers mostly target state agencies, industrial facilities, military contractors, and research institutes. The main objective is espionage: attackers gain access to confidential data and attempt to hide their presence for as long as possible. There have been cases when attackers successfully persisted in the victim&#8217;s network for several years.</p>
<p>Unfortunately, the SOLAR JSOC and NCIRCC report did not provide indicators of compromise, so the experts had to rely on descriptions of the functionality and screenshots of the malicious code. As a result, Group-IB&#8217;s researchers came up with some interesting conclusions about which <strong>Chinese groups could be behind the attacks against Russian federal executive authorities in 2020</strong>, what tools they used, and how their malware has evolved since.</p>
<h2>Key conclusions</h2>
<ul>
<li>The research describes Webdav-O malware detected in attacks against Russian federal executive authorities in 2020.</li>
<li>Group-IB experts detected two versions of the Webdav-O Trojan for x86 and x64 systems.</li>
<li>When comparing parts of the code, the specialists proved that the Webdav-O x64 Trojan was used in attacks against Russian federal executive authorities. The malware has existed since at least 2018.</li>
<li>Group-IB specialists established that Webdav-O has a set of commands similar to a popular Trojan called BlueTraveller (aka RemShell), which was developed in China and has been linked to the hacker group called TaskMasters.</li>
<li>Before that, Sentinel Labs released a report about malware called Mail-O, which was also identified in attacks against Russian federal executive authorities. Mail-O was deemed to be linked to the Chinese hacker group TA428.</li>
<li>Group TA428 is known to use a Trojan called Albaniiutas in their attacks. Group-IB&#8217;s analysis showed that Albaniiutas is an updated version of BlueTraveller.</li>
<li>Group-IB experts believe that either both Chinese hacker groups (TA428 and TaskMasters) attacked Russian federal executive authorities in 2020 or that there is one united Chinese hacker group made up of different units.</li>

                            <div class="blog-post-content__section--text"><h2>Starting point</h2>
<ul>
<li>As the experts put it: &#8220;<em>The report dwells on the analysis of a series of targeted attacks</em>&#8220;. Based on this information, we assumed that several hacker groups may be behind the attacks.</li>
<li>The attackers used malware that interacted with management server via the cloud service called Yandex.Disk. The malware was dubbed <strong>Webdav-O</strong>.</li>
<li>Attackers also used malicious software that accessed the cloud service Mail.ru. The malware was dubbed <strong>Mail-O</strong>.</li>
</ul>
<p>In early June 2021, analysts from the American cybersecurity company Sentinel Labs released a <a href="https://www.sentinelone.com/labs/thundercats-hack-the-fsb-your-taxes-didnt-pay-for-this-op/" target="_blank" rel="nofollow noopener">report</a> about Mail-O. The experts wrote that Mail-O is a version of the relatively well-known malware called SManager, which is used by the Chinese hacker group TA428.</p>
<p>Group-IB specialists wanted to make sure that Mail-O is loader, while Smanager and Tmanger are Remote Access Trojans (RAT). However, a part of the code overlaps in the exported functions &#8220;Entery&#8221; and &#8220;ServiceMain&#8221; of Mail-O, SManager and Tmanger, which brings us back to TA428. Moreover, hackers from TA428 have already been found to be involved in espionage against Russia, especially Russian state facilities.</p>
<p>To prove the hypothesis that TA428 was behind the attacks against Russian federal executive authorities in 2020, we decided to analyze a sample of Webdav-O. Group-IB Threat Intelligence &amp; Attribution has detected similar malicious behavior before and can now explain why we link it to a specific group. Below we provide an analysis of Webdav-O samples and highlight features that overlap with the points mentioned in the SOLAR JSOC and NCIRCC report.</p>

</div></div></div><div class="blog-post-content__section--text"><p>File &#8220;<em>1.dll</em>&#8221; is an x86 dynamic link library (DLL) that functions as a service in the system.</p>
<p>The analyzed file provides remote access to the command line shell (cmd.exe) and executes various commands originating from C2 on the compromised host.</p>
<p>The legitimate cloud service called Yandex.Disk (webdav.yandex.ru:443) is used as network infrastructure, namely C&amp;C. Network interaction with the cloud is implemented via the Webdav protocol. The authentication method is Basic.</p>
<p>The strings and configuration data are encrypted with the RC4 algorithm using the following key: { <strong>8A 4F 01 47 34 C9 75 F8 2B C8 C1 E9 D2 F3 A5 8B</strong> }. The key size is 16 bytes. The analyzed files can work with 1-7 accounts (in this case only 2 are used, but we will come back to this later).</p>

<p><picture><source srcset="https://www.group-ib.com/wp-content/uploads/1-min-4.jpg.webp" type="image/webp"><img decoding="async" class="alignnone size-full wp-image-25716 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/1-min-4.jpg" alt="functionality of the webdav-0 x86 sample" width="1500" height="1304"></picture></p>

<p>7. The file &#8220;<em>/test2/[0-9]{1,4}[0-9]{1,4}.bin</em>&#8221; is uploaded to &#8220;Yandex.Disk&#8221; (PUT). The file contains the command results. Data is encrypted using the RC4 algorithm.</p>

<h2>Blurring the boundaries</h2>
<p>Considering all the comparisons made and the information discovered about the accounts, we believe that the Chinese hacker group <strong>TaskMasters</strong> is most likely behind the attacks involving an improved version of the Webdav-O Trojan. The case of TA428, however, is still open to debate. Could both of them be behind the attack against Russian federal executive authorities in 2020? Could there be someone else involved? Or was it the same group?</p>
<p>We will continue our investigation and seek more information for analysis. Let us take a look at the report about TA428 and their new tools, in particular the Trojan called Albaniiutas, which was released by NTT Security Corporation in 2020.</p>

<p>As can be seen, this version of Webdav-O was written for a system with a different bitness and compiled later than our sample of Webdav-O x86 (2018-12 and 2018-07, respectively).</p>
<p>The legitimate cloud service Yandex.Disk (webdav.yandex.ru:443) is also used as a network infrastructure, in particular C2. Network interaction with the cloud is carried out via a Webdav protocol.</p>
<p>However, this sample supports two authentication methods instead of one in Webdav-O x86: Basic (with a username and password) and OAuth (using a token).</p>
<p>The strings and configuration data are encrypted using the RC4 algorithm with the following key: { <strong>C3 02 03 04 05 DD EE 08 09 10 11 12 1F D2 15 16</strong> }. The key size is 16 bytes. The analyzed file can work with 1-7 accounts (it works with only one in this case).</p>
<p>This sample seemed even more similar to the one described in the SOLAR JSOC and NCIRCC report: unlike our sample, it has the &#8220;-sleepuntil&#8221; function.</p>
<p>Unfortunately colleagues at SOLAR JSOC and NCIRCC did not provide any indicators of compromise, so we can only make comparisons based on screenshots and descriptions of the capabilities of their sample.</p>

<li>Based on research done by NTT Security, it can be said that TA428 has already used the malware Albaniiutas. Group-IB experts have shown that the Trojan is a new version of BlueTraveller (RemShell). As such, it can be assumed that Webdav-O is also linked to TA428.</li>

        } else {
            jQuery(sidebar).css('top', '72px');
        }
    }
    window.addEventListener('resize', positioningSidebar);
    positioningSidebar();

    if (localStorage.getItem('theme')) {
        if (localStorage.getItem('theme') == 'dark') {
            jQuery('body').addClass('theme--dark');
        } else if (localStorage.getItem('theme') == 'light') {
            jQuery('body').addClass('theme--white');
        }
    } else {
        localStorage.setItem('theme', 'dark');
        jQuery('body').addClass('theme--dark');
    }

    jQuery('.theme-toggle').click(function() {
        if (localStorage.getItem('theme') == 'dark') {
            localStorage.setItem('theme', 'light');
        } else {
            localStorage.setItem('theme', 'dark');
        }
        jQuery('body').toggleClass('no-transition');
        jQuery('body').toggleClass('theme--dark');
        jQuery('body').toggleClass('theme--white');
        setTimeout(() => {
            jQuery('body').toggleClass('no-transition');
        }, 250);
    });
    jQuery('.share-toggle').click(function() {
        jQuery('.share-toggle').toggleClass('active');
        jQuery('.share-widget').toggleClass('show');
    });
</script>
