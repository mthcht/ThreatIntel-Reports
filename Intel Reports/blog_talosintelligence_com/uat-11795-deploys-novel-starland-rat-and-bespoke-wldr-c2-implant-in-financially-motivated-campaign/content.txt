Its capabilities include&nbsp;defense evasion techniques,&nbsp;system reconnaissance,&nbsp;stealing&nbsp;browser data and cryptocurrency&nbsp;wallets, and&nbsp;a fallback C2 connection mechanism that includes a hardcoded C2 URL, as well as a&nbsp;Polygon&nbsp;Ethereum&nbsp;smart&nbsp;contract&nbsp;that serves&nbsp;as a backup. The RAT sends the reconnaissance information to the C2 to register the victim's machine and is proficient in receiving and executing intermediate payloads in several formats, including&nbsp;shellcode for 64-bit and 32-bit Windows environments, directly executing Windows shell commands, and downloading and executing malicious EXE, MSI, and DLL files.&nbsp;</p><p>Talos has&nbsp;observed&nbsp;that the threat actor has distinct infection chains for each type of intermediate payload that Starland RAT receives from the C2. The PowerShell stager is heavily obfuscated and is designed to decrypt an embedded next-stage PowerShell loader. The second-stage PowerShell loader script has capabilities for defense evasion, connects to the C2, downloads a JSON response, and processes this response to execute another embedded PowerShell payload, the WLDR agent, in the victim's machine memory. The WLDR agent is a bespoke PowerShell script that receives its C2 address through the PowerShell loader injected global variable at the time of execution. <p>The RAT also conducts Active Directory reconnaissance via the PowerShell command <code>Get-WmiObject Win32_ComputerSystem.Domain</code>. If the victim is identified as a member of Active Directory, the RAT executes the following commands to collect information about domain structure, domain controllers, and the victim’s domain privileges:&nbsp;</p>
<!--kg-card-begin: html-->
<pre>
whoami && systeminfo && net user {USERNAME} /dom && nltest /dclist
</pre>
<!--kg-card-end: html-->
<p>For workgroup-only hosts, it executes the <code>whoami /all</code> command. The reconnaissance data collected are staged by the RAT for inclusion during the victim machine registration to the primary C2 domain hardcoded in the RAT program. It also captures a screenshot of the victim machine's desktop, saves it as a PNG in the RAT’s working directory, generates a&nbsp;Base64-encoded string for the PNG file in memory, stages it alongside the reconnaissance data, and deletes the PNG file from the disk.&nbsp;</p><p>Additionally, it gathers the victim’s cryptocurrency assets information by&nbsp;enumerating&nbsp;the desktop&nbsp;cryptocurrency&nbsp;wallets and browser extension wallets, checking for the presence of over 40 cryptocurrency&nbsp;wallets.&nbsp;The collected data&nbsp;is also staged alongside the reconnaissance data and the&nbsp;Base64-encoded screenshot (PNG)&nbsp;data. The&nbsp;RAT consolidates all collected data into a single JSON file, XOR encrypts it with the 5-byte key “helo1”,&nbsp;Base64-encodes it, and sends it to the primary C2 through&nbsp;an <code>HTTP POST</code> request using the HTTP user-Agent:</p><p><code>Mozilla/5.0 (Windows NT 10.0; Win64; x64)&nbsp;AppleWebKit/537.36 (KHTML, like Gecko) Chrome/138.0.0.0 Safari/537.36</code>.&nbsp;&nbsp;</p><p>If the primary C2 registration fails, the RAT enables a blockchain-anchored fallback mechanism.
