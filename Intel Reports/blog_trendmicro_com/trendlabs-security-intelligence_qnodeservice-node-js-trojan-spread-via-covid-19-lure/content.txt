	<p class="article-details__description">QNodeService is a new, undetected malware sample written in Node.js, which is an unusual choice for malware authors. The malware has functionality that enables it to download/upload/execute files, steal credentials from Chrome/Firefox browsers, and perform file management, among other things.</p>

		<div>
			<p>We recently noticed <a href="https://twitter.com/malwrhunterteam/status/1255840193745215489">a Twitter post</a> by MalwareHunterTeam that showed a Java downloader with a low detection rate. Its name, “Company PLP_Tax relief due to Covid-19 outbreak CI+PL.jar”, suggests it may have been used in a Covid-19-themed phishing campaign. Running this file led to the download of a new, undetected malware sample written in Node.js; this trojan is dubbed as “QNodeService”.</p>
<p>The use of Node.js is an unusual choice for malware authors writing commodity malware, as it is primarily designed for web server development, and would not be pre-installed on machines likely to be targeted. However, the use of an uncommon platform may have helped evade detection by antivirus software.</p>
<p>The malware has functionality that enables it to download/upload/execute files, steal credentials from Chrome/Firefox browsers, and perform file management, among other things. It targets Windows systems, but its design and certain pieces of code suggest cross-platform compatibility may be a future goal.</p>
<p>The infection begins with a Java downloader which, in addition to downloading Node.js, downloads the following files: “wizard.js”, and “qnodejs-win32-ia32.js” or “qnodejs-win32-x64.js”. We analyzed these components to learn more about their behavior.</p>
<h3><span class="body-subhead-title">Analysis of Java Downloader</span></h3>
<p>The sample mentioned above, “Company PLP_Tax relief due to Covid-19 outbreak CI+PL.jar”, serving as the Java downloader, has been obfuscated with the Allatori obfuscator. Allatori adds junk code and obfuscates strings to make analysis more difficult. We deobfuscated the code to be able to start the analysis.</p>

		</div>
	

</div>

It then runs this file using Node.js with multiple command line arguments, including the URL of the <a href="https://www.trendmicro.com/vinfo/tmr/?/us/security/definition/command-and-control-server">C&amp;C server</a>:</p>

<h3><span class="body-subhead-title">Analysis of wizard.js</span></h3>
<p>The wizard.js file is an obfuscated Javascript (Node.js) file. It is responsible for persistence (by creating a “Run” registry key entry) and for downloading another payload depending on the system architecture.</p>
<p>It creates a file named “qnodejs-&lt;8 digit hex number&gt;.cmd” which contains the arguments used to launch the file. This is invoked by the registry key entry it creates at “HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run”. It also checks whether it’s running on a Windows platform, suggesting the authors may have cross-platform compatibility in mind.</p>

<p>A file named qnodejs-win32-ia32.js or qnodejs-win32-x64.js is downloaded based on the system architecture (whether the OS is 64-bit or 32-bit).</p>
<p>The files contain an embedded “node_modules” folder with libraries for Node.js, which is extracted upon execution. Unlike the Javascript code itself, these libraries are architecture-specific, which is the reason separate files are distributed based on system architecture. Screenshots below are based on the “win32-ia32” variant from 2020-04-30.</p>
<p>We named this malware “QNodeService,” since this seems to be the name used internally, as indicated by the code that validates command line arguments.</p>

</tr><tr><td width="198">info/get-user-home</td>
<td width="426">Gets the user profile directory (os.homedir())</td>
</tr><tr><td width="198">info/set-label</td>
<td width="426">Sets label</td>
</tr><tr><td width="198">file-manager/absolute</td>
<td width="426">Gets the full path of a file</td>
</tr><tr><td width="198">file-manager/execute</td>
<td width="426">Executes a file with the command ‘start “” /B &lt;file&gt;’</td>
</tr><tr><td width="198">file-manager/delete</td>
<td width="426">Removes a file or files on the system (accepts globs, using “rimraf” library)</td>
</tr><tr><td width="198">file-manager/forward-access</td>
<td width="426">Generates URL and token to use for the “http-forward” command (see below)</td>
</tr><tr><td width="198">file-manager/list</td>
<td width="426">Lists files in specific directories</td>
</tr><tr><td width="198">file-manager/mkdirs</td>
<td width="426">Creates a directory on the system</td>
</tr><tr><td width="198">file-manager/write</td>
<td width="426">Writes a file sent from the C&amp;C SERVER onto the system</td>
</tr><tr><td width="198">http-forward</td>
<td width="426">HTTP requests sent to a specific URL at the C&amp;C are routed to the infected machine (see below)</td>
</tr><tr><td width="198">password-recovery/applications</td>

</tr><tr><td width="198">password-recovery/recover</td>

</tr></tbody></table>
<p>On May 5th, the malware was updated with three additional commands:</p>
<table cellpadding="1" cellspacing="0" border="1" width="100%">
<tbody><tr><td width="126">info/get-tags</td>
<td width="498">Returns list of tags set by “add-tag” command</td>
</tr><tr><td width="126">info/add-tag</td>
<td width="498">Adds tags</td>
</tr><tr><td width="126">info/remove-tag</td>
<td width="498">Removes tags</td>
</tr></tbody></table>
<p>Of particular note is the http-forward command, which allows an attacker to download a file without directly connecting to the victim machine, as shown below in figures 13-16. However, a valid request path and access token are required to access files on the machine. The C&amp;C server must first send “file-manager/forward-access” to generate the URL and access token to use for the http-forward command later<br />
.<br />
</p>

		</div>

			<p>The malware responds with the forwarding URL and access token. Then, a third party who has been given the URL and access token could send an HTTP request to the C&amp;C server to retrieve files from the victim machine without directly connecting to it.</p>

		</div>

    <div class="richText">
	
    


	
		<div>
			<p>The C&amp;C server forwards the HTTP request to the malware on the victim machine using the http-forward command. If the access token is correct, the malware sends the file’s contents back to the C&amp;C server, which in turn sends the contents back to the attacker in its HTTP response, enabling remote download.</p>

		</div>
