<h3 class="wp-block-heading"><strong>scDbg.exe</strong></h3>



<p>We then move to a shellcode emulator called <a href="http://sandsprite.com/blogs/index.php?uid=7&amp;pid=152" target="_blank" rel="noreferrer noopener">scDbg.exe</a>. We can load the dumped binary in there and feed it the offset position and to see if any sort of decoded shellcode appears.</p>



<figure class="wp-block-image size-large"><img data-attachment-id="494" data-permalink="https://clickallthethings.wordpress.com/lokibot08/" data-orig-file="https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot08.png" data-orig-size="685,645" data-comments-opened="1" data-image-meta="{&quot;aperture&quot;:&quot;0&quot;,&quot;credit&quot;:&quot;&quot;,&quot;camera&quot;:&quot;&quot;,&quot;caption&quot;:&quot;&quot;,&quot;created_timestamp&quot;:&quot;0&quot;,&quot;copyright&quot;:&quot;&quot;,&quot;focal_length&quot;:&quot;0&quot;,&quot;iso&quot;:&quot;0&quot;,&quot;shutter_speed&quot;:&quot;0&quot;,&quot;title&quot;:&quot;&quot;,&quot;orientation&quot;:&quot;0&quot;}" data-image-title="lokibot08" data-image-description="" data-image-caption="" data-medium-file="https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot08.png?w=300" data-large-file="https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot08.png?w=656" loading="lazy" width="685" height="645" src="https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot08.png?w=685" alt="" class="wp-image-494" srcset="https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot08.png 685w, https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot08.png?w=150 150w, https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot08.png?w=300 300w" sizes="(max-width: 685px) 100vw, 685px" /></figure>



<p>And it does! Note that it dumped it to a file called <em>oledump.unpack</em>. However, notice how the unpacked information isn&#8217;t very informative. But that last line says, &#8220;Change found at 402438&#8230;&#8221;. We can use another tool called to <a rel="noreferrer noopener" href="https://blog.didierstevens.com/2015/10/14/cut-bytes-py/" target="_blank">cut-bytes.py</a> to look at the <em>oledump.unpack</em> from that point. Notice strings such as LoadLibraryW&#8230; ExpandEnvironmentStringsW&#8230; APPDATA\vbc.exe&#8230; htp://frndgreen and so on.</p>



<figure class="wp-block-image size-large"><img data-attachment-id="496" data-permalink="https://clickallthethings.wordpress.com/lokibot09/" data-orig-file="https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot09.png" data-orig-size="645,386" data-comments-opened="1" data-image-meta="{&quot;aperture&quot;:&quot;0&quot;,&quot;credit&quot;:&quot;&quot;,&quot;camera&quot;:&quot;&quot;,&quot;caption&quot;:&quot;&quot;,&quot;created_timestamp&quot;:&quot;0&quot;,&quot;copyright&quot;:&quot;&quot;,&quot;focal_length&quot;:&quot;0&quot;,&quot;iso&quot;:&quot;0&quot;,&quot;shutter_speed&quot;:&quot;0&quot;,&quot;title&quot;:&quot;&quot;,&quot;orientation&quot;:&quot;0&quot;}" data-image-title="lokibot09" data-image-description="" data-image-caption="" data-medium-file="https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot09.png?w=300" data-large-file="https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot09.png?w=645" loading="lazy" width="645" height="386" src="https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot09.png?w=645" alt="" class="wp-image-496" srcset="https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot09.png 645w, https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot09.png?w=150 150w, https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot09.png?w=300 300w" sizes="(max-width: 645px) 100vw, 645px" /></figure>



<p>But can we get this output in a little more&#8230; readable form? Yes, we can do with <em>scDbg.exe</em> again. First, let&#8217;s cut out only the bytes necessary.</p>



<figure class="wp-block-image size-large"><img data-attachment-id="500" data-permalink="https://clickallthethings.wordpress.com/lokibot11/" data-orig-file="https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot11.png" data-orig-size="526,34" data-comments-opened="1" data-image-meta="{&quot;aperture&quot;:&quot;0&quot;,&quot;credit&quot;:&quot;&quot;,&quot;camera&quot;:&quot;&quot;,&quot;caption&quot;:&quot;&quot;,&quot;created_timestamp&quot;:&quot;0&quot;,&quot;copyright&quot;:&quot;&quot;,&quot;focal_length&quot;:&quot;0&quot;,&quot;iso&quot;:&quot;0&quot;,&quot;shutter_speed&quot;:&quot;0&quot;,&quot;title&quot;:&quot;&quot;,&quot;orientation&quot;:&quot;0&quot;}" data-image-title="lokibot11" data-image-description="" data-image-caption="" data-medium-file="https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot11.png?w=300" data-large-file="https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot11.png?w=526" loading="lazy" width="526" height="34" src="https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot11.png?w=526" alt="" class="wp-image-500" srcset="https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot11.png 526w, https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot11.png?w=150 150w, https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot11.png?w=300 300w" sizes="(max-width: 526px) 100vw, 526px" /></figure>



<p>Using <em>oledump-cut.unpack</em>, we do run into a problem when we toss it into <em>scDbg.exe</em>. We don&#8217;t see anything beyond ExpandEnvironmentStringsW.</p>



<figure class="wp-block-image size-large"><img data-attachment-id="499" data-permalink="https://clickallthethings.wordpress.com/lokibot10/" data-orig-file="https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot10.png" data-orig-size="819,174" data-comments-opened="1" data-image-meta="{&quot;aperture&quot;:&quot;0&quot;,&quot;credit&quot;:&quot;&quot;,&quot;camera&quot;:&quot;&quot;,&quot;caption&quot;:&quot;&quot;,&quot;created_timestamp&quot;:&quot;0&quot;,&quot;copyright&quot;:&quot;&quot;,&quot;focal_length&quot;:&quot;0&quot;,&quot;iso&quot;:&quot;0&quot;,&quot;shutter_speed&quot;:&quot;0&quot;,&quot;title&quot;:&quot;&quot;,&quot;orientation&quot;:&quot;0&quot;}" data-image-title="lokibot10" data-image-description="" data-image-caption="" data-medium-file="https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot10.png?w=300" data-large-file="https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot10.png?w=656" loading="lazy" width="819" height="174" src="https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot10.png?w=819" alt="" class="wp-image-499" srcset="https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot10.png 819w, https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot10.png?w=150 150w, https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot10.png?w=300 300w, https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot10.png?w=768 768w" sizes="(max-width: 819px) 100vw, 819px" /></figure>



<p>The <a rel="noreferrer noopener" href="https://isc.sans.edu/forums/diary/VelvetSweatshop+Maldocs+Shellcode+Analysis/24776/" target="_blank"><strong>SANS blog post</strong></a> referenced at the beginning shows how to deal with this. It turns out that <em>scDbg.exe</em> does not hook ExpandEnvironmentStringsW. But it does hook ExpandEnvironmentStringsA. We can then try patching the .unpack file by overwriting the StringsW with StringsA. Save your change and then toss it back into <em>scDbg.exe</em> like we tried above.</p>



<figure class="wp-block-image size-large"><img data-attachment-id="502" data-permalink="https://clickallthethings.wordpress.com/lokibot12/" data-orig-file="https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot12.png" data-orig-size="555,172" data-comments-opened="1" data-image-meta="{&quot;aperture&quot;:&quot;0&quot;,&quot;credit&quot;:&quot;&quot;,&quot;camera&quot;:&quot;&quot;,&quot;caption&quot;:&quot;&quot;,&quot;created_timestamp&quot;:&quot;0&quot;,&quot;copyright&quot;:&quot;&quot;,&quot;focal_length&quot;:&quot;0&quot;,&quot;iso&quot;:&quot;0&quot;,&quot;shutter_speed&quot;:&quot;0&quot;,&quot;title&quot;:&quot;&quot;,&quot;orientation&quot;:&quot;0&quot;}" data-image-title="lokibot12" data-image-description="" data-image-caption="" data-medium-file="https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot12.png?w=300" data-large-file="https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot12.png?w=555" loading="lazy" width="555" height="172" src="https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot12.png?w=555" alt="" class="wp-image-502" srcset="https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot12.png 555w, https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot12.png?w=150 150w, https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot12.png?w=300 300w" sizes="(max-width: 555px) 100vw, 555px" /></figure>



<p>Another option is to overwrite that character directly from the command line. Looking at the hex editor above, we can see that we are at offset 0x77. We can add that to the starting point in <em>scDbg.exe</em> like so:</p>



<figure class="wp-block-image size-large"><img data-attachment-id="503" data-permalink="https://clickallthethings.wordpress.com/lokibot13/" data-orig-file="https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot13.png" data-orig-size="949,261" data-comments-opened="1" data-image-meta="{&quot;aperture&quot;:&quot;0&quot;,&quot;credit&quot;:&quot;&quot;,&quot;camera&quot;:&quot;&quot;,&quot;caption&quot;:&quot;&quot;,&quot;created_timestamp&quot;:&quot;0&quot;,&quot;copyright&quot;:&quot;&quot;,&quot;focal_length&quot;:&quot;0&quot;,&quot;iso&quot;:&quot;0&quot;,&quot;shutter_speed&quot;:&quot;0&quot;,&quot;title&quot;:&quot;&quot;,&quot;orientation&quot;:&quot;0&quot;}" data-image-title="lokibot13" data-image-description="" data-image-caption="" data-medium-file="https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot13.png?w=300" data-large-file="https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot13.png?w=656" loading="lazy" width="949" height="261" src="https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot13.png?w=949" alt="" class="wp-image-503" srcset="https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot13.png 949w, https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot13.png?w=150 150w, https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot13.png?w=300 300w, https://clickallthethings.wordpress.com/wp-content/uploads/2020/03/lokibot13.png?w=768 768w" sizes="(max-width: 949px) 100vw, 949px" /></figure>



<p>We can now see everything in a much clearer format and it looks like it&#8217;s <a href="https://app.any.run/tasks/db864efd-35b3-4e91-9e84-c6149dbfd4d7" target="_blank" rel="noreferrer noopener">downloading Lokibot</a>.<br><br>Thanks for reading!</p>

		return fetches[handle];

	function runExtraScript(handle, type, index) {
		const id = 'wp-enqueue-dynamic-script:' + handle + ':' + type + ':' + (index + 1);
		const template = document.getElementById(id);
		if (!template) {
			return Promise.reject();
		}

		const script = document.createElement( 'script' );
