		<div class="entry-meta">
			<span class="posted-on"><a href="https://clickallthethings.wordpress.com/2021/02/02/xlsb-analyzing-a-microsoft-excel-binary-spreadsheet/" rel="bookmark"><time class="entry-date published" datetime="2021-02-02T21:15:39-06:00">February 2, 2021</time></a></span><span class="byline"><span class="author vcard"><span class="sep"> ~ </span><a class="url fn n" href="https://clickallthethings.wordpress.com/author/arndtjames/">Jamie</a></span></span>					</div><!-- .entry-meta -->

	<div class="entry-content">
		
<p>The <a rel="noreferrer noopener" href="https://twitter.com/InQuest" target="_blank">@InQuest</a> crew has been putting some unusual documents out on the Twitters and I thought I&#8217;d take a closer look at one of them. And as ALWAYS, new documents are never that straight forward to analyze. Attackers always put a twist on what has already been done.</p>



<p>In this case, we&#8217;ve got an .xlsb file, XLM code, hidden sheets, protected sheets, and the ever-so-sneaky-hiding-in-plain-sight white font.<br><br>Here&#8217;s the doc: <a rel="noreferrer noopener" href="https://app.any.run/tasks/47e1c347-664c-4ada-9655-1724387e859e/#" target="_blank"><strong>https://app.any.run/tasks/47e1c347-664c-4ada-9655-1724387e859e/#</strong></a></p>



<h2 class="wp-block-heading"><strong>Microsoft Excel Binary Spreadsheets (.xlsb)</strong></h2>



<p>I can&#8217;t say that I&#8217;ve ever seen these until now. They open and function like any other spreadsheet. The difference is under the hood. They store the spreadsheet using a binary format (BIFF12) rather than the typical .xlsx or .xls. This means that .xlsb files are usually bigger as they&#8217;re not compressed. Extremely complicated spreadsheets (ones with lots of formulas, charts, and shapes) can benefit from this file format as they may save and load much faster.</p>



<p>But this format means that some of our normal analysis tools do not work. For example, oledump can&#8217;t find any OLE objects in the file.</p>



<figure class="wp-block-image size-large"><a href="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image.png"><img data-attachment-id="951" data-permalink="https://clickallthethings.wordpress.com/image-22/" data-orig-file="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image.png" data-orig-size="503,41" data-comments-opened="1" data-image-meta="{&quot;aperture&quot;:&quot;0&quot;,&quot;credit&quot;:&quot;&quot;,&quot;camera&quot;:&quot;&quot;,&quot;caption&quot;:&quot;&quot;,&quot;created_timestamp&quot;:&quot;0&quot;,&quot;copyright&quot;:&quot;&quot;,&quot;focal_length&quot;:&quot;0&quot;,&quot;iso&quot;:&quot;0&quot;,&quot;shutter_speed&quot;:&quot;0&quot;,&quot;title&quot;:&quot;&quot;,&quot;orientation&quot;:&quot;0&quot;}" data-image-title="image" data-image-description="" data-image-caption="" data-medium-file="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image.png?w=300" data-large-file="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image.png?w=503" width="503" height="41" src="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image.png?w=503" alt="" class="wp-image-951" srcset="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image.png 503w, https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image.png?w=150 150w, https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image.png?w=300 300w" sizes="(max-width: 503px) 100vw, 503px" /></a></figure>



<p>OfficeMalScanner will expand the document if you use the <em>inflate</em> option. However, the output doesn&#8217;t show the normal vbaproject.bin. There&#8217;s a ton of other files that are NOT vbaproject.bin. (<em>Of course</em>, there&#8217;s no vbaproject.bin. Oledump.py didn&#8217;t find any macros, right?)</p>



<figure class="wp-block-image size-large"><a href="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-1.png"><img data-attachment-id="953" data-permalink="https://clickallthethings.wordpress.com/image-1-2/" data-orig-file="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-1.png" data-orig-size="643,918" data-comments-opened="1" data-image-meta="{&quot;aperture&quot;:&quot;0&quot;,&quot;credit&quot;:&quot;&quot;,&quot;camera&quot;:&quot;&quot;,&quot;caption&quot;:&quot;&quot;,&quot;created_timestamp&quot;:&quot;0&quot;,&quot;copyright&quot;:&quot;&quot;,&quot;focal_length&quot;:&quot;0&quot;,&quot;iso&quot;:&quot;0&quot;,&quot;shutter_speed&quot;:&quot;0&quot;,&quot;title&quot;:&quot;&quot;,&quot;orientation&quot;:&quot;0&quot;}" data-image-title="image-1" data-image-description="" data-image-caption="" data-medium-file="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-1.png?w=210" data-large-file="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-1.png?w=643" width="643" height="918" src="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-1.png?w=643" alt="" class="wp-image-953" srcset="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-1.png 643w, https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-1.png?w=105 105w, https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-1.png?w=210 210w" sizes="(max-width: 643px) 100vw, 643px" /></a></figure>



<p>In hindsight, all of these .bin files make sense as this is an .xlsb file. It certainly didn&#8217;t make sense the first time I cracked it open, though.</p>

<h2 class="wp-block-heading"><strong>Unprotecting the sheets</strong></h2>



<p>All hope is not lost. We can bypass the protected sheets if we save the document in a different macro-enabled format like .xlsm. This will also change the worksheets from .bin files to .xml files. This will be important in a moment.</p>



<figure class="wp-block-image size-large"><a href="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-7.png"><img data-attachment-id="966" data-permalink="https://clickallthethings.wordpress.com/image-7-2/" data-orig-file="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-7.png" data-orig-size="585,47" data-comments-opened="1" data-image-meta="{&quot;aperture&quot;:&quot;0&quot;,&quot;credit&quot;:&quot;&quot;,&quot;camera&quot;:&quot;&quot;,&quot;caption&quot;:&quot;&quot;,&quot;created_timestamp&quot;:&quot;0&quot;,&quot;copyright&quot;:&quot;&quot;,&quot;focal_length&quot;:&quot;0&quot;,&quot;iso&quot;:&quot;0&quot;,&quot;shutter_speed&quot;:&quot;0&quot;,&quot;title&quot;:&quot;&quot;,&quot;orientation&quot;:&quot;0&quot;}" data-image-title="image-7" data-image-description="" data-image-caption="" data-medium-file="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-7.png?w=300" data-large-file="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-7.png?w=585" loading="lazy" width="585" height="47" src="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-7.png?w=585" alt="" class="wp-image-966" srcset="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-7.png 585w, https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-7.png?w=150 150w, https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-7.png?w=300 300w" sizes="(max-width: 585px) 100vw, 585px" /></a></figure>



<figure class="wp-block-image size-large"><a href="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-8.png"><img data-attachment-id="968" data-permalink="https://clickallthethings.wordpress.com/image-8-2/" data-orig-file="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-8.png" data-orig-size="342,422" data-comments-opened="1" data-image-meta="{&quot;aperture&quot;:&quot;0&quot;,&quot;credit&quot;:&quot;&quot;,&quot;camera&quot;:&quot;&quot;,&quot;caption&quot;:&quot;&quot;,&quot;created_timestamp&quot;:&quot;0&quot;,&quot;copyright&quot;:&quot;&quot;,&quot;focal_length&quot;:&quot;0&quot;,&quot;iso&quot;:&quot;0&quot;,&quot;shutter_speed&quot;:&quot;0&quot;,&quot;title&quot;:&quot;&quot;,&quot;orientation&quot;:&quot;0&quot;}" data-image-title="image-8" data-image-description="" data-image-caption="" data-medium-file="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-8.png?w=243" data-large-file="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-8.png?w=342" loading="lazy" width="342" height="422" src="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-8.png?w=342" alt="" class="wp-image-968" srcset="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-8.png 342w, https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-8.png?w=122 122w, https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-8.png?w=243 243w" sizes="(max-width: 342px) 100vw, 342px" /></a></figure>



<p>Change your newly created .xlsm file to a .zip and navigate your way into <em>xl\worksheets</em> and <em>xl\macrosheets</em> to find .xml sheets. We will un-protect these sheets by taking out a section called <em>sheetProtection</em>. Delete everything from <em>&lt;sheetProtection</em> to its trailing <em>/&gt;</em>, including the two &lt; &gt; characters, and then save the .xml. Delete sheet protection wherever you find it.</p>



<figure class="wp-block-image size-large"><a href="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-9.png"><img data-attachment-id="970" data-permalink="https://clickallthethings.wordpress.com/image-9-2/" data-orig-file="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-9.png" data-orig-size="1102,77" data-comments-opened="1" data-image-meta="{&quot;aperture&quot;:&quot;0&quot;,&quot;credit&quot;:&quot;&quot;,&quot;camera&quot;:&quot;&quot;,&quot;caption&quot;:&quot;&quot;,&quot;created_timestamp&quot;:&quot;0&quot;,&quot;copyright&quot;:&quot;&quot;,&quot;focal_length&quot;:&quot;0&quot;,&quot;iso&quot;:&quot;0&quot;,&quot;shutter_speed&quot;:&quot;0&quot;,&quot;title&quot;:&quot;&quot;,&quot;orientation&quot;:&quot;0&quot;}" data-image-title="image-9" data-image-description="" data-image-caption="" data-medium-file="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-9.png?w=300" data-large-file="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-9.png?w=656" loading="lazy" width="1024" height="71" src="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-9.png?w=1024" alt="" class="wp-image-970" srcset="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-9.png?w=1024 1024w, https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-9.png?w=1016 1016w, https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-9.png?w=150 150w, https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-9.png?w=300 300w, https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-9.png?w=768 768w, https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-9.png 1102w" sizes="(max-width: 1024px) 100vw, 1024px" /></a></figure>



<p>You&#8217;ll have to drag the various .xml files out of the .zip file, edit them, and then copy them back into their appropriate locations. Finally, change the file from .zip to .xlsm.</p>



<h2 class="wp-block-heading"><strong>Analyzing the XLM</strong></h2>



<p>Now that the sheets are unprotected, we can finally get rid of that white font and see the XLM. Auto_open is pointing to Sheet11!A1. I color-coded the extraneous lines and analyzed the three important =CALL() commands.</p>



<figure class="wp-block-image size-large"><a href="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-11.png"><img data-attachment-id="975" data-permalink="https://clickallthethings.wordpress.com/image-11-2/" data-orig-file="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-11.png" data-orig-size="1253,605" data-comments-opened="1" data-image-meta="{&quot;aperture&quot;:&quot;0&quot;,&quot;credit&quot;:&quot;&quot;,&quot;camera&quot;:&quot;&quot;,&quot;caption&quot;:&quot;&quot;,&quot;created_timestamp&quot;:&quot;0&quot;,&quot;copyright&quot;:&quot;&quot;,&quot;focal_length&quot;:&quot;0&quot;,&quot;iso&quot;:&quot;0&quot;,&quot;shutter_speed&quot;:&quot;0&quot;,&quot;title&quot;:&quot;&quot;,&quot;orientation&quot;:&quot;0&quot;}" data-image-title="image-11" data-image-description="" data-image-caption="" data-medium-file="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-11.png?w=300" data-large-file="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-11.png?w=656" loading="lazy" width="1024" height="494" src="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-11.png?w=1024" alt="" class="wp-image-975" srcset="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-11.png?w=1024 1024w, https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-11.png?w=150 150w, https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-11.png?w=300 300w, https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-11.png?w=768 768w, https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-11.png 1253w" sizes="(max-width: 1024px) 100vw, 1024px" /></a></figure>



<p>Ultimately, it downloads a .dll to C:\ProgramData\fps\ and registers that .dll via rundll32.exe.</p>



<p>As a bonus, Excel does some of the XLM concatenating for us making analysis easier. Here&#8217;s an example from Sheet1. You can see that cell L3 contains =CONCATENATE(Sheet&#8230;), but the cell itself shows the result.</p>



<figure class="wp-block-image size-large"><a href="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-12.png"><img data-attachment-id="977" data-permalink="https://clickallthethings.wordpress.com/image-12-2/" data-orig-file="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-12.png" data-orig-size="577,180" data-comments-opened="1" data-image-meta="{&quot;aperture&quot;:&quot;0&quot;,&quot;credit&quot;:&quot;&quot;,&quot;camera&quot;:&quot;&quot;,&quot;caption&quot;:&quot;&quot;,&quot;created_timestamp&quot;:&quot;0&quot;,&quot;copyright&quot;:&quot;&quot;,&quot;focal_length&quot;:&quot;0&quot;,&quot;iso&quot;:&quot;0&quot;,&quot;shutter_speed&quot;:&quot;0&quot;,&quot;title&quot;:&quot;&quot;,&quot;orientation&quot;:&quot;0&quot;}" data-image-title="image-12" data-image-description="" data-image-caption="" data-medium-file="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-12.png?w=300" data-large-file="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-12.png?w=577" loading="lazy" width="577" height="180" src="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-12.png?w=577" alt="" class="wp-image-977" srcset="https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-12.png 577w, https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-12.png?w=150 150w, https://clickallthethings.wordpress.com/wp-content/uploads/2021/02/image-12.png?w=300 300w" sizes="(max-width: 577px) 100vw, 577px" /></a></figure>
