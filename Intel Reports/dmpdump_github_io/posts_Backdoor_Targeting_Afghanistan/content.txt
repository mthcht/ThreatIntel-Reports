title="656 words" > <em>3 min</em> read</span></div></div></div></header><div class="content"><p>On August 29, 2026, a ZIP file containing an executable named <code class="language-plaintext highlighter-rouge">Special Job Opportunities and Recruitment Information in Various Ministries of Afghanistan.exe</code> and a DLL named <code class="language-plaintext highlighter-rouge">dgxi.dll</code> was uploaded to Virus Total from Afghanistan. The executable name and the upload origin suggest the likely targeting of an Afghanistan government agency. As expected, the executable is a legitimate executable (<code class="language-plaintext highlighter-rouge">ApplicationFrameHost.exe</code>, a Windows executable), and the DLL is a malicious library that is side-loaded by the renamed executable.</p><p><a href="/assets/images/bdoorafg/zipcontent.png" class="popup img-link shimmer"><img src="/assets/images/bdoorafg/zipcontent.png" alt="Zip Content" loading="lazy"></a> <em>Figure 1: Zip content.</em></p><p>A review of the side-loaded DLL revealed a targeted backdoor using the following C2: <code class="language-plaintext highlighter-rouge">185.235.137[.]35:9000</code>.</p><h2 id="backdoor-overview"><span class="me-2">Backdoor Overview</span><a href="#backdoor-overview" class="anchor text-muted"><i class="fas fa-hashtag"></i></a></h2><p>The DLL establishes persistence by making a copy of the renamed ApplicationFrameHost.exe executable using <code class="language-plaintext highlighter-rouge">GetModuleFileNameW</code> to retrieve its own path and copying itself and the accompanying DLL to <code class="language-plaintext highlighter-rouge">%AppData%\Microsoft\ApplicationHost\</code>. The executable is copied as <code class="language-plaintext highlighter-rouge">ApplicationHost.exe</code>. Persistent execution is established using the common registry run key <code class="language-plaintext highlighter-rouge">HKCU\Software\Microsoft\Windows\CurrentVersion\Run</code>.</p><p><a href="/assets/images/bdoorafg/persist2.png" class="popup img-link shimmer"><img src="/assets/images/bdoorafg/persist2.png" alt="Persist2" loading="lazy"></a> <em>Figure 2: Registry run key.</em></p><p>The main backdoor logic is implemented in an exported function named <code class="language-plaintext highlighter-rouge">DXGIDeclareAdapterRemovalSupport()</code>. First, this function implements anti-debugging and anti-analysis checks:</p><ul><li>It detects debuggers with <code class="language-plaintext highlighter-rouge">CheckRemoteDebuggerPresent()</code> and <code class="language-plaintext highlighter-rouge">OutputDebugStringA()</code> timing.<li>It detects the presence of common analysis tools: ida.exe, ida64.exe, x64dbg.exe, x32dbg.exe, windbg.exe, ollydbg.exe<li>It performs timing and integrity checks.</ul><p><a href="/assets/images/bdoorafg/antia1.png" class="popup img-link shimmer"><img src="/assets/images/bdoorafg/antia1.png" alt="antia1" loading="lazy"></a> <em>Figure 3: Sample anti-debugging.</em></p><p><a href="/assets/images/bdoorafg/antia2.png" class="popup img-link shimmer"><img src="/assets/images/bdoorafg/antia2.png" alt="antia2" loading="lazy"></a> <em>Figure 4: Sample anti-analysis.</em></p><p>The backdoor checks if it is being executed with the <code class="language-plaintext highlighter-rouge">--startup</code> argument. If it is not, it drops and opens an embedded decoy PDF named <code class="language-plaintext highlighter-rouge">Document_&lt;4digits&gt;.pdf</code> under <code class="language-plaintext highlighter-rouge">AppData\Roaming\</code>. The <code class="language-plaintext highlighter-rouge">--startup</code> argument is likely used by the malware developer to avoid dropping the PDF with each test run.</p><p><a href="/assets/images/bdoorafg/embeddedpdf.png" class="popup img-link shimmer"><img src="/assets/images/bdoorafg/embeddedpdf.png" alt="embedded pdf" loading="lazy"></a> <em>Figure 5: Argument check and execution of embedded PDF.</em></p><p>The embedded dropped PDF is in Pashto and is titled <code class="language-plaintext highlighter-rouge">ریاست الوزراء - د دفتر لوی ریاست - د مسؤلینو لست </code> (machine translation: Office of the Prime Minister - The Office of the Director General - List of Officials ). The PDF contains a list of individual names and their corresponding position name, salary, department, and phone number.</p><p><a href="/assets/images/bdoorafg/decoypdf.png" class="popup img-link shimmer"><img src="/assets/images/bdoorafg/decoypdf.png" alt="decoypdf" loading="lazy"></a> <em>Figure 6: Decoy PDF.</em></p><p>The backdoor configuration is XOR encrypted with key <code class="language-plaintext highlighter-rouge">thisscert23$SecretKey206</code>. Upon decryption, we obtain the following C2 infrastructure: <code class="language-plaintext highlighter-rouge">185.235.137.35:9000</code>. This IP address is owned by HZ Hosting Ltd.</p><p><a href="/assets/images/bdoorafg/encryptedconfig.png" class="popup img-link shimmer"><img src="/assets/images/bdoorafg/encryptedconfig.png" alt="encryptedconfig" loading="lazy"></a> <em>Figure 7: Encrypted configuration.</em></p><p><a href="/assets/images/bdoorafg/ipinfo.png" class="popup img-link shimmer"><img src="/assets/images/bdoorafg/ipinfo.png" alt="ipinfo" loading="lazy"></a> <em>Figure 8: Encrypted configuration.</em></p><p>After decrypting the C2 configuration, the backdoor initiates a connection loop to the C2. The first connection sends a registration beacon with basic system information. The following victim machine details are sent in JSON format:</p><ul><li><code class="language-plaintext highlighter-rouge">clientId</code>: Uses the MachineGuid from HKLM\SOFTWARE\Microsoft\Cryptography.<li><code class="language-plaintext highlighter-rouge">machineName</code>: Uses <code class="language-plaintext highlighter-rouge">GetComputerNameA</code>.<li><code class="language-plaintext highlighter-rouge">osVersion</code>: Uses <code class="language-plaintext highlighter-rouge">RtlGetVersion</code> from ntdll.dll.<li><code class="language-plaintext highlighter-rouge">clientVersion</code>: Uses a hard-coded value of <code class="language-plaintext highlighter-rouge">1.0.0</code>, suggesting this is one of the first releases of this backdoor.</ul><p>Sample registration beacon:</p><div class="language-json highlighter-rouge"><div class="code-header"> <span data-label-text="JSON"><i class="fas fa-code fa-fw small"></i></span> <button aria-label="copy" data-title-succeed="Copied!"><i class="far fa-clipboard"></i></button></div><div class="highlight"><code><table class="rouge-table"><tbody><tr><td class="rouge-gutter gl"><pre class="lineno">1
