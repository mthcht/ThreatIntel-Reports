class="row flex-grow-1"><main aria-label="Main Content" class="col-12 col-lg-11 col-xl-9 px-md-4"><article class="px-1"><header><h1 data-toc-skip>Linux Backdoor Targeting iKuai Routers</h1><div class="post-meta text-muted"> <span> Posted <time data-ts="1782864000" data-df="ll" data-bs-toggle="tooltip" data-bs-placement="bottom" > Jul 1, 2026 </time> </span><div class="d-flex justify-content-between"> <span> By <em> <a href="https://github.com/dmpdump">dmpdump</a> </em> </span><div> <span class="readtime" data-bs-toggle="tooltip" data-bs-placement="bottom" title="1022 words" > <em>5 min</em> read</span></div></div></div></header><div class="content"><p>On July 1, 2026, <a href="https://x.com/malwrhunterteam">MalwareHunterTeam</a> shared an ELF uploaded to VirusTotal from Japan with 0 detection. After a quick code inspection, it was evident that the ELF was a backdoor targeting specific Linux-based devices.</p><ul><li>File name: <code class="language-plaintext highlighter-rouge">libjson_script.so.0</code><li>SHA2: <code class="language-plaintext highlighter-rouge">4e6276cc400b3b9e9616d04474b64a8fa0c35375b9673ab41a92a6d5bce72d8d</code><li>First uploaded to VirusTotal from Japan on 2026-06-08</ul><p><a href="/assets/images/ikuai/vt.png" class="popup img-link shimmer"><img src="/assets/images/ikuai/vt.png" alt="sshot" loading="lazy"></a></p><p>The ELF impersonates the legitimate <code class="language-plaintext highlighter-rouge">libjson_script.so</code>, which is part of the OpenWrt Project, specifically part of <a href="https://github.com/openwrt/libubox/blob/master/json_script.c">libubox</a>. This impersonation is relevant because, as we will see next, the backdoor seems to target the Chinese <a href="https://www.ikuai8.com/en/shop-products.php?productType=router">iKuai</a> routers.</p><h1 id="backdoor-overview">Backdoor Overview</h1><p>The main routine of the backdoor performs the following actions:</p><ul><li>After executing <code class="language-plaintext highlighter-rouge">acquire_lock()</code> to ensure there is only one instance of the backdoor running, it proceeds to decrypt the configuration.<li>Creates the <code class="language-plaintext highlighter-rouge">/var/tmp</code> directory and changes directories to it.<li>Initializes an MbedTLS AES-GCM context with a 256-bit key. The backdoor uses a statically-linked MbedTLS library.<li>Initializes an mbedTLS HTTPS client without certificate validation.<li>Initializes a task scheduler thread for tasks sent from the C2.<li>Attempts to get a <code class="language-plaintext highlighter-rouge">GWID</code>, or creates and sets a new one if none can be found. This <code class="language-plaintext highlighter-rouge">GWID</code> is likely a <code class="language-plaintext highlighter-rouge">Gateway ID</code> associated with iKuai routers.<li>Gets the process ID.<li>Enters an infinite loop that beacons to the C2 to receive tasks. The loop has a sleep interval which is obtained from the C2. A default sleep time of 3600 seconds (1 hour) is set by default as part of the configuration decryption.</ul><p><a href="/assets/images/ikuai/mainroutine.png" class="popup img-link shimmer"><img src="/assets/images/ikuai/mainroutine.png" alt="sshot" loading="lazy"></a></p><h2 id="configuration-decryption"><span class="me-2">Configuration decryption</span><a href="#configuration-decryption" class="anchor text-muted"><i class="fas fa-hashtag"></i></a></h2><p>The backdoor uses an XOR decryption algorithm with a single byte key to decrypt configuration strings (with a function named <code class="language-plaintext highlighter-rouge">xor_decode</code>). The byte used as key is <code class="language-plaintext highlighter-rouge">0x5A</code>.</p><p><a href="/assets/images/ikuai/xor.png" class="popup img-link shimmer"><img src="/assets/images/ikuai/xor.png" alt="sshot" loading="lazy"></a></p><p>The strings decrypted as part of the configuration decryption are:</p><ul><li><code class="language-plaintext highlighter-rouge">https://47.80.111[.]129:7380</code>, the C2 address.<li><code class="language-plaintext highlighter-rouge">Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/125.0.0.0 Safari/537.36</code>, the User Agent string used by the backdoor.<li><code class="language-plaintext highlighter-rouge">/cdn-cgi/trace</code>, a C2 URI.<li><code class="language-plaintext highlighter-rouge">/cdn-cgi/bm/cv/result</code>, a C2 URI.<li><code class="language-plaintext highlighter-rouge">/cdn-cgi/challenge-platform/generate/ov1</code>, a C2 URI.<li><code class="language-plaintext highlighter-rouge">en-US,en;q=0.9</code>, the Accept-Language value for the backdoor HTTP request.<li><code class="language-plaintext highlighter-rouge">application/octet-stream</code>, the Content-Type value for the backdoor HTTP request.<li><code class="language-plaintext highlighter-rouge">https://raw.githubusercontent.com/pnzzuv09911cast11/googlehub/refs/heads/main/readme.txt</code>, this Github repository is no longer available, and it does not seem to be used by the backdoor.<li><code class="language-plaintext highlighter-rouge">3600</code>, the default sleep interval in seconds for the C2 communications.<li><code class="language-plaintext highlighter-rouge">8fc4cdd44e1d2baee2d8915c3a3651f452da877565a3ee4d43fb44ee28a4ee8c</code>, an AES-256 key used for subsequent encryption and decryption.</ul><p><a href="/assets/images/ikuai/configdecrypt.png" class="popup img-link shimmer"><img src="/assets/images/ikuai/configdecrypt.png" alt="sshot" loading="lazy"></a></p><h2 id="obtaining-the-device-gwid"><span class="me-2">Obtaining the Device GWID</span><a href="#obtaining-the-device-gwid" class="anchor text-muted"><i class="fas fa-hashtag"></i></a></h2><p>The <code class="language-plaintext highlighter-rouge">get_gwid()</code> function is interesting because it indicates that the backdoor is targeting a specific custom Linux version. This function attempts to get the <code class="language-plaintext highlighter-rouge">GWID</code>, or <code class="language-plaintext highlighter-rouge">Gateway ID</code> of the device by checking a <code class="language-plaintext highlighter-rouge">GWID=</code> field in <code class="language-plaintext highlighter-rouge">/etc/release</code>, checking <code class="language-plaintext highlighter-rouge">/usr/share/misc/.runlevel.cache</code> for a previously generated ID, or, if needed, creating a random <code class="language-plaintext highlighter-rouge">GWID</code> value and writing it to a newly created <code class="language-plaintext highlighter-rouge">/usr/share/misc/.runlevel.cache</code> file.</p><p><a href="/assets/images/ikuai/getgwid.png" class="popup img-link shimmer"><img src="/assets/images/ikuai/getgwid.png" alt="sshot" loading="lazy"></a></p><p>The <code class="language-plaintext highlighter-rouge">GWID</code> is a value that is referenced in the official <a href="https://www.ikuai8.com/support/cjwt/xs/2019-07-26-05-38-00.html">iKuai documentation</a>.</p><h2 id="c2-task-loop"><span class="me-2">C2 Task Loop</span><a href="#c2-task-loop" class="anchor text-muted"><i class="fas fa-hashtag"></i></a></h2><p>The main C2 task loop first obtains the hostname, the local IP address (excluding localhost), and once again it attempts to access <code class="language-plaintext highlighter-rouge">/etc/release</code>, this time to obtain the <code class="language-plaintext highlighter-rouge">VERSTRING=</code> field.</p><p><a href="/assets/images/ikuai/verstring.png" class="popup img-link shimmer"><img src="/assets/images/ikuai/verstring.png" alt="sshot" loading="lazy"></a></p><p>Reviewing <a href="https://web.archive.org/web/20260514000343/https://forum.naixi.net/thread-11395-1-1.html">Chinese forums</a>, I found that this field is present in the <code class="language-plaintext highlighter-rouge">release</code> file of iKuai routers, providing additional evidence that these routers are being targeted.</p><p><a href="/assets/images/ikuai/release.png" class="popup img-link shimmer"><img src="/assets/images/ikuai/release.png" alt="sshot" loading="lazy"></a></p><p>A JSON object is then created using the embedded cJSON library and profiling information is added to it. This information includes GWID, architecture, hostname, pid, current working directory, a version set to 1.4, ip address information and the verstring information from the <code class="language-plaintext highlighter-rouge">release</code> file. This information is AES-encrypted before it is sent to <code class="language-plaintext highlighter-rouge">https://47.80.111[.]129:7380/cdn-cgi/trace</code>.</p><p><a href="/assets/images/ikuai/send.png" class="popup img-link shimmer"><img src="/assets/images/ikuai/send.png" alt="sshot" loading="lazy"></a></p><p>The backdoor receives an encrypted JSON from the C2. After decrypting and parsing the C2 response, it retrieves the top-level “sleep” and “tasks” members. It then iterates over each object in the “tasks” array, extracting the “id” and “command” fields for processing.</p><p><a href="/assets/images/ikuai/jsondecrypt.png" class="popup img-link shimmer"><img src="/assets/images/ikuai/jsondecrypt.png" alt="sshot" loading="lazy"></a></p><p>The backdoor supports the following 6 commands:</p><div class="table-wrapper"><table><thead><tr><th>Command<th>Action<tbody><tr><td>__sched__<td>Downloads payload from a url and executes as a ‘scheduled task’<tr><td>__sched_cancel__<td>Cancels a scheduled task<tr><td>__uu__<td>Downloads, executes, and deletes an ELF<tr><td>__dd__<td>Reads a file, base64 encodes it, and exfiltrates it<tr><td>cd<td>Changes directory<tr><td>exec_cmd_async (default)<td>Executes shell commands</table></div><h3 id="__sched__"><span class="me-2">__sched__</span><a href="#__sched__" class="anchor text-muted"><i class="fas fa-hashtag"></i></a></h3><p>The <code class="language-plaintext highlighter-rouge">__sched__</code> command receives data to download and execute additional payload as a file. This command will get a download url, a destination directory, execution time and execution repetition data to the previously initialized <code class="language-plaintext highlighter-rouge">sched_start</code> thread. The <code class="language-plaintext highlighter-rouge">sched_start</code> thread will parse the data and will download, decrypt, and execute payload as a forked process. The default destination location for the downloaded payload is <code class="language-plaintext highlighter-rouge">/var/tmp/.&lt;random hex&gt;</code>.</p><p><a href="/assets/images/ikuai/schtask1.png" class="popup img-link shimmer"><img src="/assets/images/ikuai/schtask1.png" alt="sshot" loading="lazy"></a></p><p><a href="/assets/images/ikuai/schtask2.png" class="popup img-link shimmer"><img src="/assets/images/ikuai/schtask2.png" alt="sshot" loading="lazy"></a></p><h3 id="__sched_cancel__"><span class="me-2">__sched_cancel__</span><a href="#__sched_cancel__" class="anchor text-muted"><i class="fas fa-hashtag"></i></a></h3><p>This command dequeues a task based on a task id.</p><h3 id="__uu__"><span class="me-2">__uu__</span><a href="#__uu__" class="anchor text-muted"><i class="fas fa-hashtag"></i></a></h3><p>This command runs <code class="language-plaintext highlighter-rouge">exec_elf</code>. The code in this command mirrors the ELF download and execution code used in the <code class="language-plaintext highlighter-rouge">__sched__</code> command. The endpoint used to download payload with this command is <code class="language-plaintext highlighter-rouge">https://47.80.111[.]129:7380/cdn-cgi/challenge-platform/generate/ov1</code>.</p><p><a href="/assets/images/ikuai/uu.png" class="popup img-link shimmer"><img src="/assets/images/ikuai/uu.png" alt="sshot" loading="lazy"></a></p><h3 id="__dd__"><span class="me-2">__dd__</span><a href="#__dd__" class="anchor text-muted"><i class="fas fa-hashtag"></i></a></h3><p>This command reads files, base64 encodes the content and sends them back to the C2. This function is designed to exfiltrate small files, as it has a limit of 512 KB.</p><p><a href="/assets/images/ikuai/dd.png" class="popup img-link shimmer"><img src="/assets/images/ikuai/dd.png" alt="sshot" loading="lazy"></a></p><h3 id="cd"><span class="me-2">cd</span><a href="#cd" class="anchor text-muted"><i class="fas fa-hashtag"></i></a></h3><p>This command changes directories via chdir().</p><h3 id="exec_cmd_async"><span class="me-2">exec_cmd_async</span><a href="#exec_cmd_async" class="anchor text-muted"><i class="fas fa-hashtag"></i></a></h3><p>The default action in the C2 tasking loop is <code class="language-plaintext highlighter-rouge">exec_cmd_async</code>. This command runs shell commands (with ‘/bin/sh -c’) and pipes the result back to the C2.</p><p><a href="/assets/images/ikuai/execcmd.png" class="popup img-link shimmer"><img src="/assets/images/ikuai/execcmd.png" alt="sshot" loading="lazy"></a></p><h2 id="report-function"><span class="me-2">Report function</span><a href="#report-function" class="anchor text-muted"><i class="fas fa-hashtag"></i></a></h2><p>All the results from the executed commands are sent back to the C2 using the <code class="language-plaintext highlighter-rouge">report_result</code> function. The results are sent as an encrypted JSON to the following endpoint: <code class="language-plaintext highlighter-rouge">https://47.80.111[.]129:7380/cdn-cgi/bm/cv/result</code>.</p><p><a href="/assets/images/ikuai/report.png" class="popup img-link shimmer"><img src="/assets/images/ikuai/report.png" alt="sshot" loading="lazy"></a></p><h2 id="hunting-for-additional-samples"><span class="me-2">Hunting for Additional Samples</span><a href="#hunting-for-additional-samples" class="anchor text-muted"><i class="fas fa-hashtag"></i></a></h2><p>I created a deliberately broad Yara rule to see if I could find any other samples of this backdoor, but I could not find any. To the best of my knowledge, this backdoor seems to be rare. If you have seen it before (e.g. reported somewhere else), feel free to reach out and I’ll happily add references to previous work, or to your findings.</p><div class="language-plaintext highlighter-rouge"><div class="code-header"> <span data-label-text="Plaintext"><i class="fas fa-code fa-fw small"></i></span> <button aria-label="copy" data-title-succeed="Copied!"><i class="far fa-clipboard"></i></button></div><div class="highlight"><code><table class="rouge-table"><tbody><tr><td class="rouge-gutter gl"><pre class="lineno">1
