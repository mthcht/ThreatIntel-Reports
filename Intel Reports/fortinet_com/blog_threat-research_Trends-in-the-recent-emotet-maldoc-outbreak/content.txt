<div class="cmp cmp-text aem-GridColumn aem-GridColumn--default--12">
  <p>Emotet is a malware<span> family that steals sensitive and private information from victims&#39; computers. The malware has infected more than a million devices and is considered one of the most dangerous threats of the decade.</span><br />
</p>
<p>In addition to analyzing threats, <a href="https://www.fortinet.com/fortiguard/labs?utm_source&#61;blog&amp;utm_campaign&#61;fortiguardlabs">FortiGuard Labs</a> also focuses on how malware spreads. We have observed that the recent Emotet outbreak is being spread through a variety of malicious Microsoft Office files, or maldocs, attached to <a href="https://www.fortinet.com/resources/cyberglossary/phishing?utm_source&#61;blog&amp;utm_medium&#61;blog&amp;utm_campaign&#61;phishing">phishing emails</a>. Once a victim opens the attached document, a VBA Macro or Excel 4.0 Macro is used to execute malicious code that downloads and runs the Emotet malware.</p>
<p>In this blog, we will focus on what these malicious documents look like and how they drop Emotet malware onto a victim&#39;s local disk. We will first look at the samples captured in this campaign and then examine their propagation trends.</p>
<p style="	text-align: left;
"><b>Affected Platforms: </b>Microsoft Windows<br />
<b>Impacted Users: </b>Windows users<br />
<b>Impact:</b> Controls victim&#39;s device and collects sensitive information<br />
<b>Severity Level:</b> Critical</p>
<h2>Phishing Emails with Malicious Attachment</h2>
<p>The recent Emotet outbreak uses phishing emails combined with <a href="https://www.fortinet.com/resources/cyberglossary/social-engineering?utm_source&#61;blog&amp;utm_campaign&#61;social-engineering">social engineering</a> to trick victims into loading the <a href="https://www.fortinet.com/resources/cyberglossary/malware?utm_source&#61;blog&amp;utm_campaign&#61;malware">malware</a> onto their devices. These emails often include &#34;Re:&#34; or &#34;Fw:&#34; in the subject line, as shown in Figure 1 and 2, to disguise the email as a reply or forwarded message to help convince the target that the email is legitimate.</p>

<p>We captured five different samples connected with this Emotet campaign that contain differences in the macro code and execution flow. For identification purposes, we have given each sample a tag name, which is from when the sample first appeared. The tag name consists of two parts, the year prefix and a suffix with the week of the month, connected by an underscore.</p>
<p>The first sample appeared in the third week of November 2021 and its tag name is &#34;2021_NovW3&#34;. It is an Excel file or Word document with VBA Macro. The second is an Excel file using Excel 4.0 Macro. It appeared in the fourth week of November 2021 with the tag name &#34;2021_NovW4&#34;. The third sample is a Word document with a VBA Macro with the tag name of &#34;2021_DecW2&#34;. The fourth sample is an Excel file with an Excel 4.0 Macro. It’s tag name is &#34;2021_DecW4&#34;. The fifth sample is an Excel file with a VBA Macro and the tag name of &#34;2022_FebW2&#34;.</p>

  <h2>Attack Trends in the Latest Emotet Campaign</h2>
<p>Emotet was first discovered in 2014 and continues to attack victims. The latest Emotet campaign broke out in mid-November of 2021 and is spread using malicious documents attached to phishing emails. <a href="https://www.fortinet.com/fortiguard/labs?utm_source&#61;blog&amp;utm_campaign&#61;fortiguardlabs">FortiGuard Labs</a> has been tracking these malicious documents as well as the number of variants used to evade detection in this campaign. Figure 15 shows the daily timestamps for Emotet maldocs used from mid-November 2021 to March 2022. All the samples mentioned in the previous section emerged during this period.</p>
<p>The first attack appeared on November 16, 2021. After that, it spread different types of malicious documents every week until the Christmas break. Once the break ended on January 12, it surged with more frequent and consistent attacks, releasing a large number and variety of malicious documents. From the end of February through the end of March, it turned to using the same type of malicious document (2021_NovW4) with different phishing picture templates. After February 28th, new malicious documents appeared every day except for weekends, with only one or two days off.</p>

Using an Excel file is more flexible because its macro type can be VBA Macro, Excel 4.0 Macro, or both. One of the benefits is that Excel 4.0 Macro, an older technique, bypasses antivirus detection more easily than a VBA Macro.</p>
<p>As shown in the timeline, Emotet malware has primarily been spread since March 2022 through the malicious Excel file &#34;2021_NovW4&#34;, which uses the Excel 4.0 Macro. We believe that the authors prefer to use Excel files with Excel 4.0 Macro for malicious documents to reduce detection by antivirus engines.</p>
<h2>Fortinet Protections</h2>
<p>Fortinet customers are protected from this malware by FortiGuard’s <a href="https://www.fortinet.com/support-and-training/support-services/fortiguard-security-subscriptions/web-filtering.html?utm_source&#61;blog&amp;utm_campaign&#61;web-filtering">Web Filtering</a>, AntiVirus, <a href="https://www.fortinet.com/products/email-security/fortimail.html?utm_source&#61;blog&amp;utm_campaign&#61;fortimail-main-page">FortiMail</a>, <a href="https://www.fortinet.com/products/endpoint-security/forticlient.html?utm_source&#61;blog&amp;utm_campaign&#61;endpoint-web-page">FortiClient</a>, <a href="https://www.fortinet.com/products/endpoint-security/fortiedr.html?utm_source&#61;blog&amp;utm_campaign&#61;fortiedr">FortiEDR</a>, and CDR (content disarm and reconstruction) services:</p>
<p>The malicious macros inside the Excel sample can be disarmed by the FortiGuard CDR (content disarm and reconstruction) service.</p>
<p><a href="https://www.fortinet.com/products/endpoint-security/fortiedr.html?utm_source&#61;blog&amp;utm_campaign&#61;fortiedr">FortiEDR</a> detects the Word and Excel files and Emotet dll file as malicious based on their behavior.</p>
<p>Fortinet customers are protected from these malicious documents and malware by FortiGuard AntiVirus, which is included in <a href="https://www.fortinet.com/products/email-security/fortimail.html?utm_source&#61;blog&amp;utm_campaign&#61;fortimail-main-page">FortiMail</a>. It detects all malicious macro file types, including Excel 4.0 Macro samples.</p>
