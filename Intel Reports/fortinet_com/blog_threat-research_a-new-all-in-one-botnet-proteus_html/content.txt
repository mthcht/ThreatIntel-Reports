<p><strong>Introduction</strong></p>

<p>The ART team at Fortinet has discovered a new malware named Proteus, a multifunctional botnet written in .NET that appears to be a proxy, coin miner, e-commerce merchant account checker, and keylogger. This particular botnet is downloaded by the Andromeda botnet. The handful of malicious features densely packed in this new malware also includes the ability to drop other malware. We have compiled its main features in this brief analysis.</p>

<p><strong>Data Encryption</strong></p>

<p>All C&amp;C communication is encrypted with a symmetrical algorithm. All strings used in this botnet are also encrypted using the same algorithm. Part of the encrypted <em>hostname</em> string is shown below:</p>

<p><img alt="" src="/content/dam/fortinet-blog/new-images/uploads/a-new-all-in-one-botnet-proteus-2253.jpg" data-style="width: 445px; height: 13px;"/></p>

<p align="center">Figure 1 Partial Encrypted Hostname</p>

<p>And the encrypted <em>hostname</em> is: <u>http://prot{removed}twork.ml/</u> which is used as the C&amp;C domain.</p>

<p>A simple decryption Algorithm is provided below:</p>

<p><img alt="" src="/content/dam/fortinet-blog/new-images/uploads/a-new-all-in-one-botnet-proteus-2254.jpg" data-style="width: 550px; height: 263px;"/></p>

<p align="center">Figure 2 Decryption Algorithm</p>

<p><strong>Preparation&nbsp; </strong></p>

<p>The sample arrives obfuscated, drops a copy of itself in the %AppData% folder as <em>chrome.exe</em>, and executes the copy. It then creates a hardcoded mutex to ensure there is only one instance of itself running.&nbsp;</p>

<p>&nbsp;<img alt="" src="/content/dam/fortinet-blog/new-images/uploads/a-new-all-in-one-botnet-proteus-2255.jpg" data-style="width: 375px; height: 14px;"/></p>

<p align="center">Figure 3 Mutex Name</p>

<p>In order to register the botnet with the C&amp;C server, it sends an initial registration message with several pieces of information regarding the infected machine. The packet for registering the bot takes the format as below:</p>

<div data-style="background:#eee;border:1px solid #ccc;padding:5px 10px;"><code>{&quot;m&quot;:&quot;&lt;Encrypted MachineName&gt;&quot;, &quot;o&quot;:&quot;&lt;Encrypted OperationSystem&gt;&quot;, &quot;v&quot;:&quot;&lt;Encrypted BotVersion&gt;&quot;}</code></div>

<p><img alt="" src="/content/dam/fortinet-blog/new-images/uploads/a-new-all-in-one-botnet-proteus-2256.jpg" data-style="width: 495px; height: 24px;"/></p>

<p align="center">Figure 4 Bot Registering Function</p>

<p>The fingerprint consists of the processor, BIOS and baseboard information of the infected machine, as shown below.</p>

<p><img alt="" src="/content/dam/fortinet-blog/new-images/uploads/a-new-all-in-one-botnet-proteus-2257.jpg" data-style="width: 452px; height: 90px;"/></p>

<p align="center">Figure 5 Generating Fingerprint</p>

<p>The bot comes with a hardcoded default fingerprint, as shown below. However, it appears that the default fingerprint is always overwritten by the above-mentioned newly generated fingerprint, which is a unique identifier for the infected machine.&nbsp; The fingerprint is included in the HTTP header in the <em>authorization</em> field.&nbsp;</p>

<p><img alt="" src="/content/dam/fortinet-blog/new-images/uploads/a-new-all-in-one-botnet-proteus-2258.jpg" data-style="width: 402px; height: 14px;"/></p>

<p align="center">Figure 6 Default Fingerprint</p>

<p>MachineName is retrieved by calling the Win32 API GetComputerName, OperatingSystem is the OS architecture x64 or x86. The BotVersion is obtained from the assembly version that the code is executing in:&nbsp;&nbsp;&nbsp;&nbsp;</p>

<p><img alt="" src="/content/dam/fortinet-blog/new-images/uploads/a-new-all-in-one-botnet-proteus-2259.jpg" data-style="width: 209px; height: 36px;"/></p>

<p align="center">Figure 7 Bot version</p>

<p>The C&amp;C server responses with an encrypted string that reads &ldquo;successful.&rdquo; Then the bot plays ping pong with the server to make sure it&rsquo;s live in order to carry out the rest of its malicious actions.</p>

<p><img alt="" src="/content/dam/fortinet-blog/new-images/uploads/a-new-all-in-one-botnet-proteus-2260.jpg" data-style="width: 452px; height: 210px;"/></p>

<p align="center">Figure 8 Ping Pong</p>

<p><strong>Features &amp; Tasks</strong></p>

<p>Proteus creates six threads for different tasks, as follows:</p>

<table border="1" cellpadding="0" cellspacing="0" width="100%">
	<tbody>
		<tr>
			<td data-style="width:134px;">
			<p><strong><em>Task</em></strong></p>
			</td>
			<td data-style="width:418px;">
			<p><strong><em>Description</em></strong></p>
			</td>
		</tr>
		<tr>
			<td data-style="width:134px;">
			<p><em>SocksTask</em></p>
			</td>
			<td data-style="width:418px;">
			<p>creates a socket and sets up port forwarding</p>
			</td>
		</tr>
		<tr>
			<td data-style="width:134px;">
			<p><em>MiningTask</em></p>
			</td>
			<td data-style="width:418px;">
			<p>appears to use SHA256 miner for mining digital currency *</p>
			</td>
		</tr>
		<tr>
			<td data-style="width:134px;">
			<p><em>EMiningTask</em></p>
			</td>
			<td data-style="width:418px;">
			<p>appears to use CPUMiner and ZCashMiner for mining digital currency *</p>
			</td>
		</tr>
		<tr>
			<td data-style="width:134px;">
			<p><em>CheckerTask</em></p>
			</td>
			<td data-style="width:418px;">
			<p>validates given accounts</p>
			</td>
		</tr>
		<tr>
			<td data-style="width:134px;">
			<p><em>CommandsTask</em></p>
			</td>
			<td data-style="width:418px;">
			<p>kills current process or downloads and executes an executable on request</p>
			</td>
		</tr>
		<tr>
			<td data-style="width:134px;">
			<p><em>LoggerTask</em></p>
			</td>
			<td data-style="width:418px;">
			<p>sets up keylogger</p>
			</td>
		</tr>
	</tbody>
</table>

<p align="center">Table 1 Tasks and Descriptions</p>

<p data-style="margin-left:.25in;">* <em>The bot verifies with the server during runtime to determine which miner to use for mining digital currency such as Bitcoin.</em>&nbsp;</p>

<p><img alt="" src="/content/dam/fortinet-blog/new-images/uploads/a-new-all-in-one-botnet-proteus-2261.jpg" data-style="width: 446px; height: 12px;"/></p>

<p align="center">Figure 9 Check Module for MiningTask</p>

<p><img alt="" src="/content/dam/fortinet-blog/new-images/uploads/a-new-all-in-one-botnet-proteus-2262.jpg" data-style="width: 401px; height: 22px;"/></p>

<p align="center">Figure 10 Check Modules for EMiningTask</p>

<p>For <em>SocksTask</em>, <em>MiningTask</em>, <em>EMiningTask</em> and <em>LoggerTask</em>, the bot first sends a CheckModule message by providing its program fingerprint and corresponding module name to the C&amp;C server.&nbsp; The server then sends a command back to the bot, indicating whether or not the bot should proceed with the requested task.&nbsp;</p>

<p>For <em>CheckerTask</em>, the bot first requests an account from the C&amp;C server. If the server replies with an account to the bot, the bot will proceed to check the given account on some well-known e-commerce websites including eBay, Amazon, and Netflix.&nbsp; Some of the websites are on German (.de) domains.&nbsp; Similarly, for <em>CommandsTask</em>, the bot first requests a command from the server and then executes the command if it is valid.&nbsp;</p>

<p><strong>Conclusion </strong></p>

<p>The Proteus botnet has a combination of features including coin miner, proxy server, keylogger, and many more. It is also capable of downloading and executing a file. All of this in one botnet may be even more harmful than one might first think, as it could download anything and execute it in the infected host. Our team will continue to monitor this botnet family and provide more information as it comes to light.</p>
