    <div class="cmp cmp-text aem-GridColumn aem-GridColumn--default--12">
  <p>The TrickBot malware family has been live for several years, mainly focused on stealing victim’s online banking information. In new samples recently collected by FortiGuard Labs, we found a new TrickBot variant, with a new module pwgrab, which attempt to steal credentials, autofill data, history and so on from browsers as well as several software applications. I did a deep analysis on this pwgrab module, and in this blog I will explain how it works on a victim’s system. </p>
<p><b>TrickBot downloaded by opening an excel file</b></p>
<p>The new TrickBot variant is spread by an Excel file (originally named “Sep_report.xls”) using a malicious Macro VBS code that is executed when the victim opens the file in Microsoft Excel. We captured this sample on October 19<sup>th</sup>, 2018. Figure 1 shows that “Sep_report.xls” is opened in Microsoft Excel where it requests that the victim enable the embedded Macro by clicking on the “Enable Content” button.</p>


</div>

<div class="cmp cmp-text aem-GridColumn aem-GridColumn--default--12">
  <p>The VBA code is password protected for viewing. To analyze the code, I manually modified the protected flag to bypass the password protection.</p>
<p>The VBA code starts with the function “Workbook_Open”, which is called automatically when the Excel file is opened. It then reads data from Text control, which is encoded Powershell code. In Figure 2 you can see part of the decoded Powershell code.</p>

<p><b>Report Credentials</b></p>
<p>Trickbot has many C&amp;C commands. I have talked about these commands in detail in my <a href="https://www.fortinet.com/blog/threat-research/deep-analysis-of-the-online-banking-botnet-trickbot.html">previous blog</a>.</p>
<p>In module “pwgrab32”, however, I observed that it has new command numbers: 81 and 83.</p>
<p>    Command 81 is for reporting grabbed credentials of Browsers, FTP clients, and Outlook.</p>
<p>    Command 83 is for reporting grabbed form autofill information from Google Chrome.</p>
<p>It uses HTTP POST method to report the plain text credentials to the C&amp;C server.</p>
<p>The POST URI format is like this:</p>
<p>    <i>POST /[group tag]/[Client_ID]/[Command number]/</i></p>
<p>The body part is the grabbed credentials or form autofill information in plain text.</p>
<p>    “group tag” is “auto1”.</p>
<p>    “Client_ID” is generated with the computer name, Windows version and random string.</p>

<p><b>How to remove this malware:</b></p>
<p>1) Open Task Scheduler and go to Task Scheduler(Local) -&gt; Task Scheduler Library<b></b></p>
<p>2) Select the item named “Msnetcs”, press the Delete key, and then click Yes.<b></b></p>
<p>3) Restart your system and delete the entire folder of %AppData%\VsCard.</p>
