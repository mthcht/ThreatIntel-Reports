    <div class="cmp cmp-text aem-GridColumn aem-GridColumn--default--12">
  <p>Two weeks ago, FortiGuard Labs spotted a malicious document with the politically themed file name “Draft PH-US Dialogue on Cyber Security.doc”. This document takes advantage of the vulnerability <a href="https://www.fortinet.com/blog/threat-research/cve-2017-11826-exploited-in-the-wild-with-politically-themed-rtf-document.html">CVE-2017-11882</a>. Upon successful exploitation, it drops a malware in the victim’s %temp% directory.</p>
<p>Our analysis of this malware shows that it belongs to <i>Hussarini</i>, also known as <i>Sarhust</i>, a backdoor family that has been used actively in APT attacks targeting countries in the ASEAN region since 2014.</p>
<p>According to reports, the Philippines is the <a href="http://news.abs-cbn.com/business/08/15/14/philippines-most-exposed-cyber-attack-threats-report">most exposed</a> country in ASEAN to the cyberattacks known as advanced persistent threats, or APTs. After several massive data breaches in 2016, the Philippines started to <a href="http://cnnphilippines.com/business/2017/05/04/Govt-to-invest-P2B-for-national-cybersecurity.html">invest</a> in beefing up their defences against cyberattacks. In spite of these investments, however, the Philippines is still among the <a href="http://business.inquirer.net/250163/ph-among-prone-cybersecurity-attacks">most prone</a> countries to be targeted by these sorts of APT attacks.</p>
<p><b>Exploit Document</b></p>
<p>Our analysis begins with the exploit document named “Draft PH-US Dialogue on Cyber Security.doc” that takes advantage of the CVE-2017-11882 vulnerability. Upon successful exploitation, the malicious document file drops two files in the %Temp% directory.</p>
<p>·       Outllib.dll</p>
<p>·       OutExtra.exe</p>
<p>OutExtra.exe is a signed legitimate application from Microsoft named finder.exe. This file is part of the Microsoft Office suite and can be used to find keywords within Outlook data files. However, in this attack, this file is used to load the <i>Hussarini</i> backdoor via DLL hijacking.</p>
<p>DLL hijacking is a technique used by some APT malware in which instead of the legitimate application (.exe) loading the benign DLL, the application is tricked into loading a DLL containing malicious code. Using this technique, a malware can evade the Host Intrusion Prevention System (HIPS) of security programs that monitor the behaviors of executed files. Most HIPS tools whitelist signed or trusted files, thereby excluding any malware loaded using DLL hijacking by those signed files from any behavior monitoring. In the context of this attack, OutExtra.exe is a signed legitimate application; however, it is tricked into loading a malware file that is disguised as the legitimate Outllib.dll file.</p>
<p><b>Decoy Document</b></p>
<p>To avoid suspicion by the victim, the exploit downloads a decoy document from the legitimate-seeming hxxp://157.52.167.71:29317/office/word/2003/ph2/philip.varilla. During our analysis, though, the download link for the decoy document was already down.</p>
<p>However, taking a look at the URI, we spotted several clues as to where/from whom the hacker possibly wants the user to believe the document came from. First is the “ph2,” which could mean “ph” for Philippines and “2” as its second directory of decoy documents. And second is “philip.varilla”. A quick Google search on this name led us to the Service Director of the Philippines Department of Information and Communications Technology (DICT), who has the same name. DICT is the agency responsible for the planning, development, and promotion of the Philippines’ information and communications technology including cybersecurity.</p>
<p><b>Hussarini</b></p>
<p>In fact, the file Outllib.dll is actually the <i>Hussarini</i> backdoor, a DLL which exports functions containing the malicious code. When the file OutExtra.exe is executed, some of these functions are called, effectively executing its malicious code.</p>

  <p>There is also a big difference in the file size. The original Outllib.dll has a file size range of 4-8 MB, depending on the version, but the fake file only ranges from 40-50 KB. One of the reasons for this big difference in file size is that only one of the exported functions of the backdoor DLL contains the malicious code. All of the others are just RETN functions that do nothing.</p>
<p>Thus, we will focus our analysis on the function that contains the backdoor code named <i>RenInitInstance&#64;12.</i> This function begins by instantiating a class initializing the setting of the bot. It then creates two concurrent threads taking the created object as its parameter.</p>


</div>

<div class="cmp cmp-text aem-GridColumn aem-GridColumn--default--12">
  <p>The first thread acts as a client thread that is responsible for communicating with the command and control (C&amp;C) server and listening for commands. The response is then parsed and passed to the second thread that acts as the worker. The worker thread executes the commands and reports the result to the client thread.</p>
<p>Before communicating with its command and control (C&amp;C), the malware saves a <i>ServerID</i> in the registry with a randomly generated value. This ID identifies this bot in the botnet. </p>


</div>

<div class="cmp cmp-text aem-GridColumn aem-GridColumn--default--12">
  <p><b>C&amp;C Communication</b></p>
<p>Interestingly, there’s a private IP address 10.1.0.105 in the code that may have been used as a test C&amp;C server. This IP address is replaced at runtime with the real C&amp;C publicdfaph.publicvm.com.</p>
<p>When communicating with its C&amp;C, Hussarini uses its own custom protocol encoded with base64, which is sent over HTTP. Due to the high-level nature of the code and limited analysis time, we were not able to identify all the fields of the protocol, but knowing some important parts is enough to understand how the communication works.</p>


</div>

The connection disruption could be because the attacker detected that the bot was being analysed and blocked our analysis environment from communicating with the C&amp;C, or just that the machine is not interesting to performing further attacks. The received data was enclosed with the tag &lt;COMMAND&gt;&lt;/COMMAND&gt;, encoded with base64, and still follows the same data structure of the protocol when decoded. The commands are pretty obvious since its strings are not encrypted after decoding the data.</p>

<p>·       cache.txt</p>
<p>·       cache.txt.cfg</p>
<p>The second command contains commands for the Command Prompt (cmd.exe).</p>

<div class="cmp cmp-text aem-GridColumn aem-GridColumn--default--12">
  <p>The description of the commands written on cache.txt are as follows:</p>
<p>·       <i>systeminfo – </i>get the systeminfo of the computer<i></i></p>
<p>·       <i>arp –a </i>– view the mapping of IP addresses to MAC addresses<i></i></p>
<p>·       <i>ipconfig /all</i> – display all current TCP/IP network configuration values<i></i></p>
<p>·       <i>netstat -ano - </i> displays protocols statistics and current TCP/IP network connections<i></i></p>
<p>·       <i>tasklist -v – </i>list of apps and services with their Process ID (PID) for all task running<i></i></p>
<p>·       <i>net start – </i>starts any of the various services that are running<i></i></p>
<p>·       <i>net view – </i>displays the other computers that are visible on the network<i></i></p>
<p>·       <i>dir &#34;c:\users&#34; /o-d – </i>displays all users<i></i></p>
<p> </p>
<p>After sending these <i>cmd</i> commands, the C&amp;C stopped responding. It could be that the hacker decided to block the connection after seeing the result of these commands.</p>
<p>Based on its code, this malware is capable of executing the following commands from the hacker:</p>
<p>·       Create, read, write files</p>
<p>·       Download and execute files/components</p>
<p>·       Launch remote shell using cmd.exe</p>
<p>While other APT backdoors have more capabilities, such as keylogging, taking screen shots, etc., Hussarini only has few, including the capability to download and execute files/components. However, its functionality can be extended by the hacker. Also, since this backdoor can launch a remote cmd shell, all cmd commands are available for the attacker to use, such as those seen in Figure 11.</p>
<p><i>Hussarini</i> uses a dynamic domain to maintain anonymity and to also possibly be able to change the C&amp;C server IP address. At the time of this analysis, however, we only saw it resolved to the IP address 157.52.167.71, which is the same IP used to host the decoy document.</p>


</div>

</div>
<div class="cmp cmp-text aem-GridColumn aem-GridColumn--default--12">
  <p><b>Final thoughts</b></p>
<p>We are unsure how the document is being distributed; however, taking a look at the C&amp;C domain name <i><a class="vglnk" rel="nofollow"><span>publicdfaph.publicvm.com</span></a></i> and considering the file name of the exploit document “Draft PH-US Dialogue on Cyber Security.doc” and the clues from the decoy document download link hxxp://157.52.167.71:29317/office/word/2003/ph2/philip.varilla, there is one scenario that seems to make the most sense.</p>
<p>It seems likely that the names used were crafted to make it look like the document came from the Department of Information and Communications Technology (DICT), or possibly from the Service Director, which would imply that the employees of the Department of Foreign Affairs (DFA) are the target. Clearly, the use of <i>publicdfaph </i>in the C&amp;C domain name is used to camouflage the traffic and to trick a network administrator into thinking that this domain is under DFA so as not to raise any suspicion.</p>
<p><b>Conclusion</b></p>
<p>Hussarini was first mentioned in APT campaigns targeting the Philippines and Thailand in 2014. Today, this malware is still actively being used against the Philippines. The Department of Information and Communications Technology was only formed in 2016 and has <a href="https://www.rappler.com/technology/news/168634-dict-launches-ph-5-year-natl-cybersecurity-plan">acknowledged</a> that the Philippines’ state of cybersecurity is still in infancy. In general, this contributes to the Philippines continuing to be a target for cybercrime/cyberespionage or even state-sponsored attacks. Because of this, we expect that attacks targeting that region will continue to evolve in both quantity and quality. As always, we here at FortiGuard Labs will continue to monitor events in order to hunt for, catch, and block these attacks.</p>
<p><b>Solution:</b></p>
<p>Fortinet detects the exploit document as MSOffice/CVE_2017_11882.A!tr and the Hussarini samples as W32/Sarhust.D!tr. Malicious URLs related to this malware are also blocked by FortiGuard Web Filtering Service.</p>
