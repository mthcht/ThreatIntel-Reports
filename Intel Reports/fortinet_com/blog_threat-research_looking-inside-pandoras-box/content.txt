<div class="cmp cmp-text aem-GridColumn aem-GridColumn--default--12">
  <p>In Greek mythology, opening of the infamous Pandora’s box (jar) introduced terrible things to the world. That can also be said about today’s ransomware. The newly emerged Pandora ransomware that crowned the name is no exception. It steals data from the victim’s network, encrypts the victim’s files, and unleashes the stolen data if the victim opts not to pay. The Greek myth says hope was left in the box. Does that hold true for Pandora ransomware, an emerging malware that shows all techniques used by modern ransomware? In this blog we are taking a hammer and crowbar to look inside today’s Pandora’s box to find out what mysteries it holds. We will discuss:<br />
</p>
<ul><li>How this ransomware tries to evade detection</li><li>The numerous obfuscation and anti-analysis techniques that are used to hinder analysts</li><li>How multi-threading is used to speed up processing</li><li>How the filesystem is processed</li><li>How and which files are encrypted.</li></ul>
<div> </div>
<div><b>Affected Platforms:</b> Windows<br />
<b>Impacted Users:</b> Windows users<br />
<b>Impact: </b>Most files on the compromised machines are encrypted<br />
<b>Severity Level:</b> Medium</div>
<h2>Pandora Group</h2>
<p>The Pandora ransomware group emerged into the already crowded ransomware field as early as in mid-February 2022 and targets corporate networks for financial gain. The group got recent publicity after they announced that they acquired data from an international supplier in the automotive industry. The incident came as surprise as the attack came two weeks after another automotive supplier was reportedly hit with unknown ransomware, which resulted in one of the world’s biggest car manufacturers suspending factory operations. The threat group uses the double extortion method to increase pressure on the victim. This means that they not only encrypt the victim’s files, but also exfiltrate them and threaten to release the data if the victim does not pay.</p>
<p>The Pandora Group has a leak site in the Dark Web (TOR network), where they publicly announce their victims and threaten them with the <a title="data leak" href="https://www.fortinet.com/resources/cyberglossary/data-leak?utm_source&#61;blog&amp;utm_medium&#61;blog&amp;utm_campaign&#61;blog-data-leak">data leak</a>. There are currently three victims listed on the leak site (see Figure 1), a U.S.-based real estate agency, a Japanese technology company, and a U.S. law firm.</p>

  <h2>Malware Analysis</h2>
<p>We analyzed the sample with the SHA-256 hash <span style="	font-family: &#34;Courier New&#34;;
"><span style="	font-size: 9.0pt;
">5b56c5d86347e164c6e571c86dbf5b1535eae6b979fede6ed66b01e79ea33b7b</span></span>, which is a 64-bit Windows PE file. It is the ransomware itself, so by the time this file is executed during an attack, the attackers probably already had extensive access to the victim’s network, and they had already exfiltrated the data they will use for the extortion. This sample does not have the capability to communicate with the threat actors. Its sole purpose is to find and encrypt files. However, it does this in an interesting and complex manner.</p>
<p>In the following sections these interesting aspects of the <a title="malware" href="https://www.fortinet.com/resources/cyberglossary/malware-analysis?utm_source&#61;blog&amp;utm_medium&#61;blog&amp;utm_campaign&#61;blog-malware-analysis">malware</a> will be discussed.</p>
<h3>Execution Flow</h3>
<p>The sample goes through the following steps:</p>
<p>Note that “T” followed by numbers within brackets refers to MITRE ATT&amp;CK technique ID, which are summarized at the end of the post.</p>
<p> 1) <b>Unpacking</b>: The sample is packed with a modified UPX packer (T1027.002), so the first step is to unpack the real content to memory and jump to it. This will be discussed later.</p>
<p> 2) <b>Mutex</b><span>: It creates a </span><span style="	font-size: 11.0pt;
"><span style="	font-family: Calibri , sans-serif;
">mutex </span></span><span>called </span><span style="	font-family: &#34;Courier New&#34;;
"><span style="	font-size: 9.0pt;
">ThisIsMutexa</span></span>.</p>
<p> 3) <b>Disable Security Features</b>: It can delete Windows shadow copies (T1490), bypass AMSI (T1562.001), and disable Event Logging (T1562.002). More on these features later.</p>
<p> 4) <b>Collects system information: </b><span style="	font-family: &#34;Courier New&#34;;
"><span style="	font-size: 9.0pt;
">GetSystemInfo()</span></span>is used to collect information about the local system.</p>
<p> 5) <b>Loads Hardcoded Public Key</b>: A public key is hardcoded in the malware sample. This is used to set up the cryptography for encryption.</p>
<p> 6) <b>Store Private and Public Keys in Registry</b>: A private key is generated, and both the hardcoded public key and the newly generated private key are stored in the registry       (T1112).</p>
<p> 7) <b>Search Drives</b>: It searches for unmounted drives on the system and mounts them to encrypt them as well (T1005).</p>
<p> 8) <b>Setup Multi-Threading</b>: The sample uses worker threads to distribute the encryption process. More on this later.</p>
<p> 9) <b>Enumerate Filesystem</b>: The worker threads start to enumerate the filesystems of the identified drives (T1083).</p>
<p>10) <b>Drop Ransom Note</b><span>: The ransom note is dropped in every folder in </span><span style="	font-family: &#34;Courier New&#34;;
"><span style="	font-size: 9.0pt;
">Restore_My_Files.txt</span></span>.</p>
<p>11) <b>Check File Name Blacklist</b>: For every file and folder a blacklist of file/folder names is checked. If the file/folder is on the blacklist it will not be encrypted. More on this later.</p>
<p>12) <b>Check File Extension Blacklist</b>: Each file is checked against a file extension blacklist. If the extension is on the list, it will not be encrypted.</p>
<p>13) <b>Unlock File</b>: If the file is locked by a running process, the sample will try to unlock it using the Windows Restart Manager(T1489).</p>
<p>14) <b>Encrypt File</b>: The worker threads will encrypt(T1486) the file and write it back to the original file.</p>
<p>15) <b>Rename File</b><span>: Once the encryption is finished the file is renamed to</span><span style="	font-family: &#34;Courier New&#34;;
"><span style="	font-size: 9.0pt;
">[original_filename].pandora</span></span><span style="	font-size: 11.0pt;
"><span style="	font-family: Calibri , sans-serif;
">.</span></span></p>
<h2>Anti-Reverse Engineering Techniques</h2>

This is not new for malware, but Pandora lies on the extreme side of how much is invested in slowing analysis down. In this section we will go through the different techniques that were identified.</p>

<h3>Control-Flow Flattening</h3>
<p>Control-Flow Flattening is an obfuscation technique that can hide the structure of the program by modifying the control-flow. In the simplest case, it replaces the normal control flow of each function with a state machine, thus it makes harder for an analyst to quickly understand how each function works. Pandora uses a more complex control-flow flattening combined with opaque predicates, to complicate the control flow even further.</p>


</div>

<h3>Function Call Obfuscation</h3>
<p>It was already mentioned in the previous section that most function calls are not calling a direct address, but a register. Its value is calculated at runtime.</p>

<p>As mentioned, this was solved using emulation. By emulating the execution of a function, we could calculate the register values at CALL instructions. This allowed us to resolve function calls at scale.</p>

  <h2>Multi-Threading</h2>
<p>Pandora uses multiple threads to speed up the encryption process. For that it uses Windows’s <a href="https://docs.microsoft.com/en-us/windows/win32/fileio/i-o-completion-ports">IO Completion Ports</a> concept. This allows threads to wait for a file/network handle to appear in the IO Completion Port queue and process them. Pandora uses unassociated IO Completion Ports and sends any data through it using the <span style="	font-family: &#34;Courier New&#34;;
"><span style="	font-size: 9.0pt;
">OVERLAPPED</span></span> structure. In this case drives and file paths will be passed to threads to process (enumerate or encrypt) them. The IO Completion Port is set up using the <span style="	font-family: &#34;Courier New&#34;;
"><span style="	font-size: 9.0pt;
">CreateIOCompletionPort()</span></span> API function as shown in Figure 10. By passing <span style="	font-family: &#34;Courier New&#34;;
"><span style="	font-size: 9.0pt;
">INVALID_HANDLE_VALUE</span></span> as the first parameter <span style="	font-size: 11.0pt;
"><span style="	font-family: Calibri , sans-serif;
">(</span></span><span style="	font-family: &#34;Courier New&#34;;
"><span style="	font-size: 9.0pt;
">rcx &#61; 0xFFFFFFFFFFFFFFFF</span></span><span style="	font-size: 11.0pt;
"><span style="	font-family: Calibri , sans-serif;
">)</span></span> and <span style="	font-family: &#34;Courier New&#34;;
"><span style="	font-size: 9.0pt;
">NULL</span></span> as the second <span style="	font-size: 11.0pt;
"><span style="	font-family: Calibri , sans-serif;
">(</span></span><span style="	font-family: &#34;Courier New&#34;;
"><span style="	font-size: 9.0pt;
">rdx &#61; 0x0</span></span><span style="	font-size: 11.0pt;
"><span style="	font-family: Calibri , sans-serif;
">)</span></span> an unassociated IO Completion Port is created. The fourth parameter is the <span style="	font-family: &#34;Courier New&#34;;

"><span style="	font-size: 9.0pt;
">r9 &#61; 0x4</span></span>), defines that maximum 4 threads are allowed to work with this IO Completion Port.</p>

  <h2>Restart Manager</h2>
<p>The Restart Manager is a Windows feature to reduce the number of restarts needed during installation and updates. The reason for a restart is usually because a file that needs to be updated is locked by a running process. The Restart Manager can save the state and stop the locking process to unlock the target file. Once the update is finished, it can restore the locking process again. Pandora uses the Restart Manager to make sure that even files that are currently locked will be encrypted. For each file the following process is executed:</p>
<p style="	margin-left: 40.0px;
">1)      Create Restart Manager session with <span style="	font-family: &#34;Courier New&#34;;
"><span style="	font-size: 9.0pt;
">RmStartSession()</span></span></p>
<p style="	margin-left: 40.0px;
">2)      Register the target file as a resource with <span style="	font-family: &#34;Courier New&#34;;
"><span style="	font-size: 9.0pt;
">RmRegisterResource()</span></span></p>
<p style="	margin-left: 40.0px;
">3)      Check if the target file is locked by any process with <span style="	font-family: &#34;Courier New&#34;;
"><span style="	font-size: 9.0pt;
">RmGetList()</span></span></p>
<p style="	margin-left: 40.0px;
">4)      If so, terminate locking processes</p>
<p style="	margin-left: 40.0px;
">5)      End Restart Manager session with <span style="	font-family: &#34;Courier New&#34;;
"><span style="	font-size: 9.0pt;
">RmEndSession()</span></span></p>

<h2>Disabling Security Features</h2>
<p>The Pandora ransomware has the capabilities to disable some of the security measures on the target machine.</p>
<h3>Deleting Shadow Copies<br />
</h3>
<p>Like a lot of other ransomware, Pandora deletes the Windows Shadow Copies, which could help the operator restore the machine to a state before the infection. Figure 15 shows the call to <span style="	font-family: &#34;Courier New&#34;;
"><span style="	font-size: 9.0pt;
">ShellExecuteW()</span></span> with the parameters from runtime(T1059). We can see that it uses the <span style="	font-family: &#34;Courier New&#34;;
"><span style="	font-size: 9.0pt;
">vssadmin.exe</span></span>.</p>

<div class="cmp cmp-text aem-GridColumn aem-GridColumn--default--12">
  <h3>AMSI Bypass</h3>
<p>The Antimalware Scan Interface (AMSI) allows security products to integrate better with Windows to be able to scan all kinds of different objects, such as PowerShell scripts, JavaScript, VBScript, etc. By bypassing AMSI, the malware can take away significant capabilities from the security products running on the machine. Pandora bypasses AMSI by patching the <span style="	font-family: &#34;Courier New&#34;;
"><span style="	font-size: 9.0pt;
">AmsiScanBuffer()</span></span> function in the <span style="	font-family: &#34;Courier New&#34;;
"><span style="	font-size: 9.0pt;
">amsi.dll </span></span>in memory.</p>
<h3>Disable Event Log</h3>
<p>Similar to the AMSI bypass, Pandora disables the Event Tracing for Windows (ETW) feature, by patching the <span style="	font-family: &#34;Courier New&#34;;
"><span style="	font-size: 9.0pt;
">EtwEventWrite()</span></span> function in the Windows kernel <span style="	font-size: 11.0pt;
"><span style="	font-family: Calibri , sans-serif;
">(</span></span><span style="	font-family: &#34;Courier New&#34;;
"><span style="	font-size: 9.0pt;
">ntdll.dll</span></span>). Figure 16 shows that the first byte of the function is replaced with <span style="	font-family: &#34;Courier New&#34;;
"><span style="	font-size: 9.0pt;
">0xC3</span></span>, which is the <span style="	font-family: &#34;Courier New&#34;;
"><span style="	font-size: 9.0pt;
">ret</span></span> instruction. This renders the <span style="	font-family: &#34;Courier New&#34;;
"><span style="	font-size: 9.0pt;
">EtwEventWrite()</span></span> function useless, because after every call it return immediately without logging the event.</p>

  <h2>Conclusion</h2>
<p>The Pandora ransomware contains all of the most important features that state-of-the-art ransomware samples usually contain. The level of obfuscation to slow down analysis is more advanced than average malware. The threat actor also paid attention to unlock files to guarantee the maximum encryption coverage, while still allowing the machine to run. We can already see anti-security product features. We can expect the threat actor to develop these capabilities further. There is currently no proof that Pandora operates as Ransomware-as-a-Service (RaaS), but the time investment in the complexity of the malware might indicate that they are moving in that direction in the long term. The current attacks and leaks might be a way to make their name in the ransomware field, which they could capitalize on if they adopt the RaaS model later. It is worth tracking the threat actor to monitor how their malware changes.</p>
