                            <h1 class="header__title title-h2 mb-24 mt-md-48 mt-lg-64 mt-xl-64">The Locking Egregor</h1><p class="header__text mb-xs-48 mb-64 mb-lg-96 mb-xl-96">Analysis of TTPs employed by Egregor operators</p><div class="post-info__date mb-24 mb-lg-32 mb-xl-48"><div class="body2">November 20, 2020 · <span id="reading-time"></span> min to read · Ransomware</div></div><div class="post-info__image mb-24 mb-lg-32 mb-xl-48"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/img-1440-64.jpg.webp" type="image/webp"><img src="https://www.group-ib.com/wp-content/uploads/img-1440-64.jpg" alt="" class="webpexpress-processed"></picture></div><div class="post-info__tags"><div class="post-info__tag body2">Digital Forensics</div><div class="post-info__tag body2">Egregor</div><div class="post-info__tag body2">Incident Response</div></div>                        </div>
                    </div>
                </div>
                <div class="blog-post-content" id="blog-post-content">
                    <div class="blog-post-content__section--text"><p>Regardless of a cybersecurity role in your organization, whether you are a SOC analyst, threat hunter, or CISO, the more you know about the threat landscape relevant to your business and region the better you can protect your assets. But when it comes to ransomware, any big organization can be a target, and you should always be on guard. Especially, given that the major cybercrime trend of 2020 is <strong>Big Game Hunting</strong>.</p>
<p>More and more players join the game, disrupting more and more businesses all around the world. Ransomware itself, as well as attackers&#8217; TTPs become increasingly complex, making detection and analysis really tough. One of such ransomware families, that came into the game quite recently, but already managed to «lock» quite outstanding victims, such as Crytek and Barnes &amp; Noble &#8211; is<strong> Egregor</strong>.</p>
<p>Recently Group-IB DFIR team observed Egregor ransomware operators actively using <strong>Qakbot (aka Qbot)</strong> to gain initial access, just like it was with <a href="https://www.group-ib.com/blog/prolock-evolution/" target="_blank" rel="noopener"><strong>Prolock</strong> </a>not long ago. The close similarities in TTPs with earlier ProLock campaigns indicate that Qakbot operators have likely abandoned ProLock for Egregor.</p>
<p>Egregor has been actively distributed since September 2020. In less than 3 months Egregor operators have managed to successfully hit <strong>69 companies</strong> around the world with 32 targets in the US, 7 victims in France and Italy each, 6 in Germany, and 4 in the UK. Other victims happened to be from the APAC, Middle East, and Latin America. Egregor&#8217;s favorite sectors are Manufacturing (28.9% of victims) and Retail (14.5%).</p>
<div id="attachment_26584" style="width: 1510px" class="wp-caption alignnone"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/1-min-22.png.webp" type="image/webp"><img aria-describedby="caption-attachment-26584" decoding="async" class="size-full wp-image-26584 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/1-min-22.png" alt="Egregor victims distribution by country" width="1500" height="787"></picture><p id="caption-attachment-26584" class="wp-caption-text">Egregor victims</p></div>
</div>
                                                            <div class="experts--type1 mb-24 mb-lg-32 mb-xl-48 mt-24 mt-lg-32 mt-xl-48">
                                    <div class="experts__quot">
                                        <div class="experts__quot-text">
                                            <div class="experts__quot-icon"><img src="/wp-content/themes/gib-theme/assets/images/quot.svg" alt=""></div>
                                            <div class="title-h5">Given the increased activity of Egregor operators and the gang's focus on big firms, we decided to release this "emergency" blog post to help cybersecurity teams identify and hunt for this threat actor. This blog will dive you into recent Qakbot campaigns, TTPs employed by the threat actors during their Big Game Hunting operations, and in-depth analysis of Egregor ransomware.</div>

                            <div class="blog-post-content__section--text"><h2>Recent Qakbot campaigns</h2>
<p>In September 2020, Emotet switched back to distributing Trickbot, so Qakbot operators had to distribute their trojan without its help. To deliver the trojan, Qakbot operators used malicious Microsoft Excel documents impersonating DocuSign-encrypted spreadsheets, and still prefer to use so-called &#8220;Email Thread Hijacking&#8221; technique.</p>
<div id="attachment_26585" style="width: 470px" class="wp-caption alignnone"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/2-min-28.png.webp" type="image/webp"><img aria-describedby="caption-attachment-26585" decoding="async" class="size-full wp-image-26585 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/2-min-28.png" alt="DocuSign decoy screenshot" width="460" height="335"></picture><p id="caption-attachment-26585" class="wp-caption-text">DocuSign decoy</p></div>
<h2>Post-Exploitation</h2>
<p><strong>During our incident response engagements, we saw almost identical techniques to those we saw in attacks involving ProLock ransomware.</strong> Once initial access is gained, the threat actors used AdFind to collect Active Directory information.</p>
<p>Also we&#8217;ve seen the same script to enable comfortable lateral movement &#8211; &#8220;rdp.bat&#8221;. It was used by the threat actors to modify registry and firewall rules to enable connections via Remote Desktop Protocol.</p>
<p>To compromise the whole network infrastructure, the threat actor used Cobalt Strike – an extremely popular post-exploitation tool we&#8217;ve seen in almost 70% of incidents involving Big Game Hunting operations this year.</p>
<p>In some cases, the threat actors also distributed Qakbot through the network via PsExec, just like in cases with Prolock we observed in the past, they use a file named &#8220;md.exe&#8221; – that is the Qakbot binary.</p>
<p>In addition, they used Rclone for data exfiltration – the same masquerading technique was used, they renamed its binary to svchost.exe and placed it to C:\Windows.</p>
<p>Parts of exfiltrated data are published on Egregor&#8217;s Data Leak Site (DLS) to prove they not only locked the victim&#8217;s network, but also stolen sensitive information:</p>
<div id="attachment_26592" style="width: 596px" class="wp-caption alignnone"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/3-min-29.png.webp" type="image/webp"><img aria-describedby="caption-attachment-26592" decoding="async" class="size-full wp-image-26592 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/3-min-29.png" alt="Egregor's "Hall of shame"" width="586" height="350"></picture><p id="caption-attachment-26592" class="wp-caption-text">Egregor&#8217;s &#8220;Hall of shame&#8221;</p></div>
<p>If the victim refuses to pay, the threat actors publish the whole set of exfiltrated data:</p>
<div id="attachment_26583" style="width: 591px" class="wp-caption alignnone"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/4-min-29.png.webp" type="image/webp"><img aria-describedby="caption-attachment-26583" decoding="async" class="size-full wp-image-26583 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/4-min-29.png" alt="The whole set of data exfiltrated from Crytek" width="581" height="273"></picture><p id="caption-attachment-26583" class="wp-caption-text">The whole set of data exfiltrated from Crytek</p></div>
<h2>Ransomware deployment</h2>
<p><strong>The threat actors used multiple techniques for ransomware deployment</strong>, in some cases even in a single attack, including abusing Background Intelligent Transfer Service (BITS), WMI command-line (WMIC) utility and PowerShell remote sessions. It&#8217;s interesting that the PowerShell script contains comments in Russian:</p>
<div id="attachment_26591" style="width: 966px" class="wp-caption alignnone"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/5-min-31.png.webp" type="image/webp"><img aria-describedby="caption-attachment-26591" decoding="async" class="size-full wp-image-26591 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/5-min-31.png" alt="A part of PowerShell script used to deploy Egregor ransomware" width="956" height="479"></picture><p id="caption-attachment-26591" class="wp-caption-text">A part of PowerShell script used to deploy Egregor ransomware</p></div>
<h2>Ransomware analysis</h2>
<p>We analyzed a sample of Egregor ransomware, which was obtained during one of our incident response engagements. Egregor is delivered as a DLL, and should be launched via rundll32 executable with the similar command line:</p>
<p><em>rundll32.exe C:\Windows\q.dll,DllRegisterServer -password –-mode</em></p>
<p>After calling the function DllRegisterServer, the next stage will be decoded, decrypted and executed. This stage is protected using ChaCha8 stream cipher (the key and the nonce are stored inside the file) and Base64 encoding:</p>
<p><picture><source srcset="https://www.group-ib.com/wp-content/uploads/6-min-23.png.webp" type="image/webp"><img decoding="async" class="alignnone size-full wp-image-26590 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/6-min-23.png" alt="egregor encoding file" width="799" height="592"></picture></p>
<p>The next stage is also used as an encryption layer for the final payload, which could be decrypted only if the correct password is provided as an argument. This password is used as the key for HMAC-SHA256, and the input data for HMAC-SHA256 is hardcoded within the program. After that, 10000 iterations of HMAC-SHA256 are used along with XOR operation to create a key for Rabbit stream cipher, which will be used to decrypt the final payload:</p>
<p><picture><source srcset="https://www.group-ib.com/wp-content/uploads/7-min-25.png.webp" type="image/webp"><img decoding="async" class="alignnone size-full wp-image-26587 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/7-min-25.png" alt="egregor final payload" width="738" height="379"></picture></p>
<p>The final payload is highly obfuscated with junk instructions and a lot of jump and call obfuscation is used. We noticed that Egregor obfuscation is very similar to the obfuscation used in another ransomware &#8211; Sekhmet). The string obfuscation is likewise similar to Sekhmet and even the keys for decrypting the same strings are the identical.</p>
<p><strong>We noticed that the sequence of language checks is very similar to Sekhmet and Maze ransomware.</strong></p>
<p>The main purpose of the Egregor (unsurprisingly) is to encrypt files. Files are encrypted using ChaCha8 stream cipher among with RSA-2048 asymmetric algorithm – the same scheme was used in Sekhmet and Maze ransomware (key and nonce for ChaCha8 are generated randomly for each encrypted file):</p>
<div id="attachment_26588" style="width: 699px" class="wp-caption alignnone"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/8-min-24.png.webp" type="image/webp"><img aria-describedby="caption-attachment-26588" decoding="async" class="size-full wp-image-26588 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/8-min-24.png" alt="ChaCha8 key and nonce generation in Egregor and Sekhmet" width="689" height="144"></picture><p id="caption-attachment-26588" class="wp-caption-text">ChaCha8 key and nonce generation in Egregor and Sekhmet</p></div>
<div id="attachment_26589" style="width: 679px" class="wp-caption alignnone"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/9-min-18.png.webp" type="image/webp"><img aria-describedby="caption-attachment-26589" decoding="async" class="size-full wp-image-26589 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/9-min-18.png" alt="ChaCha8 key and nonce generation in Maze" width="669" height="205"></picture><p id="caption-attachment-26589" class="wp-caption-text">ChaCha8 key and nonce generation in Maze</p></div>
<p>ChaCha8 key and nonce is encrypted and added to the beginning of the encrypted file.</p>
<p>Local RSA-2048 keypair is generated for each infected computer; the local private key is encrypted by the public master key and then added to the &#8220;technical block&#8221; at the end of the ransom note (this block also contains the number of encrypted files, information about workstation and domain).</p>
<p>To check if it is able to encrypt file in specific directory, Egregor will try to create a shortcut in this directory (the name of the shortcut is equal to victim ID, which is generated based on hardware configuration of the computer). The shortcut is created with the option FILE_FLAG_DELETE_ON_CLOSE, which allows to automatically deleting this shortcut after the handle is closed.</p>
<p>After all, the ransom note named <strong>RECOVER-FILES.txt</strong> will be created in each directory with encrypted files. Here is a template extracted from an Egregor sample:</p>
<p><picture><source srcset="https://www.group-ib.com/wp-content/uploads/10-min-21.png.webp" type="image/webp"><img decoding="async" class="alignnone size-full wp-image-26586 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/10-min-21.png" alt="Egregor ransom note template" width="963" height="1737"></picture></p>
<p>The largest ransom demand we observed was more than <strong>4 000 000 $</strong> in BTC.</p>
<h2>Conclusion</h2>
<p>Tactics, techniques and procedures observed are very similar to those seen in the past Qakbot&#8217;s Big Game Hunting operations. At the same time, we see that these methods are still very effective and allow threat actors to compromise quite big companies successfully. <strong>It&#8217;s important to note, that the fact many Maze partners started to move to Egregor will most likely result in the shift in TTPs, so defenders should focus on known methods associated with Maze affiliates.</strong></p>
<h3>General Recommendations</h3>
<ol>
<li>If you&#8217;ve detected Qakbot infection in your network, make sure you handle it properly, and there&#8217;s no evidence of lateral movement.</li>
<li>Make sure your security controls are able to detect and block Cobalt Strike usage.</li>
<li>Focus on suspicious RDP connections as well as BITS, wmic and PowerShell abuse.</li>
<li>Develop threat hunting capability for your team, so you can reduce attacker&#8217;s dwell time, and prevent successful ransomware deployment.</li>
<li>Make sure your team has updated cyber <a href="/products/threat-intelligence/" target="_blank" rel="noopener">threat intelligence</a> information to detect and prevent human-operated ransomware attacks.</li>
<li>Learn what techniques and methods Threat Hunters use today through Group-IB&#8217;s <a href="/cybersecurity-education/technical-training-programs/" target="_blank" rel="noopener">Cyber Education courses</a>.</li>
<li>Download the white paper <strong><a href="/resources/research-hub/egregor-ransomware/" target="_blank" rel="noopener">&#8220;Egregor ransomware: The legacy of Maze lives on&#8221;</a></strong> for more TTPs, detection and threat hunting tips.</li>
</ol>

    function positioningSidebar() {
        let sidebar = document.getElementById('sidebar');
        let sidebarHeight = sidebar.offsetHeight;
        let windowHeight = document.documentElement.clientHeight;
        if (windowHeight < (sidebarHeight + 48)) {
            let sidebarAuthors = sidebar.querySelector('.sidebar__authors');
            let sidebarMorePosts = sidebar.querySelector('.sidebar__more-posts');
            let authorsHeight = sidebarAuthors ? sidebarAuthors.offsetHeight : 0;
            let morePostsHeight = sidebarMorePosts ? sidebarMorePosts.offsetHeight : 0;
            let sidebarTop = authorsHeight + morePostsHeight + 140;
            jQuery(sidebar).css('top', -sidebarTop + 'px');
        } else {
            jQuery(sidebar).css('top', '72px');
        }
    }
    window.addEventListener('resize', positioningSidebar);
    positioningSidebar();

    if (localStorage.getItem('theme')) {
        if (localStorage.getItem('theme') == 'dark') {
            jQuery('body').addClass('theme--dark');
        } else if (localStorage.getItem('theme') == 'light') {
            jQuery('body').addClass('theme--white');
        }
    } else {
        localStorage.setItem('theme', 'dark');
        jQuery('body').addClass('theme--dark');
    }

    jQuery('.theme-toggle').click(function() {
        if (localStorage.getItem('theme') == 'dark') {
            localStorage.setItem('theme', 'light');
        } else {
            localStorage.setItem('theme', 'dark');
        }
        jQuery('body').toggleClass('no-transition');
        jQuery('body').toggleClass('theme--dark');
        jQuery('body').toggleClass('theme--white');
        setTimeout(() => {
            jQuery('body').toggleClass('no-transition');
        }, 250);
    });
    jQuery('.share-toggle').click(function() {
        jQuery('.share-toggle').toggleClass('active');
        jQuery('.share-widget').toggleClass('show');
    });
</script>
