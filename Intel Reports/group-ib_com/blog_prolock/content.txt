                            <h1 class="header__title title-h2 mb-24 mt-md-48 mt-lg-64 mt-xl-64">ATT&CKing ProLock Ransomware</h1><p class="header__text mb-xs-48 mb-64 mb-lg-96 mb-xl-96">The success of enterprise ransomware attacks has motivated more and more threat actors to join the game.</p><div class="post-info__date mb-24 mb-lg-32 mb-xl-48"><div class="body2">May 14, 2020 · <span id="reading-time"></span> min to read · Ransomware</div></div><div class="post-info__image mb-24 mb-lg-32 mb-xl-48"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/img-1440-24.jpg.webp" type="image/webp"><img src="https://www.group-ib.com/wp-content/uploads/img-1440-24.jpg" alt="" class="webpexpress-processed"></picture></div><div class="post-info__tags"><div class="post-info__tag body2">ProLock</div><div class="post-info__tag body2">Ransomware</div></div>                        </div>
                    </div>
                </div>
                <div class="blog-post-content" id="blog-post-content">
                    <div class="blog-post-content__section--text"><p>The success of enterprise ransomware attacks has motivated more and more threat actors to join the game.</p>
<p>One of these new players is <strong>ProLock ransomware</strong>.</p>
<p>The locker emerged in March 2020 as the successor of PwndLocker, which began operating in late 2019 and was responsible for the attack on Illinois&#8217; Lasalle County earlier this year. Their ransoms were always in the six-figure range, and it seems that ProLock operators are continuing that trend.</p>
<p>Despite not being around long, ProLock has already made its mark, targeting financial, healthcare, government, and retail organizations. The group&#8217;s first big <a href="https://krebsonsecurity.com/2020/05/ransomware-hit-atm-giant-diebold-nixdorf/" target="_blank" rel="nofollow noopener">attack</a> – that we know of, at least – happened at the end of April, when they successfully attacked Diebold Nixdorf &#8211; one of the major ATM providers.</p>
<p>In this post I&#8217;ll tell you all you need to know about the new player&#8217;s main tactics, techniques and procedures (TTPs). After, I give a complete outline of the MITRE ATT&amp;CK mapping as it pertains to ProLock.</p>
<h2>Initial Access</h2>
<p>ProLock operators used two main vectors of initial access: QakBot (Qbot) and unprotected Remote Desktop Protocol (RDP)-servers with weak credentials.</p>
<p>The latter is a fairly common technique among ransomware operators. This kind of access is usually bought from a third party but may be obtained by group members as well.</p>
<p>The more interesting initial access vector is QakBot, a trojan that was at one point affiliated with the MegaCortex ransomware family.</p>
<p>Typically, QakBot is distributed via phishing campaigns. Phishing emails may contain attachments of weaponized Microsoft Office documents or just links to such documents that are located on cloud storage – Microsoft OneDrive, for example.</p>
<p>QakBot is also known to be loaded by Emotet, a trojan notorious for its connection with Ryuk operators.</p>
<h2>Execution</h2>
<p>Once weaponized document is downloaded and opened by the victim, malicious macros is enabled, PowerShell is launched and used to download and run QakBot payload from the C2 server.</p>
<p>It&#8217;s important to note here that the same can be said about ProLock: the payload is extracted from a BMP or JPG file, and is loaded into memory with PowerShell. In some cases, a scheduled task is used to run PowerShell:</p>
</div>
                            
                            <div class="blog-post-content__section"><div class="code"><div class="code__wrapper">schtasks.exe /CREATE /XML C:\Programdata\WinMgr.xml /tn WinMgr
schtasks.exe /RUN /tn WinMgr
del C:\Programdata\WinMgr.xml
del C:\Programdata\run.bat</div></div></div><div class="blog-post-content__section--text"><h2>Persistence</h2>
<p>In case of RDP access, valid accounts are used to gain persistence in the network. QakBot, on the other hand, uses multiple persistence mechanisms – most often Run keys and scheduled tasks:</p>
<div id="attachment_26828" style="width: 982px" class="wp-caption alignnone"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/1-min-23.png.webp" type="image/webp"><img aria-describedby="caption-attachment-26828" decoding="async" class="size-full wp-image-26828 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/1-min-23.png" alt="Qakbot gained persistence via Run key - prolock ransomware" width="972" height="93"></picture><p id="caption-attachment-26828" class="wp-caption-text">Figure 1: Qakbot gained persistence via Run key</p></div>
<p>In some cases, startup folders are also used: a shortcut is placed in the folder that points to the loader.</p>
<h2>Defense Evasion</h2>
<p>QBot has a neat trick that lets it avoid detection: it checks for the newest version of itself, and replaces the current version with the new one. Executable files are signed with a stolen or fake signature. The initial payload, downloaded by PowerShell, is stored on the server with a PNG extension. What&#8217;s more, is that it&#8217;s replaced with the legitimate file calc.exe after execution.</p>
<p>To evade detection, QakBot also uses <strong>explorer.exe</strong> to execute a process injection technique.</p>
<p>As already mentioned, the ProLock payload is hidden inside a BMP or JPG file and may be considered a defense evasion technique as well.</p>
<h2>Credential Access</h2>
<p>QakBot has keylogging capabilities but is also able to download and run additional scripts like Invoke-Mimikatz, a PowerShell version of the notorious Mimikatz. This enables the adversary to employ the credential dumping technique.</p>
<h2>Discovery</h2>
<p>Once privileged credentials are obtained, ProLock operators start network discovery activities. They include, but are not limited to, port scanning and Active Directory reconnaissance.</p>
<p>In addition to a wide variety of scripts, attackers use AdFind – another popular tool used by many ransomware groups – to query Active Directory.</p>
<h2>Lateral Movement</h2>
<p>Many adversaries favor RDP to move laterally across networks, and ProLock is no exception. Attackers even have batch scripts in their arsenals to enable RDP access on the target hosts:</p>
</div>
                            
                            <div class="blog-post-content__section"><div class="code"><div class="code__wrapper"><pre>reg add "HKLM\System\CurrentControlSet\Control\Terminal Server" /v "fDenyTSConnections" /t REG_DWORD /d 0 /f
netsh advfirewall firewall set rule group="Remote Desktop" new enable=yes
reg add "HKLM\System\CurrentControlSet\Control\Terminal Server\WinStations\RDP-Tcp" /v "UserAuthentication" /t REG_DWORD /d 0 /f</pre></div></div></div><div class="blog-post-content__section--text"><p>For remote script execution, ProLock operators use PsExec from Sysinternals Suite, another common tool.</p>
<p>To run ProLock on hosts, attackers used WMIC – a command line interface for Windows Management Instrumentation – which is also becoming increasingly popular among ransomware operators.</p>
<h2>Collection</h2>
<p>Just like many other groups, ProLock operators collect data from compromised networks to improve their chances of fulfilling their ransom demands. Prior to exfiltration, collected data is archived with 7Zip.</p>
<h2>Exfiltration</h2>
<p>For exfiltration, ProLock operators use Rclone, a command line tool capable of synching files to and from different cloud storage providers, such as OneDrive, Google Drive, Mega, etc. The executable is always renamed to resemble legitimate system binaries.</p>
<p>Unlike their peers, though, ProLock operators still don&#8217;t have a website where they publish exfiltrated data from companies that refuse to pay the ransom.</p>
<h2>Impact</h2>
<p>Once the data is exfiltrated, the group deploys ProLock enterprise-wide. PowerShell is used to extract the binary from a PNG or a JPG file and inject it into the memory:</p>
<div id="attachment_26829" style="width: 1169px" class="wp-caption alignnone"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/2-min-30.png.webp" type="image/webp"><img aria-describedby="caption-attachment-26829" decoding="async" class="size-full wp-image-26829 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/2-min-30.png" alt="Prolock ransomware PowerShell script" width="1159" height="521"></picture><p id="caption-attachment-26829" class="wp-caption-text">Figure 4: PowerShell script</p></div>
<p>First, ProLock kills processes from embedded list (what&#8217;s interesting is that it uses only six letters from the process name, like &#8220;winwor&#8221;) and stops services, including security-related ones like CSFalconService (CrowdStrike Falcon), via the <strong>net stop</strong> command.</p>
<p>Then, like many other ransomware families, it uses <strong>vssadmin</strong> to remove Volume Shadow Copies and limit their size, so no new copies are created:</p>
</div>
                            
                            <div class="blog-post-content__section"><div class="code"><div class="code__wrapper"><pre>vssadmin.exe delete shadows /all /quiet
vssadmin.exe resize shadowstorage /for=C: /on=C: /maxsize=401MB
vssadmin.exe resize shadowstorage /for=C: /on=C: /maxsize=unbounded</pre></div></div></div><div class="blog-post-content__section--text"><p>ProLock adds <strong>.proLock, .pr0Lock</strong> or <strong>.proL0ck</strong> extension to each encrypted file, and drops [HOW TO RECOVER FILES].TXT to each folder – a file with instructions on how to decrypt files, including the link to the website, where the victim should enter the unique ID and get payment information:</p>
<div id="attachment_26827" style="width: 979px" class="wp-caption alignnone"><picture><source srcset="https://www.group-ib.com/wp-content/uploads/3-min-31.png.webp" type="image/webp"><img aria-describedby="caption-attachment-26827" decoding="async" class="size-full wp-image-26827 webpexpress-processed" src="https://www.group-ib.com/wp-content/uploads/3-min-31.png" alt="ProLock Ransom Note" width="969" height="782"></picture><p id="caption-attachment-26827" class="wp-caption-text">Figure 3: ProLock Ransom Note</p></div>
<p><strong>Each ProLock sample has an embedded ransom amount – in this case it was 35 Bitcoin, or approximately $312 000.</strong></p>
<h2>Summary</h2>
<p>As you can see, <strong>ProLock uses many similar techniques as other ransomware operators to achieve their goals</strong>. At the same time, however, the group does have its own unique approach. With more and more cybercrime groups showing interest in enterprise ransomware deployment campaigns, some operators may be involved in deploying different ransomware families, so we&#8217;ll likely see more overlaps in tactics, techniques and procedures.</p>

    function positioningSidebar() {
        let sidebar = document.getElementById('sidebar');
        let sidebarHeight = sidebar.offsetHeight;
        let windowHeight = document.documentElement.clientHeight;
        if (windowHeight < (sidebarHeight + 48)) {
            let sidebarAuthors = sidebar.querySelector('.sidebar__authors');
            let sidebarMorePosts = sidebar.querySelector('.sidebar__more-posts');
            let authorsHeight = sidebarAuthors ? sidebarAuthors.offsetHeight : 0;
            let morePostsHeight = sidebarMorePosts ? sidebarMorePosts.offsetHeight : 0;
            let sidebarTop = authorsHeight + morePostsHeight + 140;
            jQuery(sidebar).css('top', -sidebarTop + 'px');
        } else {
            jQuery(sidebar).css('top', '72px');
        }
    }
    window.addEventListener('resize', positioningSidebar);
    positioningSidebar();

    if (localStorage.getItem('theme')) {
        if (localStorage.getItem('theme') == 'dark') {
            jQuery('body').addClass('theme--dark');
        } else if (localStorage.getItem('theme') == 'light') {
            jQuery('body').addClass('theme--white');
        }
    } else {
        localStorage.setItem('theme', 'dark');
        jQuery('body').addClass('theme--dark');
    }

    jQuery('.theme-toggle').click(function() {
        if (localStorage.getItem('theme') == 'dark') {

            localStorage.setItem('theme', 'dark');
        }
        jQuery('body').toggleClass('no-transition');
