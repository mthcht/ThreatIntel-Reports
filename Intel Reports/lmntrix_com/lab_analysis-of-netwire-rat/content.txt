								<figure class="lmx-bs-hero">
					<img class="lmx-bs-hero__img" src="https://lmntrix.com/wp-content/uploads/blog/2024/09/Beware-of-Neware-RAT.webp" width="749" height="420" alt="Beware of Neware RAT" loading="eager" fetchpriority="high" decoding="async">				</figure>

<figure class="aligncenter size-full"><figcaption class="wp-element-caption">Beware of Neware RAT</figcaption></figure>
</div>


<p class="wp-block-paragraph">The NetWire RAT is malicious remote access trojan that emerged in the wild in 2012. This multi-platform malware was developed by World Wired Labs, and the program has since undergone several developmental upgrades. It is capable of infecting Windows, Linux, Mac OS operating systems. The malware developers have another program called PWNDROID released in mid-2020, for the Android platform. A company advertising the remote access tool frequently used by criminals and, nation-state threats may be serving as a front for Chinese hacking groups, according to new research published recently.</p>



<p class="wp-block-paragraph">The&nbsp;PWNDROID Android malware type, which can be used to listen in on targets&#8217; phone calls, capture audio, send and receive text messages, and track victims&#8217; geolocation. Multiple groups&nbsp;with&nbsp;possible ties to the Chinese government, is thought to have used it, according to LMNTRIX CDC.</p>



<p class="wp-block-paragraph">Recent APT attacks which leverage and drop the NetWire payload get distributed via social engineering e-mails. This Trojan (RAT) is mainly focused on password stealing and keylogging, as well as including remote control capabilities. Recently, NetWire has been distributed via Microsoft office documents and spreading their secondary payload attacks especially GuLoader campaigns.</p>



<p class="wp-block-paragraph">Target OS: Windows, Linux, Mac OS</p>



<p class="wp-block-paragraph">Motivation: Remote Access Tool &amp; APT Campaigns</p>



<p class="wp-block-paragraph">Threat Actors: APT33, The White Company &amp; Silver Terrier groups potentially use the Netwire RAT.<strong><br></strong></p>



<h3 class="wp-block-heading"><strong><u>Static Analysis</u></strong></h3>



<p class="wp-block-paragraph">Sample: NetWire Remote Access Tool</p>



<p class="wp-block-paragraph">SHA256: e4029ef5d391b9a380ed98a45f3e5a01eece6b7a1120ab17d6db0f8bb1309a47</p>



<p class="wp-block-paragraph">Filetype: Portable Executable (EXE)</p>



<p class="wp-block-paragraph"><strong>Common Anti-Debugging Methods Used</strong></p>



<p class="wp-block-paragraph">When the sample was loaded into Ollydbg, and we got the disassembly to start with, NetWire displayed the following error message. In addition to this error message, the malware uses NtWow64ReadVirtualMemory64 from NTDLL to query the PEB (process environment block), and a timing based check such as GetTickCount from Kernel32.DLL are used to thwart debugging.</p>



<figure class="wp-block-image size-full"><img width="1024" height="559" loading="lazy" decoding="async" decoding="async" src="/wp-content/uploads/blog/2024/09/1_netw_antidebug-1024x559-1.webp" alt="" class="wp-image-2026"/></figure>



<p class="wp-block-paragraph">&nbsp;</p>



<p class="wp-block-paragraph"><strong>Keylogger Functions</strong></p>



<p class="wp-block-paragraph">Based on the familiar CPP functions &amp; a lot of functions being imported from MSVBVM60, MSVCRT and MSCOREE DLL files, we believe the developers may be using Microsoft VC++ and/or Delphi for NetWire RAT.</p>



<figure class="wp-block-image size-full"><img width="1024" height="423" loading="lazy" decoding="async" decoding="async" src="/wp-content/uploads/blog/2024/09/2_netw_keylog1-1024x423-1.webp" alt="" class="wp-image-2027"/></figure>



<figure class="wp-block-image size-full"><img width="919" height="527" loading="lazy" decoding="async" decoding="async" src="/wp-content/uploads/blog/2024/09/2_netw_keylog2.webp" alt="" class="wp-image-2028"/></figure>



<p class="wp-block-paragraph">GetUserName, GetSecurityInfo, GetMonitorInfoA, GetLogonSessionData, and Key Press Events are monitored by the NetWire malware sample. A logged on user&#8217;s session data, encoded base 64 strings, key state, key press and keyboard events being monitored could hint at keylogging functionality.</p>



<figure class="wp-block-image size-full"><img width="841" height="320" loading="lazy" decoding="async" decoding="async" src="/wp-content/uploads/blog/2024/09/3_netw_browser_creds.webp" alt="" class="wp-image-2029"/></figure>



<p class="wp-block-paragraph">After dumping the strings from our sample PE file, and decoding them with IDAPython, we can realize that the keylogger also records and sends login data from popular web browers such as Firefox, Chrome and Internet Explorer to the NetWire Admin Workstation. The NetWire keylogger module encodes the keystrokes logged after stealing credentials from the logged on user, prior to sending it to NetWire Admin Workstation. You can find a copy of the NetWire log decoder from GitHub.</p>



<p class="wp-block-paragraph">Refer <a href="https://github.com/ArsenalRecon/NetWireLogDecoder" target="_blank" rel="noreferrer noopener nofollow">https://github.com/ArsenalRecon/NetWireLogDecoder</a></p>



<p class="wp-block-paragraph">&nbsp;</p>



<p class="wp-block-paragraph"><strong>Payment Data Being Stolen</strong></p>



<figure class="wp-block-image size-full"><img width="1024" height="398" loading="lazy" decoding="async" decoding="async" src="/wp-content/uploads/blog/2024/09/4_netw_paydata1-1024x398-1.webp" alt="" class="wp-image-2030"/></figure>



<figure class="wp-block-image size-full"><img width="1024" height="409" loading="lazy" decoding="async" decoding="async" src="/wp-content/uploads/blog/2024/09/4_netw_paydata2-1024x409-1.webp" alt="" class="wp-image-2031"/></figure>



<p class="wp-block-paragraph">LMNTRIX CDC analysts discovered payment being collected for exfiltration by NetWire trojan while investigating the keylogger module further.</p>



<p class="wp-block-paragraph">&nbsp;</p>



<p class="wp-block-paragraph"><strong>Remote Access Tool (RAT)</strong></p>



<figure class="wp-block-image size-full"><img width="1024" height="538" loading="lazy" decoding="async" decoding="async" src="/wp-content/uploads/blog/2024/09/5_netw_ratfunc1-1024x538-1.webp" alt="" class="wp-image-2032"/></figure>



<figure class="wp-block-image size-full"><img width="1024" height="400" loading="lazy" decoding="async" decoding="async" src="/wp-content/uploads/blog/2024/09/5_netw_ratfunc2-1024x400-1.webp" alt="" class="wp-image-2033"/></figure>



<p class="wp-block-paragraph">Netwire Developers from World Wired Labs have implemented the remote access tool functionality using a simple TCP Client-Server model with sockets.<strong><br></strong></p>



<h3 class="wp-block-heading"><strong><u>Dynamic Analysis</u></strong><u></u></h3>



<p class="wp-block-paragraph"><strong>Infection Chain</strong></p>



<figure class="wp-block-image size-full"><img width="1024" height="371" loading="lazy" decoding="async" decoding="async" src="/wp-content/uploads/blog/2024/09/6_netw_infchain-1024x371-1.webp" alt="" class="wp-image-2034"/></figure>



<p class="wp-block-paragraph">NetWire infects its victims using initial infection vectors of the mal-spam variety with e-mail attachment (EML). It contains a Microsoft Office (Excel) document with VBA macro enabled content. The malware tricks the user to enable the macros to perform malicious actions. Once the user enables the macro content, using Wscript file to drop a payload file in the %temp% folder, it then invokes a web-request and connects with the designated C2 server for further infection.</p>



<p class="wp-block-paragraph"><strong>Sample Information</strong></p>



<figure class="wp-block-image size-full"><img width="1024" height="239" loading="lazy" decoding="async" decoding="async" src="/wp-content/uploads/blog/2024/09/7_sample_info-1024x239-1.webp" alt="" class="wp-image-2035"/></figure>



<p class="wp-block-paragraph"><strong>Technical Analysis of XLS</strong></p>



<figure class="wp-block-image size-full"><img width="1024" height="504" loading="lazy" decoding="async" decoding="async" src="/wp-content/uploads/blog/2024/09/8_netw_tech_analysis-1024x504-1.webp" alt="" class="wp-image-2036"/></figure>



<p class="wp-block-paragraph">Once the user opens the attached document, there’s a fake Excel template displaying a message “Document created in earlier version of MS Excel” upon enabling the content, the victim now views the content. With the help of this malware the threat actor can trick the user to view the document, and infect them for further malicious actions.</p>



<p class="wp-block-paragraph"><strong>Embedded Macro Content: Screenshot 1</strong></p>



<figure class="wp-block-image size-full"><img width="1024" height="740" loading="lazy" decoding="async" decoding="async" src="/wp-content/uploads/blog/2024/09/9_netw_macro1em-1024x740-1.webp" alt="" class="wp-image-2037"/></figure>



<p class="wp-block-paragraph"><strong>Embedded Macro Content: Screenshot 2</strong></p>



<figure class="wp-block-image size-full"><img width="1024" height="724" loading="lazy" decoding="async" decoding="async" src="/wp-content/uploads/blog/2024/09/9_netw_macro2em-1024x724-1.webp" alt="" class="wp-image-2038"/></figure>



<p class="wp-block-paragraph">VBA code in the screenshot (above) is obfuscated with random functions in order to hide the exact code. It’s one of the tricks used by the malware author. Macros is a programmable pattern which translates a certain sequence of input into a preset sequence of output. Macros can make tasks less repetitive automating a complicated sequence of keystrokes, mouse movements, commands, or other types of user input.</p>



<p class="wp-block-paragraph"><strong>Macro-Enabled, Process Tree</strong></p>



<figure class="wp-block-image size-full"><img width="1024" height="284" loading="lazy" decoding="async" decoding="async" src="/wp-content/uploads/blog/2024/09/10_netw_process_tree-1024x284-1.webp" alt="" class="wp-image-2039"/></figure>



<p class="wp-block-paragraph">Once the macros are enabled, using the Wscript shell to execute and drop the payload file in %temp% folder [ Actual, file will be BIN[.]exe].<strong><br></strong></p>



<p class="wp-block-paragraph"><strong>Dropped VBS Script</strong></p>



<figure class="wp-block-image size-full"><img width="1024" height="342" loading="lazy" decoding="async" decoding="async" src="/wp-content/uploads/blog/2024/09/11_netw_dropped1-1024x342-1.webp" alt="" class="wp-image-2040"/></figure>



<p class="wp-block-paragraph">Here the command is very straight forward, using the cmd[..]exe the malware connects to the malicious domain and drops the payload file in the Windows %temp% folder. The dropped vbs file gets executed in %temp% folder as well.</p>

<figure class="wp-block-image size-full"><img width="1024" height="225" loading="lazy" decoding="async" decoding="async" src="/wp-content/uploads/blog/2024/09/12_netw_initial_ioc-1024x225-1.webp" alt="" class="wp-image-2042"/></figure>



<p class="wp-block-paragraph">Once communicating with the malicious URL, it’s silently drops a .VBS script file in the %AppData% folder to perform further malicious actions.</p>

<h3 class="wp-block-heading"><strong>Preventive Measures</strong></h3>



<ul class="wp-block-list">
<li>Usage of anti-malware software such as antivirus or, any endpoint protection such as LMNTRIX EDR / EPP with updates.</li>



<li>Beware of e-mails from unknown contacts or, untrusted external sources.</li>



<li>Always make it a practice to scan attachments that you may find suspicious, especially when the e-mails are related to financial or delivery correspondence, documents, and URLs.</li>



<li>Use a strong password, preferably 16 to 18 characters, or more with a combination of alphabets, numbers and symbols.</li>



<li>We recommend using multi factor authentication for website login / passwords for all websites.</li>
</ul>

    <script>
    (function () {
        if ( ! window.matchMedia || ! window.matchMedia( '(pointer: fine)' ).matches ) {
            return;
        }
        /*
         * Motion (2026-10-06, Firefox moved in jerks): pointermove only records the
         * target, a single requestAnimationFrame loop moves the glow towards it,
         * and the easing depends on the frame time, not on how many events
         * arrived — so at 13 fps (Firefox on a busy page) the glow glides along
         * the same path as at 60 fps instead of standing still and jumping.
         * The loop stops itself once the glow has settled on the pointer.
         */
        var RADIUS = 115;                 // half of the 230px layer
        var TAU = 45;                     // ms: time constant of the follow (≈95 % in 135 ms)
        var glow = document.createElement( 'div' );
        glow.id = 'lmx-cursor-glow';
        document.body.appendChild( glow );
        document.body.classList.add( 'lmx-cursor-active' );

        var tx = window.innerWidth / 2, ty = window.innerHeight / 2; // where the pointer is
        var gx = tx, gy = ty;                                        // where the glow is
        var raf = null, last = 0;

        function place() {
            glow.style.transform = 'translate3d(' + ( gx - RADIUS ).toFixed( 1 ) + 'px,' + ( gy - RADIUS ).toFixed( 1 ) + 'px,0)';
        }

        function frame( now ) {
            var dt = last ? Math.min( 100, now - last ) : 16;
            last = now;
            var k = 1 - Math.exp( -dt / TAU );
            gx += ( tx - gx ) * k;
            gy += ( ty - gy ) * k;
            if ( Math.abs( tx - gx ) < .3 && Math.abs( ty - gy ) < .3 ) {
                gx = tx; gy = ty; place();
                raf = null; last = 0;
                return;
            }
            place();
            raf = requestAnimationFrame( frame );
        }

        function onMove( e ) {
            tx = e.clientX;
            ty = e.clientY;
            if ( ! glow.classList.contains( 'is-visible' ) ) {
                gx = tx; gy = ty; place();           // first appearance: no slide-in from the centre
                glow.classList.add( 'is-visible' );
            }
            if ( raf === null ) {
                raf = requestAnimationFrame( frame );
            }
        }
        document.addEventListener( window.PointerEvent ? 'pointermove' : 'mousemove', onMove, { passive: true } );

        document.addEventListener( 'mouseleave', function () {
            glow.classList.remove( 'is-visible' );
        } );
        document.addEventListener( 'mouseenter', function () {
            glow.classList.add( 'is-visible' );
        } );

        // If the device later reports a coarse pointer (e.g. hybrid touch laptop
        // switches input), stop hiding the real cursor.
        var fineQuery = window.matchMedia( '(pointer: fine)' );
        function handlePointerChange( ev ) {
            if ( ! ev.matches ) {
                document.body.classList.remove( 'lmx-cursor-active' );
                glow.classList.remove( 'is-visible' );
            } else {
                document.body.classList.add( 'lmx-cursor-active' );
            }
        }
        if ( fineQuery.addEventListener ) {
            fineQuery.addEventListener( 'change', handlePointerChange );
        }
    })();
