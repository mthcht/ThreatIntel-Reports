Microsoft has observed multiple impacted organizations across government, natural resources, banking, and energy organizations. ESET <a href="https://www.welivesecurity.com/2022/04/12/industroyer2-industroyer-reloaded/" target="_blank" data-bi-compnm="null" rel="noopener noreferrer">published technical details</a> on this new version of CaddyWiper/ARGUEPATCH.     <p>To locate possible exploitation activity, run the following queries:</p>

<div class="richtext aem-GridColumn aem-GridColumn--default--12" data-component-id="aca330e78c05fd9ffbcf8222be356f7b">
<div class="cmp-text text-break" data-automation-test-id="RichTextV1Div-">
    <p>Surface suspicious MSHTA process execution</p>
</div>

    

</div>
<div class="richtext aem-GridColumn aem-GridColumn--default--12" data-component-id="aca330e78c05fd9ffbcf8222be356f7b">
<div class="cmp-text text-break" data-automation-test-id="RichTextV1Div-">
    <p>Use this query to look for MSHTA launching with command lines referencing DLLs in the AppData\Roaming path.</p>
</div>

    

</div>
<div class="richtext aem-GridColumn aem-GridColumn--default--12" data-component-id="aca330e78c05fd9ffbcf8222be356f7b">
<div class="cmp-text text-break" data-automation-test-id="RichTextV1Div-">
    <div class="highlight"><pre class="chroma"><code class="language-fallback" data-lang="fallback"><span class="line"><span class="cl">DeviceProcessEvents
</span></span><span class="line"><span class="cl">| where FileName &#61;~ &#34;mshta.exe&#34;
</span></span><span class="line"><span class="cl">| where ProcessCommandLine has_all (&#34;.dll&#34;, &#34;Roaming&#34;)
</span></span><span class="line"><span class="cl">| where ProcessCommandLine contains &#64;&#34;Roaming\j&#34;
</span></span><span class="line"><span class="cl">| extend DLLName &#61; extract(&#64;&#34;[jJ][a-z]{1,12}\.dll&#34;, 0, ProcessCommandLine)
</span></span></code></pre></div>
</div>

    

</div>
<div class="richtext aem-GridColumn aem-GridColumn--default--12" data-component-id="aca330e78c05fd9ffbcf8222be356f7b">

    <p>Surface suspicious Scheduled Task activity</p>
</div>

    

</div>
<div class="richtext aem-GridColumn aem-GridColumn--default--12" data-component-id="aca330e78c05fd9ffbcf8222be356f7b">
<div class="cmp-text text-break" data-automation-test-id="RichTextV1Div-">
    <p>Use this query to look for Scheduled Tasks that may relate to actor activity.</p>
</div>

    

</div>
<div class="richtext aem-GridColumn aem-GridColumn--default--12" data-component-id="aca330e78c05fd9ffbcf8222be356f7b">
<div class="cmp-text text-break" data-automation-test-id="RichTextV1Div-">
    <div class="highlight"><pre class="chroma"><code class="language-fallback" data-lang="fallback"><span class="line"><span class="cl">DeviceProcessEvents
</span></span><span class="line"><span class="cl">| where ProcessCommandLine has_all (&#34;schtasks.exe&#34;, &#34;create&#34;, &#34;wscript&#34;, &#34;e:vbscript&#34;, &#34;.wav&#34;)
</span></span></code></pre></div>
</div>

    

</div>
<div class="richtext aem-GridColumn aem-GridColumn--default--12" data-component-id="aca330e78c05fd9ffbcf8222be356f7b">
<div class="cmp-text text-break" data-automation-test-id="RichTextV1Div-">
    <p>Potential renamed <em>sdelete</em> usage</p>
</div>

    

</div>
<div class="richtext aem-GridColumn aem-GridColumn--default--12" data-component-id="aca330e78c05fd9ffbcf8222be356f7b">

    <p>Use this query to look for command line parameters associated with the use of a renamed Sysinternals sdelete tool to delete multiple files on the C drive as part of destructive attacks on a host.</p>
</div>

    

</div>
<div class="richtext aem-GridColumn aem-GridColumn--default--12" data-component-id="aca330e78c05fd9ffbcf8222be356f7b">
<div class="cmp-text text-break" data-automation-test-id="RichTextV1Div-">
    <div class="highlight"><pre class="chroma"><code class="language-fallback" data-lang="fallback"><span class="line"><span class="cl">DeviceProcessEvents
</span></span><span class="line"><span class="cl">| where InitiatingProcessFileName !~ &#34;sdelete.exe&#34;
</span></span><span class="line"><span class="cl">and InitiatingProcessCommandLine has_all (&#34;-accepteula&#34;, &#34;-r&#34;, &#34;-s&#34;, &#34;-q&#34;, &#34;c:/&#34;)

</span></span></code></pre></div>
