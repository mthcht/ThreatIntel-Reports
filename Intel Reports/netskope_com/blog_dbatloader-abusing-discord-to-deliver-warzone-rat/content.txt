  (function () {
    let pagefind;
    let debounceTimer;

    async function loadPagefind() {
      if (pagefind) return pagefind;
      try {
        pagefind = await import('/pagefind/pagefind.js');
        await pagefind.init();
      } catch {
        pagefind = null;
      }
      return pagefind;
    }

    function initSearch() {
      const overlay = document.getElementById('search-overlay');
      const openBtn = document.getElementById('search-open');
      const closeBtn = document.getElementById('search-close');
      const input = document.getElementById('search-input');
      const results = document.getElementById('search-results');

      function openModal() {
        overlay?.classList.remove('hidden');
        overlay?.classList.add('flex');
        input?.focus();
        loadPagefind();
      }

      function closeModal() {
        overlay?.classList.add('hidden');
        overlay?.classList.remove('flex');
        if (input) input.value = '';
        if (results) results.innerHTML = '';
      }

      openBtn?.addEventListener('click', openModal);
      closeBtn?.addEventListener('click', closeModal);
      overlay?.addEventListener('click', (e) => {
        if (e.target === overlay) closeModal();
      });
      document.addEventListener('keydown', (e) => {
        if (e.key === 'Escape') closeModal();
        if ((e.metaKey || e.ctrlKey) && e.key === 'k') {
          e.preventDefault();
          openModal();
        }
      });

      input?.addEventListener('input', () => {
        clearTimeout(debounceTimer);
        debounceTimer = setTimeout(runSearch, 200);
      });

      async function runSearch() {
        const query = input?.value.trim() ?? '';
        if (!results) return;
        if (!query) {
          results.innerHTML = '';
          return;
        }

        const pf = await loadPagefind();
        if (!pf) {
          results.innerHTML = `<p class="p-4 text-sm text-(--text-secondary)">Search is unavailable in development. It runs against the built site.</p>`;
          return;
        }

        const search = await pf.search(query);
        if (search.results.length === 0) {
          results.innerHTML = `<p class="p-4 text-sm text-(--text-secondary)">No results for "${query}".</p>`;
          return;
        }

        const items = await Promise.all(search.results.slice(0, 8).map((r) => r.data()));
        results.innerHTML = items
          .map(
            (item) => `
            <a href="${item.url}" class="block px-4 py-3 border-b border-(--border-subtle) last:border-0 hover:bg-(--bg-tertiary) transition-colors">
              <p class="font-medium text-(--text-primary) text-sm mb-1">${item.meta?.title ?? item.url}</p>
              <p class="text-xs text-(--text-secondary) line-clamp-2">${item.excerpt}</p>
            </a>
          `,
          )
          .join('');
      }
    }

    // Initialize on page load and after Astro view transitions
    document.addEventListener('astro:page-load', initSearch);
  })();

sm:px-6 lg:px-8 py-12 bg-(--bg-primary)"><div class="prose max-w-none"><h2 id="summary">Summary</h2>
<p><a href="/reports">67%</a> of the malware downloads Netskope blocks come from popular cloud applications being abused by attackers. One of the services commonly abused by threat actors is Discord, which is abused to host malware such as <a href="/blog/2020/11/here-comes-troublegrabber-stealing-credentials-through-discord">TroubleGrabber</a> using <a href="/blog/2020/11/leaky-chats-accidental-exposure-and-malware-in-discord-attachments">public attachment URLs</a>.</p>
<p>In this blog post, we will analyze a recent <a href="https://malpedia.caad.fkie.fraunhofer.de/details/win.dbatloader">DBatLoader</a> (a.k.a. <a href="/library/malware/modiloader" class="threat-link">ModiLoader</a>) sample that uses this technique on Discord to deliver a malware known as <a href="https://malpedia.caad.fkie.fraunhofer.de/details/win.ave_maria">Warzone</a> (a.k.a. Ave Maria), a Remote Access Trojan created in 2018.</p>
<p>This malware is actively being sold on the internet, through a dedicated website:</p>
<p><img src="/_astro/dbatloader-1.HSGlVljL_ZpC5yX.webp" alt="Screenshot of Warzone RAT website" loading="lazy" decoding="async" width="761" height="217"></p>

<ul>

<li>WebCam Live <a href="/library/malware/stream" class="threat-link">Stream</a></li>
<li>Download/Upload Files</li>
<li>Password Grabber (Chrome, Firefox, Internet Explorer, Edge, Outlook, etc.)</li>
<li>Offline/Online <a href="/library/malware/keylogger" class="threat-link">Keylogger</a></li>
</ul>
<p><img src="/_astro/dbatloader-2.jVUC8MA7_1rHY0I.webp" alt="Listing of Warzone features, according to their website." loading="lazy" decoding="async" width="634" height="441"></p>

<h2 id="analysis">Analysis</h2>
<p>It all starts with the first stage of <a href="/library/malware/dbatloader" class="threat-link">DBatLoader</a>, which is known for abusing cloud services, like Google Drive and Discord, to retrieve its second stage, both of which are developed in Delphi.</p>
<p><img src="/_astro/dbatloader-5.Dv4LHFCB_Z1Fe0X7.webp" alt="Screenshot of the first stage of DBatLoader." loading="lazy" decoding="async" width="626" height="254"></p>
<p>First stage of DBatLoader.</p>
<p>The sample is signed with a revoked certificate from “Afia Wave Enterprises”.</p>
<p><img src="/_astro/dbatloader-6.CDHaiYBN_L4MKJ.webp" alt="Screenshot of DBatLoader digital signature." loading="lazy" decoding="async" width="400" height="475"></p>
<p>DBatLoader digital signature.</p>
<p>Once running, the malware allocates and executes a shellcode, which is responsible for downloading the second stage.</p>
<p><img src="/_astro/dbatloader-7.2tUazIRK_2m1JJI.webp" alt="Screenshot showing DBatLoader shellcode." loading="lazy" decoding="async" width="704" height="692"></p>
<p>DBatLoader shellcode.</p>
<p>Later, the second stage is downloaded from Discord, which is eventually decrypted and executed in memory.</p>
<p><img src="/_astro/dbatloader-8-1024x402.CMAfFmFm_B237W.webp" alt="Screenshot showing DBatLoader downloading its second stage from Discord." loading="lazy" decoding="async" width="1024" height="402"></p>
<p>DBatLoader downloading its second stage from Discord.</p>
<p>Looking at the decrypted file strings, we can see references to a few batch scripts that are usually created and executed by this malware to accomplish small tasks, like disabling Windows Defender. However, this sample doesn’t contain the routines to run these files.</p>
<p><img src="/_astro/dbatloader-9.CTb1xqPF_2lhY6E.webp" alt="Screenshot showing strings related to batch scripts." loading="lazy" decoding="async" width="318" height="227"></p>
<p>Strings related to batch scripts.</p>
<p>The loader then copies itself to “%AppData%” as “windows explorer.exe” and creates a very simple persistence technique through Windows Registry.</p>
<p><img src="/_astro/dbatloader-10.CJzAQ6_T_1kpwDg.webp" alt="Screenshot of DBatLoader persistence mechanism." loading="lazy" decoding="async" width="545" height="69"></p>
<p>DBatLoader persistence mechanism.</p>
<p>The final payload is encrypted and stored in DBatLoader’s resources, named “YAK”.</p>
<p><img src="/_astro/dbatloader-11.BZ6BfYq2_1CW3E2.webp" alt="Screenshot of Warzone RAT encrypted payload." loading="lazy" decoding="async" width="777" height="446"></p>
<p>Warzone RAT encrypted payload.</p>
<p>After decrypting these bytes, the payload is executed using a technique known as <a href="https://attack.mitre.org/techniques/T1055/012/">Process Hollowing</a>. Simply put, the code is injected through the following steps:</p>
<ol>
<li>The target process is created in a suspended state with <strong>CreateProcessA</strong>;</li>
<li>The original process’ code section is removed with <strong>NtUnmapViewOfSection</strong>;</li>
<li>New space is allocated in the process with <strong>VirtualAllocEx</strong>;</li>
<li>The malicious code is written using <strong>WriteProcessMemory</strong>;</li>
<li>Finally, the code is resumed with <strong>SetThreatContext</strong> and <strong>ResumeThread</strong>.</li>
</ol>
<p><img src="/_astro/dbatloader-12.CsQUFMQq_Z1hJl4u.webp" alt="Screenshot of Warzone RAT being injected through Process Hollowing." loading="lazy" decoding="async" width="825" height="467"></p>
<p>Warzone RAT being injected through Process Hollowing.</p>
<p>This is a very common process injection technique, used by many malware such as <a href="https://malpedia.caad.fkie.fraunhofer.de/details/win.astaroth">Astaroth</a>, <a href="https://malpedia.caad.fkie.fraunhofer.de/details/win.cobalt_strike">Cobalt Strike</a>, and <a href="https://malpedia.caad.fkie.fraunhofer.de/details/win.trickbot">Trickbot</a>. After injecting Warzone RAT, DBatLoader exits the process without further actions.</p>
<p>The final payload can be dumped from memory using a debugger or the <a href="https://github.com/hasherezade/pe-sieve">pe-sieve</a> tool.</p>
<p><img src="/_astro/dbatloader-13.DVL-MMl5_2f0LI0.webp" alt="Screenshot of Warzone RAT strings." loading="lazy" decoding="async" width="567" height="311"></p>
<p>Warzone RAT strings.</p>
<p>As we mentioned earlier in this blog post, Warzone provides full access to the infected machine and is also able to steal passwords from many browsers and email clients.</p>
<p><img src="/_astro/dbatloader-14.BGnXNR0G_hVK8t.webp" alt="Screenshot of part of the Warzone RAT function that grabs passwords from browsers." loading="lazy" decoding="async" width="510" height="459"></p>
<p>Part of the Warzone RAT function that grabs passwords from browsers.</p>
<p>The malware communicates to its C2 server via TCP using sockets, through the port 1990 in this case.</p>
<p><img src="/_astro/dbatloader-15.CbZtQT-z_Zh3Abo.webp" alt="Screenshot of Warzone RAT C2 communication." loading="lazy" decoding="async" width="464" height="96"></p>
<p>Warzone RAT C2 communication.</p>
<p>This information is encrypted and stored within the PE file in a section named “.bss”. The first 4 bytes of the section are the key length, followed by the key and the encrypted data.</p>
<p><img src="/_astro/dbatloader-16.Bn_B0cp1_Z2mpe56.webp" alt="Screenshot of Warzone RAT encrypted configuration." loading="lazy" decoding="async" width="412" height="472"></p>
<p>Warzone RAT encrypted configuration.</p>
<p>The data is encrypted with RC4 and, once we understood this structure, we created a <a href="https://github.com/netskopeoss/NetskopeThreatLabsIOCs/blob/main/DBatLoader/script/decrypt_warzone_c2.py">python script</a> that is able to parse and decrypt the C2 address from Warzone.</p>
<p><img src="/_astro/dbatloader-17.EFY7Wnnw_2nAHr2.webp" alt="Screenshot of decrypted data from Warzone." loading="lazy" decoding="async" width="215" height="50"></p>
<p>Decrypted data from Warzone.</p>
