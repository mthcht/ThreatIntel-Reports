  (function () {
    let pagefind;
    let debounceTimer;

    async function loadPagefind() {
      if (pagefind) return pagefind;
      try {
        pagefind = await import('/pagefind/pagefind.js');
        await pagefind.init();
      } catch {
        pagefind = null;
      }
      return pagefind;
    }

    function initSearch() {
      const overlay = document.getElementById('search-overlay');
      const openBtn = document.getElementById('search-open');
      const closeBtn = document.getElementById('search-close');
      const input = document.getElementById('search-input');
      const results = document.getElementById('search-results');

      function openModal() {
        overlay?.classList.remove('hidden');
        overlay?.classList.add('flex');
        input?.focus();
        loadPagefind();
      }

      function closeModal() {
        overlay?.classList.add('hidden');
        overlay?.classList.remove('flex');
        if (input) input.value = '';
        if (results) results.innerHTML = '';
      }

      openBtn?.addEventListener('click', openModal);
      closeBtn?.addEventListener('click', closeModal);
      overlay?.addEventListener('click', (e) => {
        if (e.target === overlay) closeModal();
      });
      document.addEventListener('keydown', (e) => {
        if (e.key === 'Escape') closeModal();
        if ((e.metaKey || e.ctrlKey) && e.key === 'k') {
          e.preventDefault();
          openModal();
        }
      });

      input?.addEventListener('input', () => {
        clearTimeout(debounceTimer);
        debounceTimer = setTimeout(runSearch, 200);
      });

      async function runSearch() {
        const query = input?.value.trim() ?? '';
        if (!results) return;
        if (!query) {
          results.innerHTML = '';
          return;
        }

        const pf = await loadPagefind();
        if (!pf) {
          results.innerHTML = `<p class="p-4 text-sm text-(--text-secondary)">Search is unavailable in development. It runs against the built site.</p>`;
          return;
        }

        const search = await pf.search(query);
        if (search.results.length === 0) {
          results.innerHTML = `<p class="p-4 text-sm text-(--text-secondary)">No results for "${query}".</p>`;
          return;
        }

        const items = await Promise.all(search.results.slice(0, 8).map((r) => r.data()));
        results.innerHTML = items
          .map(
            (item) => `
            <a href="${item.url}" class="block px-4 py-3 border-b border-(--border-subtle) last:border-0 hover:bg-(--bg-tertiary) transition-colors">
              <p class="font-medium text-(--text-primary) text-sm mb-1">${item.meta?.title ?? item.url}</p>
              <p class="text-xs text-(--text-secondary) line-clamp-2">${item.excerpt}</p>
            </a>
          `,
          )
          .join('');
      }
    }

    // Initialize on page load and after Astro view transitions
    document.addEventListener('astro:page-load', initSearch);
  })();

<h2 id="summary">Summary</h2>
<p>At the beginning of 2021, <a href="/blog/2020/09/netskope-threat-coverage-emotet">Emotet</a> was considered to be the world’s most dangerous malware <a href="https://www.europol.europa.eu/newsroom/news/world%E2%80%99s-most-dangerous-malware-emotet-disrupted-through-global-action">by Europol</a>. The threat was first discovered in 2014 when it was acting as a banking trojan. Over the years, the malware evolved into one of the most relevant botnets in the threat landscape, often used to <a href="https://blog.malwarebytes.com/malwarebytes-news/2020/10/new-emotet-delivery-method-spotted-during-downward-detection-trend/">deliver other threats</a>, such as <a href="https://malpedia.caad.fkie.fraunhofer.de/details/win.trickbot">Trickbot</a> and <a href="https://malpedia.caad.fkie.fraunhofer.de/details/win.ryuk">Ryuk</a> ransomware. Netskope detected <a href="/blog/2020/10/you-can-run-but-you-cant-hide-detecting-malicious-office-documents">Emotet during Oct 2020</a>, using PowerShell and WMI to download and execute its payload.</p>
<p>After massive collaboration between law enforcement agencies around the world, <a href="https://www.bbc.com/news/technology-55826258">Emotet was taken down</a> in January 2021, where the malware’s infrastructure was disrupted from the inside. This was extremely important, as infected machines were redirected towards law enforcement-controlled infrastructure, preventing further actions from <a href="/library/malware/emotet" class="threat-link">Emotet</a>’s threat actors.</p>
<p>After almost a year, Emotet (a.k.a. Geodo, Heodo) <a href="https://cyber.wtf/2021/11/15/guess-whos-back/">was spotted again</a> in the wild, being delivered by <a href="/library/malware/trickbot" class="threat-link">Trickbot</a>. This new campaign is being tracked by <a href="https://bazaar.abuse.ch/browse/tag/Emotet/">MalwareBazaar</a> / <a href="https://feodotracker.abuse.ch/browse/emotet/">Feodo Tracker</a>, where we can see an increase since November 15, 2021.</p>
<p><img src="/_astro/return-of-emotet-1.DiQzuDtl_ZaSDpD.webp" alt="Emotet tracker from MalwareBazaar." loading="lazy" decoding="async" width="801" height="406"></p>
<p>Screenshot of Emotet tracker from MalwareBazaar.</p>
<p>In this threat coverage, we will analyze a malicious Microsoft Office document from a set of files that are delivering the new Emotet payload.</p>
<h2 id="analysis">Analysis</h2>
<p>Once we open the document, we can see a fake message that lures the victim into enabling the macros, by clicking the “Enable Editing” and “Enable Content” buttons.</p>
<p><img src="/_astro/return-of-emotet-2.DhdTe2xa_17G0wj.webp" alt="Example of a malicious document that delivers Emotet." loading="lazy" decoding="async" width="701" height="586"></p>
<p>Malicious document that delivers Emotet.</p>
<p>The threat actors protected the VBA project with a password to prevent viewing the macro in the VBA editor, likely to slow down analysis.</p>
<p><img src="/_astro/return-of-emotet-3.BCXo6sjA_1ml5at.webp" alt="Example of a protected VBA project." loading="lazy" decoding="async" width="363" height="223"></p>
<p>Protected VBA project.</p>
<p>After bypassing this protection, we can see that the document contains an obfuscated macro code.</p>
<p><img src="/_astro/return-of-emotet-4.DEcBcH8z_7X1fM.webp" alt="Example of macro code executed by the document." loading="lazy" decoding="async" width="993" height="556"></p>
<p>Macro code executed by the document.</p>
<p>There are a few functions that are not used at all, possibly added as decoys. The main code is triggered by the “<a href="https://docs.microsoft.com/en-us/office/vba/api/word.document.open"><code>Document_Open()</code></a>” function.</p>
<p><img src="/_astro/return-of-emotet-5.B-Fn7jU3_guDxU.webp" alt="Screenshot of function triggered once the document is opened." loading="lazy" decoding="async" width="497" height="58"></p>
<p>Function triggered once the document is opened.</p>
<p>By looking at the function called by this entry point, we can see the threat actors attempt to hide a PowerShell script by using string concatenation and replace, which can all be easily removed.</p>
<p><img src="/_astro/return-of-emotet-6-1024x590.B5us4Nhb_1zB4L2.webp" alt loading="lazy" decoding="async" width="1024" height="590"></p>
<p>The VBA code goal is to execute a PowerShell script, that basically iterates over a URL list, and tries to download the content into “<strong><code>C:\ProgramData\</code></strong>”.</p>
<p><img src="/_astro/return-of-emotet-7.Bj5M4grv_Z1zuian.webp" alt="Screenshot of prettyfied PowerShell script executed by the malicious document." loading="lazy" decoding="async" width="525" height="390"></p>
<p>Prettyfied PowerShell script executed by the malicious document.</p>
<p>Once an online URL is found, Emotet’s DLL is written into the disk with a random name, for example: “<strong><code>C:\ProgramData\1856230245.dll</code></strong>”.</p>
<p>At the time of our analysis, three of the URLs were offline.</p>
<p><img src="/_astro/return-of-emotet-8.2TH8fUkS_Z13Ba6f.webp" alt="Screenshot of Online and Offline URLs from Emotet’s document." loading="lazy" decoding="async" width="658" height="178"></p>
<p>Online and Offline URLs from Emotet’s document.</p>
<p>The downloaded file is a 32-bit DLL, and although this information is not 100% reliable, it looks like the file was compiled on November 16, 2021.</p>
<p><img src="/_astro/return-of-emotet-9.BOXNt2qA_Z27SCie.webp" alt="Screenshot of Emotet’s payload downloaded by the malicious document." loading="lazy" decoding="async" width="716" height="422"></p>
<p>Emotet’s payload downloaded by the malicious document.</p>
<p>The final payload is another DLL, which is unpacked and executed in memory by the downloaded file.</p>
<p><img src="/_astro/return-of-emotet-10.BVLXxYMe_lr2Ez.webp" alt="Example of Emotet being unpacked in memory." loading="lazy" decoding="async" width="742" height="465"></p>
<p>Emotet being unpacked in memory.</p>
<p>Once running, Emotet starts the communication with its C2 servers.</p>
<p><img src="/_astro/return-of-emotet-11.DCS64rXU_Z1tmguO.webp" alt="Emotet C2 communication." loading="lazy" decoding="async" width="672" height="527"></p>
<p>Emotet C2 communication.</p>
<p>At the moment of this analysis, there are <a href="https://feodotracker.abuse.ch/browse/emotet/">19 online servers</a> linked to Emotet.</p>
