<h1 class="blog-banner__heading">
      August in November: New Information Stealer Hits the Scene
  </h1>

    </div>
  </div>

  <div class="blog-content">
    <div class="blog-content__sharethis sharethis_toolbox sharethis_32x32_style">
      <div class="blog-content__sharethis_label sharethis__label">Share with your network!</div>
      <div class="blog-content__sharethis_buttons sharethis_buttons">
        <div class="sharethis-inline-share-buttons"></div>
        
      </div>

        <div class="blog-content__metadata blog-content__metadata-author">
      <span class="blog-content__date">  <time datetime="2016-12-07T13:00:00Z">December 07, 2016</time>

</span>
        <span class="blog-content__author">
                Proofpoint Staff
  
        </span>
    </div>
    <div class="node-full__body blog-content__body">  <p><strong>Overview</strong></p>

<p>During the month of November, Proofpoint observed multiple campaigns from TA530 - an actor we have noted&nbsp;for their highly personalized campaigns [6] - targeting customer service and managerial staff at retailers. These campaigns utilized “fileless” loading of a relatively new <a href="https://www.proofpoint.com/us/threat-reference/malware">malware</a> called August through the use of Word macros and PowerShell. August contains stealing functionality targeting credentials and sensitive documents from the infected computer.</p>

<p><strong>Delivery and Targeting</strong></p>

<p>During our analysis we found that many of the lures and subject lines of the emails used references to issues with supposed purchases on the company’s website and were targeted at individuals who may be able to provide support for those issues. The lures also suggested that the attached document contained detailed information about the issue. However, the documents contained macros that could download and install August Stealer.</p>

<p>The subject lines were personalized with the recipient's domain. Examples included:</p>

<ul>
	<li>Erroneous charges from [recipient’s domain]</li>
	<li>[recipient’s domain] - Help: Items vanish from the cart before checkout</li>
	<li>[recipient’s domain] Support: Products disappear from the cart during checkout</li>
	<li>Need help with order on [recipient’s domain]</li>
	<li>Duplicate charges on [recipient’s domain]</li>
</ul>

<p><a href="/sites/default/files/stealer-1.png" target="_blank"><img src="/sites/default/files/stealer-1.png"></a></p>

<p><em>Figure 1: Example email used to deliver the macro-laden document</em></p>

<p><a href="/sites/default/files/stealer-2.png" target="_blank"><img src="/sites/default/files/stealer-2.png"></a></p>

<p><em>Figure 2: Example email used to deliver the macro-laden document</em></p>

<p><a href="/sites/default/files/stealer-3.png" target="_blank"><img src="/sites/default/files/stealer-3.png"></a></p>

<p><em>Figure 3: Example macro-laden document attachment used to deliver August</em></p>

<p>The macro used is very similar to the one we discussed in our previous post detailing sandbox evasion techniques used to deliver the Ursnif banking Trojan [1]. It filters out security researchers and sandboxes using checks including Maxmind, task counts, task names, and recent file counts. Notably, the macro used in this campaign launches a Powershell command to “filelessly” load the payload from a byte array hosted on a remote site. This actor previously used this technique to load POS payloads [2][3][4].</p>

<p><a href="/sites/default/files/stealer-4.png" target="_blank"><img src="/sites/default/files/stealer-4.png"></a></p>

<p><em>Figure 4: Example PowerShell command used to download and execute the byte array</em></p>

<p><a href="/sites/default/files/stealer-5.png" target="_blank"><img src="/sites/default/files/stealer-5.png"></a></p>

<p><em>Figure 5: Snippet of the network traffic returning the byte array used to load August</em></p>

<p>The screenshot above shows the payload downloaded from the remote site as a PowerShell byte array. In addition to the byte array itself, there are few lines of code that deobfuscate the array through an XOR operation, and execute the “Main” function of the payload.</p>

<p><strong>Analysis</strong></p>

<p>August is written in .NET, with samples obfuscated with Confuser [5]. We determined from the source code of a particular sample that August can</p>

<ul>
	<li>Steal and upload files with specified extensions to a command and control (C&amp;C) server</li>
	<li>Steal .rdp files</li>
	<li>Steal wallet.dat files</li>
	<li>Steal crypto currency wallets including Electrum and Bither</li>
	<li>Grab FTP credentials from applications including SmartFTP, FileZilla, TotalCommander, WinSCP, and CoreFTP</li>
	<li>Grab messenger credentials for Pidgin, PSI, LiveMessenger, and others</li>
	<li>Collect cookies and passwords from Firefox, Chrome, Thunderbird, and Outlook</li>
	<li>Determine the presence of common security tools including Wireshark and Fiddler</li>
	<li>Communicate the hardware ID, OS name, and victim's username to the C&amp;C server</li>
	<li>Use simple encryption of network data via base64 encoding, character replacement, adding a random key (passed to server encoded in the User-Agent field), and reversing the strings</li>
</ul>

<p><a href="/sites/default/files/stealer-6.png" target="_blank"><img src="/sites/default/files/stealer-6.png"></a></p>

<p><em>Figure 6: The “Main” function executed from the PowerShell command</em></p>

<p><a href="/sites/default/files/stealer-7.png" target="_blank"><img src="/sites/default/files/stealer-7.png"></a></p>

<p><em>Figure 7: Determines the presence of security tools, and does not communicate with the C&amp;C if they are found</em></p>

<p><a href="/sites/default/files/stealer-8.png" target="_blank"><img src="/sites/default/files/stealer-8.png"></a></p>

<p><em>Figure 8: Network data encryption</em></p>

<p><a href="/sites/default/files/stealer-9.png" target="_blank"><img src="/sites/default/files/stealer-9.png"></a></p>

<p><em>Figure 9: Example encrypted traffic generated by August</em></p>

<p><a href="/sites/default/files/stealer-10.png" target="_blank"><img src="/sites/default/files/stealer-10.png"></a></p>

<p><em>Figure 10: August configured to search and upload .txt and .doc files to the server</em></p>

<p><a href="/sites/default/files/stealer-11.png" target="_blank"><img src="/sites/default/files/stealer-11.png"></a></p>

<p><em>Figure 11: August control panel with stolen credentials for FTP, messenger, mail, RDP, and other programs</em></p>

<p><strong>Conclusion</strong></p>

<p>August is a new information stealer currently being distributed by threat actor TA530&nbsp;through socially engineered emails with attached malicious documents. While this actor is largely targeting retailers and manufacturers with large B2C sales operations, August could be used to steal credentials and files in a wide range of scenarios. The malware itself is obfuscated while the macro used in these distribution campaigns employs a number of evasion techniques and a fileless approach to load the malware via PowerShell. All of these factors increase the difficulty of detection, both at the gateway and the endpoint. As email lures become increasingly sophisticated and personalized, organizations need to rely more heavily on email gateways capable of detecting macros with sandbox evasion built in as well as user education that addresses emails that do not initially look suspicious.</p>

- Стиллинг файлов удалённого подключения (.rdp)</p>

<p>Описание билда:<br>
- Зависимость от .NET Framework (2.0, возможность компиляции для более поздних версий по желанию)<br>
- Самоудаление после работы<br>
- Отправка данных на гейт (PHP 5.4+)<br>
- Шифрование входящего/исходящего трафика<br>
- Вес чистого, необфусцированного билда ~ 45кб<br>
- Не таскает за собой нативные библиотеки<br>
- Не требуются админ. права для выполнения поставленных задач<br>
- Не использовались чужие исходники</p>

<p>Описание панели управления:<br>
- Версия PHP 5.4+<br>
- Не требуется MySQL<br>
- Интуитивно-понятный интерфейс<br>
- Опенсорс, нет обфускации, нет привязок<br>
- Английский язык</p>

Софт в будущем будет обновляться и пополняться новыми фичами, не глобальные обновления для клиентов будут бесплатны</p>
