<h1 class="blog-banner__heading">
      Meet Ovidiy Stealer: Bringing credential theft to the masses
  </h1>

    </div>
  </div>

  <div class="blog-content">
    <div class="blog-content__sharethis sharethis_toolbox sharethis_32x32_style">

      <span class="blog-content__date">  <time datetime="2017-07-13T22:45:00Z">July 13, 2017</time>

</span>
        <span class="blog-content__author">
                Proofpoint Staff
  
        </span>

    <div class="node-full__body blog-content__body">  <p><strong>Overview</strong></p>

<p>Proofpoint threat researchers recently analyzed Ovidiy Stealer, a previously undocumented credential stealer which appears to be marketed primarily in the Russian-speaking regions. It is under constant development, with several updated versions appearing since the original samples were observed in June 2017. The growing number of samples demonstrate that criminals are actively adopting this <a href="https://www.proofpoint.com/us/threat-reference/malware">malware</a>. Ovidiy Stealer is priced at 450-750 Rubles (~$7-13 USD) for one build, a price that includes a precompiled executable that is also "crypted" to thwart analysis and detection.</p>

<p>It should be noted that some antivirus solutions are detecting Ovidiy Stealer with generic and heuristic signatures only. With only heuristic detection, it is possible that an AV solution will detect the behavior of Ovidiy Stealer but label it in logs with a generic description and thus SOC analysts monitoring alerts may well see the event but not recognize its significance. Instead, Ovidiy Stealer could be active an organization's network, throwing alerts but not identified specifically.</p>

<p><strong>Distribution</strong></p>

<p>We believe that Ovidiy Stealer is currently being spread via email as executable attachments, compressed executable attachments, and links to an executable download. It is also likely spread via file hosting / cracking / keygen sites, where it poses as other software or tools. In several cases, we observed the Ovidiy Stealer bundled with a “LiteBitcoin” installer, further validating this claim.</p>

<p><img alt="File litebitcoin-qt.zip, bundled Ovidiy Stealer and another Remote Manipulator System by TektonIT" src="/sites/default/files/proofpointblog1.png"></p>

<p><em>Figure 1: This file, spread as “litebitcoin-qt.zip,” bundles Ovidiy Stealer and another RAT, Remote Manipulator System by TektonIT. While the software is installing both malware samples begin to reach out to the Command and Control (C&amp;C) servers ovidiystealer[.]ru and rmansys[.]ru.</em></p>

<p><em>[Update 7/14/2017: The content of this site has been removed since this article was published. The site itself appears to still be online.]</em></p>

<p><img alt="Screenshot of Chase SoftWare 1.2 Jora.exe, a hacking tool bundled with Ovidiy" src="/sites/default/files/pfptpicture2.png"></p>

<p>&nbsp;</p>

<p><em>Figure 2: This file, spread as “Chase SoftWare 1.2 Jora.exe” appears to be an account checker for various financial institutions (that is, a hacking tool), that was bundled with Ovidiy </em></p>

<p>Other observed filenames are listed below and include game lures, hack tool lures, social network lures and others:</p>

<p>●HideMiner.zip</p>

<p>●VkHackTool.zip</p>

<p>●update_teamspeak3.5.1.exe</p>

<p>●WORLD OF TANKS 2017.txt.exe</p>

<p>●dice_bot.exe</p>

<p>●cheat v5.4.3 2017.exe</p>

<p>●Vk.com BulliTl.exe</p>

<p><strong>Analysis</strong></p>

<p>At the time of writing, we have observed versions 1.0.1 through 1.0.5 distributed in the wild. Ovidiy Stealer is written in .NET and most samples are packed with with either .NET Reactor or Confuser. Upon execution the malware will remain in the directory in which it was installed, and where it will carry out tasks. Somewhat surprisingly, there is no persistence mechanism built into this malware, so on reboot it will cease to run, but the file will remain on the victim machine.</p>

<p>Ovidiy Stealer is modular and contains functionality to target a multiple applications -- primarily browsers -- listed below.</p>

<ul>
	<li>FileZilla</li>
	<li>Google Chrome</li>
	<li>Kometa browser</li>
	<li>Amigo browser</li>
	<li>Torch browser</li>
	<li>Orbitum browser</li>
	<li>Opera browser</li>
</ul>

<p>Because a separate module carries out the targeting of each application, the fewer the modules selected, the smaller the malware payload size. Buyers can select as few as a single module, for example just “Google Chrome”.</p>

<p><img alt="Example code displaying targeted Chromium based browsers" src="/sites/default/files/pfptpicture3.png"></p>

<p><em>Figure 3: Example code displaying the targeted directories for Chromium based browsers</em></p>

<p><img alt="Example displaying the code for locating and stealing stored FileZilla passwords" src="/sites/default/files/picture4.png"></p>

<p><em>Figure 4: Example displaying the code for locating and stealing stored FileZilla passwords</em></p>

<p>Ovidiy Stealer utilizes SSL/TLS for communication with its command and control server. It currently utilizes the domain <em>ovidiystealer[.]ru</em> for its command and control (C&amp;C) communications; which is is also the domain used to market and sell the malware. The initial C&amp;C beacon is a POST reporting the following details:</p>

<ul>
	<li>id: DiskID and ProcessorID</li>
	<li>ver: Ovidiy Stealer version</li>
	<li>cn: Windows username</li>
	<li>os: Operating system and version (e.g. Windows 7)</li>
	<li>user: Registered Ovidiy Stealer username</li>
</ul>

<p><img alt="Network traffic capture of initial checkin beacon generated by the stealer" src="/sites/default/files/pfpt5.png"></p>

<p><em>Figure 5: Network traffic capture of initial checkin beacon generated by the stealer</em></p>

<p>The unique ID provided for each infected machine is a combination of the 8 character DiskID and 16 character ProcessorID, combined into one string. We observed a commonly hardcoded ProcessorID of “BFEBFBFF000206A7” being used if the function checking the ProcessorID resulted in an empty buffer, and at least one sample containing “Rofl” for that value. Ovidiy Stealer traffic also includes a hardcoded User-Agent “E9BC3BD76216AFA560BFB5ACAF5731A3”. This is the md5 hash of the phrase 'litehttp', which is also the default User-Agent of the open-source LiteHTTP Bot.[1]. We believe that Ovidiy author reused the open-source code of the LiteHTTP Bot project.</p>

<p><img alt="Code reuse shown: Ovidiy Stealer on the left, LiteHTTP Bot on the right" src="/sites/default/files/picture6.png"></p>

<p><em>Figure 6: Code reuse shown: Ovidiy Stealer on the left, LiteHTTP Bot on the right</em></p>

<p>If the stealer is able to find passwords from targeted applications, it will follow up its initial checkin with another request reporting the passwords of targeted applications:</p>

<ul>
	<li>id: DiskID and ProcessorID</li>
	<li>site: Website with saved credentials</li>
	<li>program: Targeted application</li>
	<li>login: Saved application username</li>
	<li>pass: Saved application password</li>
	<li>user: Registered Ovidiy Stealer username</li>
</ul>

<p><img alt="Network traffic capture of credentials exfiltration beacon generated by the stealer" src="/sites/default/files/picture7.png"></p>

<p>Figure <em>7: Network traffic capture of credentials exfiltration beacon generated by the stealer</em></p>

<p><strong>Sales and Support</strong></p>

<p>Ovidiy Stealer is offered for sale on <em>ovidiystealer[.]ru</em>, a domain which will help attract potential customers and, as noted above, also the C&amp;C domain. The malware boasts support, features, and login access to the web panel. The admin panel for Ovidiy Stealer allows the botmaster to view statistics on infected machines, view logs, build more stubs, and manage the account.</p>

<p><img alt="Ovidiy Stealer website landing page" src="/sites/default/files/picture8.png"></p>

<p><em>Figure 8: Ovidiy Stealer website landing page. Note the “We accept Free-Kassa” button.</em></p>

<p><img alt="Ovidiy Stealer admin panel" src="/sites/default/files/picture9.png"></p>

<p><em>Figure 9: Ovidiy Stealer admin panel</em></p>

<p>From the admin console, the botmaster has the capabilities to view and filter logs from infected machines.</p>

<p><img alt="Viewing Ovidiy Stealer client logs" src="/sites/default/files/picture10.png"></p>

<p><em>Figure 10: Viewing Ovidiy Stealer client logs</em></p>

<p>To simplify purchasing, the team behind Ovidiy Stealer uses a service known as 'RoboKassa' to collect payment for new stubs. RoboKassa is a Russian equivalent to PayPal, allowing users to conduct payment using credit cards and other types of payment to the sellers; in this case the seller is “Ovidiy” (Fig. 11).</p>

<p><img alt="Payment via RoboKassa offering several options" src="/sites/default/files/picture11.png"></p>

<p><em>Figure 11: Payment via RoboKassa offering several options</em></p>

<p>Like many other markets with many choices, the malware market is competitive and developers must market the strengths and benefits of their products in order to attract buyers. To help drive sales, the development team includes statistics on the progress of certain modules, and other plans for future releases of the malware. In addition, the site includes “testimonials" from satisfied customers, presumably to demonstrate to other would-be criminals that they can be profitable when using Ovidiy Stealer.</p>

<p><img alt="Reviews and development progress on the Ovidiy Stealer website" src="/sites/default/files/picture12.png"></p>

<p><em>Figure 12: Reviews and development progress. The user ACE’s comments translate to English as: “I only need the stealer for burglary on order. I explain what it is: I accept an order for the hijacking of a certain person's account. After I work with him and install the stealer. That's all, for one order I get 300-500 rubles. Without this project it would be impossible! Thank you!”</em></p>

<p>The main author of this project goes by the handle "TheBottle," evident from the informational page of the Ovidiy Stealer website. Moreover, the name 'TheBottle' is observed in at least one sample's PDB string:</p>

<p><em>C:\Users\TheBottle\documents\visual studio 2017\Projects\Ovidiy\Ovidiy\obj\Debug\Ovidiy.pdb</em></p>

<p><img alt="Self proclaimed author of Ovidiy Stealer, ‘TheBottle’" src="/sites/default/files/picture13.png"></p>

<p><em>Figure 13: Self proclaimed author of Ovidiy Stealer, ‘TheBottle’, translated to English</em></p>

<p><strong>Conclusion</strong></p>

<p>Ovidiy Stealer is a new password stealer that entered the criminal ranks barely one month ago. While it is not the most advanced stealer we have seen, marketing and an entry-level price scheme make it attractive and accessible to many would-be criminals. Ovidiy Stealer is lightweight and simple enough to work with relative ease, allowing for simple and efficient credential exfiltration. A lightweight, easy-to-use, and effective product coupled with frequent updates and a stable support system give Ovidiy Stealer the potential to become a much more widespread threat. Stolen credentials continue to be a major risk for individuals and organizations, because password re-use can enable one stolen login to compromise several more accounts, and the sale of stolen accounts continues to be a lucrative market for criminal looking for quick profits. Ovidiy Stealer highlights the manner in the cybercrime marketplace drives innovation and new entrants and challenges organizations that must keep pace with the latest threats to their users, their data, and their systems.</p>
