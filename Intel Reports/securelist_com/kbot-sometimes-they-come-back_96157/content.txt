											<div class="js-reading-content">
												<div class="c-wysiwyg">
													<p>Although by force of habit many still refer to any malware as a virus, this once extremely common class of threats is gradually becoming a thing of the past. However, there are some interesting exceptions to this trend: we recently discovered malware that spread through injecting malicious code into Windows executable files; in other words, a virus. It is the first &#8220;living&#8221; virus in recent years that we have spotted in the wild. </p>
<p>We named it KBOT, and Kaspersky solutions detect the malware and its components as Virus.Win32.Kpot.a, Virus.Win64.Kpot.a, Virus.Win32.Kpot.b, Virus.Win64.Kpot.b, and Trojan-PSW.Win32.Coins.nav.</p>
<h2 id="what-does-kbot-do">What does KBOT do</h2>
<p>KBOT penetrates users&#8217; computers via the Internet or a local network, or from infected external media. After the infected file is launched, the malware gains a foothold in the system, writing itself to Startup and the Task Scheduler, and then deploys web injects to try to steal the victim&#8217;s bank and personal data. For the same purpose, KBOT can download additional stealer modules that harvest and send to the C&#038;C server almost full information about the user: passwords/logins, cryptowallet data, lists of files and installed applications, and so on. The malware stores all its files and collected data in a virtual file system encrypted using the RC6 algorithm, making it hard to detect. </p>

<h2 id="infection-methods">Infection methods</h2>
<p>KBOT infects all EXE files on connected logical drives (HDD partitions, external media, network drives) and in shared network folders by adding polymorphic malicious code to the file body. To do so, the malware listens to the connection events of local and network logical drives using the <strong>IID_IwbemObjectSink</strong> interface and a query of type <strong>SELECT * FROM __InstanceCreationEvent WITHIN 1 WHERE TargetInstance ISA &#8216;Win32_LogicalDisk</strong>, and overrides the <strong>Indicate</strong> function of the <strong>IWbemObjectSink</strong> interface, where for each drive it performs recursive scanning of directories and infects EXE files.</p>
<p>The malware retrieves paths to shared network resources using the API functions <strong>NetServerEnum</strong> and <strong>NetShareEnum</strong>, before scanning directories and infecting executable EXE files:</p>
<p><a href="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115539/kbot_virus_pic_02.png" class="magnificImage"><img loading="lazy" decoding="async" src="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115539/kbot_virus_pic_02.png" alt="" width="700" height="269" class="alignnone size-full wp-image-96194" srcset="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115539/kbot_virus_pic_02.png 700w, https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115539/kbot_virus_pic_02-300x115.png 300w" sizes="(max-width: 700px) 100vw, 700px" /></a></p>

As a result, the original code of the entry point and the start of the code section are not saved. Consequently, the original functionality of the infected file is not retained.</p>

<h2 id="kbot-functions">KBOT functions</h2>
<h3 id="injects">Injects</h3>
<p>To conceal malicious activity in the system and its ability to operate in the context of system applications, KBOT attempts to inject code into running system processes. </p>
<p>Using the API functions <strong>OpenProcess</strong>/<strong>OpenProcessToken</strong> and <strong>GetTokenInformation</strong>, it retrieves the SID of the process into whose address space the main malware module is loaded. If the SID of the process matches <strong>WinLocalSystemSid</strong>, KBOT uses the <strong>CreateProcess</strong> API with the <strong>CREATE_SUSPENDED</strong> flag to create the new process svchost.exe, and then performs a classic inject: using the API functions <strong>NtCreateSection</strong>/<strong>NtMapViewOfSection</strong>, it allocates memory in the address space of the svchost.exe process, where it copies the header and sections of the main module, after which it resolves the imports from the import directory and does manual relocations using information from the relocation table directory. Next, KBOT calls the <strong>CreateRemoteThread</strong>/<strong>RtlCreateUserThread</strong> API with the address of the entry point. If the SID of the process does not match <strong>WinLocalSystemSid</strong>, the malware sets <strong>SeDebugPrivilege</strong> debug privileges and tries to perform a similar inject in the running processes <em>services.exe</em> and <em>svchost.exe</em>, whose SIDs match <strong>WinLocalSystemSid</strong>, as well as in the explorer.exe process. </p>
<p>KBOT also injects the DLLs specified in the <em>injects.ini</em> file (located in the virtual file storage) into the processes listed in the same INI file. Configuration files, including <em>injects.ini</em>, are encrypted in one of the last sections of the main module of the bot, from where they are read, decrypted, and moved to the virtual file storage. The sample first searches for the current version of the required file in its storage (it might be that the current version was previously retrieved from the C&#038;C); in case of failure, it reads the file data from the original version, which is located in the body of the bot itself in encrypted form. A special bot module — JF (joined files) — handles the processing of such files. At the start of the encrypted data of every such file, there is a structure with a data description containing a JF signature. </p>

<h3 id="dll-hijacking">DLL hijacking</h3>
<p>So as to operate in the address space of a legitimate system application when the system boots, the malware performs a <a href="https://encyclopedia.kaspersky.com/glossary/dll-hijacking/?utm_source=securelist&#038;utm_medium=blog&#038;utm_campaign=termin-explanation" rel="noopener noreferrer" target="_blank">DLL hijacking</a> attack by infecting the system libraries specified in the import directory of the system executable file and placing them next to the system file, which is then written to Startup.</p>
<input type="hidden" class="category_for_banner" data-type="posts" value="encyclopedia-glossary" />
<p>In the system folder <strong>C:\Windows\\System32</strong>, the malware searches for executable EXE files suitable for attack, excluding from consideration the following files:</p>
<ol>
<li>Containing the strings <strong>level=&#8221;requireAdministrator&#8221;</strong> and <strong>>true</autoElevate></strong> in the manifest. That is, executable files that need administrator rights to run. Calling such applications invokes a UAC dialog box.</li>
<li>Containing in the import table library names starting with <strong>API-MS-WIN-</strong> and <strong>EXT-MS-WIN-</strong>. That is, files that contain virtual library names in imports and use the API Set redirection table in ApiSetSchema.dll. For such files, DLL hijacking is impossible to implement, because virtual names are translated into system library names with full paths.</li>
<li>The names of which are contained in the stop list:<br />
<a href="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115532/kbot_virus_pic_14.png" class="magnificImage"><img loading="lazy" decoding="async" src="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115532/kbot_virus_pic_14.png" alt="" width="103" height="61" class="alignnone size-full wp-image-96182" /></a></li>
</ol>

<h3 id="startup">Startup</h3>
<p>To run at system startup, the malware uses the following methods: </p>
<ol>
<li>It writes itself to Software\\Microsoft\\Windows\\CurrentVersion\\Run.<br />
To prevent a UAC window from appearing, it sets the value of the <strong>__compat_layer</strong> environment variable to <strong>RunAsInvoker</strong>. Using the <strong>CreateDesktop</strong> API, it creates a new desktop. Within the framework of this desktop, it uses the <strong>CreateProcess</strong> API to launch the regedit.exe process. It injects into this process the shellcode, which uses API functions for working with the registry to write the full path of the system EXE to the specified registry key.</li>
<li>Using WMI tools, a task is created to run the system EXE file in Task Scheduler, next to which are the infected malicious DLLs (see DLL hijacking above). </li>
</ol>
<p>KBOT performs a preliminary check of the current tasks in Task Scheduler, reads the contents of DLLs imported from the tasks by the EXE files, and searches for the infection signature data:</p>
<p><a href="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115529/kbot_virus_pic_20.png" class="magnificImage"><img loading="lazy" decoding="async" src="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115529/kbot_virus_pic_20.png" alt="" width="487" height="244" class="alignnone size-full wp-image-96176" srcset="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115529/kbot_virus_pic_20.png 487w, https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115529/kbot_virus_pic_20-300x150.png 300w" sizes="(max-width: 487px) 100vw, 487px" /></a> </p>
<p>If there are no tasks with infected files, it creates a new task on behalf of the local system account (S-1-5-18) without a user name: </p>
<p><a href="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115529/kbot_virus_pic_21.png" class="magnificImage"><img loading="lazy" decoding="async" src="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115529/kbot_virus_pic_21.png" alt="" width="652" height="197" class="alignnone size-full wp-image-96175" srcset="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115529/kbot_virus_pic_21.png 652w, https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115529/kbot_virus_pic_21-300x91.png 300w" sizes="(max-width: 652px) 100vw, 652px" /></a></p>
<p>Task parameters:<br />
<a href="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115528/kbot_virus_pic_22.png" class="magnificImage"><img loading="lazy" decoding="async" src="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115528/kbot_virus_pic_22.png" alt="" width="464" height="183" class="alignnone size-full wp-image-96174" srcset="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115528/kbot_virus_pic_22.png 464w, https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115528/kbot_virus_pic_22-300x118.png 300w" sizes="(max-width: 464px) 100vw, 464px" /></a> </p>
<p>Example of XML with the created task:</p>
<p><a href="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115528/kbot_virus_pic_23.png" class="magnificImage"><img loading="lazy" decoding="async" src="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115528/kbot_virus_pic_23.png" alt="" width="742" height="849" class="alignnone size-full wp-image-96173" srcset="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115528/kbot_virus_pic_23.png 742w, https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115528/kbot_virus_pic_23-262x300.png 262w" sizes="(max-width: 742px) 100vw, 742px" /></a></p>
<h3 id="remote-management">Remote management</h3>
<p>To remotely manage the victim&#8217;s computer, KBOT establishes reverse connections with the servers listed in the <em>BC.ini</em> file.</p>
<p>To create several simultaneous sessions using the RDP protocol, the malware configures the Remote Desktop Server settings:</p>
<ol>
<li>It finds processes that have the <em>termserv.dll</em> library loaded in their memory.<br />
<a href="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115528/kbot_virus_pic_24.png" class="magnificImage"><img loading="lazy" decoding="async" src="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115528/kbot_virus_pic_24.png" alt="" width="720" height="301" class="alignnone size-full wp-image-96172" srcset="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115528/kbot_virus_pic_24.png 720w, https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115528/kbot_virus_pic_24-300x125.png 300w" sizes="(max-width: 720px) 100vw, 720px" /></a></li>
<li>It patches the memory section of the found process where <em>termserv.dll </em>is loaded. Different patching code is applied for different system versions.<br />
<a href="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115526/kbot_virus_pic_25.png" class="magnificImage"><img loading="lazy" decoding="async" src="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115526/kbot_virus_pic_25.png" alt="" width="742" height="479" class="alignnone size-full wp-image-96171" srcset="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115526/kbot_virus_pic_25.png 742w, https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115526/kbot_virus_pic_25-300x194.png 300w" sizes="(max-width: 742px) 100vw, 742px" /></a></li>
<li>During the patching process, it searches the memory of the module for specific sets of bytes, and replaces them with those specified.<br />
<a href="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115525/kbot_virus_pic_26.png" class="magnificImage"><img loading="lazy" decoding="async" src="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115525/kbot_virus_pic_26.png" alt="" width="668" height="333" class="alignnone size-full wp-image-96170" srcset="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115525/kbot_virus_pic_26.png 668w, https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115525/kbot_virus_pic_26-300x150.png 300w" sizes="(max-width: 668px) 100vw, 668px" /></a></li>
</ol>
<p>Next, KBOT duly edits the values of the registry keys responsible for TermService settings (not all editable values are listed):</p>
<ul>
<li>HKLM\SYSTEM\ControlSet\Control\TerminalServer\LicensingCore\ EnableConcurrentSessions</li>
<li>HKLM\SOFTWARE\Microsoft\WindowsNT\CurrentVersion\Winlogon\EnableConcurrentSessions</li>
<li>HKLM\SOFTWARE\Microsoft\WindowsNT\CurrentVersion\Winlogon\ AllowMultipleTSSessions</li>
<li>HKLM\SOFTWARE\Policies\Microsoft\WindowsNT\TerminalServices\MaxInstanceCount</li>
</ul>
<p>It then restarts TermService and creates a user in the system for remote connections with the SID <strong>WinBuiltinRemoteDesktopUsersSid</strong>.</p>
<h2 id="cc-communication">C&#038;C communication</h2>
<p>The malware, according to a timer and in a separate thread, starts a process for receiving and processing commands from the server. The list of commands is sent in the form of a buffer. To receive commands, the <em>wininet.dll</em> APIs for network connections are used. The domains for receiving commands are located in the <em>hosts.ini</em> file, which the malware periodically updates. All configuration files with C&#038;C data and connection parameters are stored in encrypted form in one of the last sections of the main bot module; newer versions are stored in an encrypted VFAT storage, as previously mentioned. Files received from C&#038;C are placed in an encrypted storage.</p>
<div style="width: 1010px" class="wp-caption aligncenter"><a href="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115525/kbot_virus_pic_27.png" class="magnificImage"><img loading="lazy" decoding="async" src="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115525/kbot_virus_pic_27.png" alt="" width="798" height="254" class="alignnone size-full wp-image-96168" srcset="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115525/kbot_virus_pic_27.png 798w, https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115525/kbot_virus_pic_27-300x95.png 300w, https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115525/kbot_virus_pic_27-768x244.png 768w" sizes="(max-width: 798px) 100vw, 798px" /></a><p class="wp-caption-text"><em>Example of hosts.ini configuration file</em></p></div>
<p>Bot IDs and detailed information about the infected system (computer name, domain, system language and version, list of local users, list of installed security software, etc.) are sent to C&#038;C in advance. Traffic is encrypted using the AES algorithm: </p>
<p><a href="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115526/kbot_virus_pic_28.png" class="magnificImage"><img loading="lazy" decoding="async" src="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115526/kbot_virus_pic_28.png" alt="" width="1921" height="336" class="alignnone size-full wp-image-96169" srcset="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115526/kbot_virus_pic_28.png 1921w, https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115526/kbot_virus_pic_28-300x52.png 300w, https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115526/kbot_virus_pic_28-1024x179.png 1024w, https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115526/kbot_virus_pic_28-768x134.png 768w, https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115526/kbot_virus_pic_28-1536x269.png 1536w" sizes="(max-width: 1921px) 100vw, 1921px" /></a></p>
<p>The malware can receive the following commands from the C&#038;C server:</p>
<ul>
<li><strong>DeleteFile</strong> — delete the specified file from the file storage.</li>
<li><strong>UpdateFile</strong> — update the specified file in the file storage.</li>
<li><strong>UpdateInjects</strong> — update injects.ini.</li>
<li><strong>UpdateHosts</strong> — update hosts.ini.</li>
<li><strong>UpdateCore</strong> — update the main bot module and the configuration file <em>kbot.ini</em>.</li>
<li><strong>Uninstall</strong> — uninstall the malware.</li>
<li><strong>UpdateWormConfig</strong> — update <em>worm.ini</em> containing information about the location of EXE files to be infected.<br />
<div style="width: 1010px" class="wp-caption aligncenter"><a href="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115525/kbot_virus_pic_29.png" class="magnificImage"><img loading="lazy" decoding="async" src="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115525/kbot_virus_pic_29.png" alt="" width="255" height="120" class="alignnone size-full wp-image-96167" /></a><p class="wp-caption-text"><em>Example of worm.ini</em></p></div></li>
<li><strong>UpdateBackconnectConfig</strong> — update the configuration file with the list of servers for reverse connections.<br />
<div style="width: 1010px" class="wp-caption aligncenter"><a href="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115525/kbot_virus_pic_30.png" class="magnificImage"><img loading="lazy" decoding="async" src="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115525/kbot_virus_pic_30.png" alt="" width="420" height="233" class="alignnone size-full wp-image-96166" srcset="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115525/kbot_virus_pic_30.png 420w, https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115525/kbot_virus_pic_30-300x166.png 300w, https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115525/kbot_virus_pic_30-270x150.png 270w" sizes="(max-width: 420px) 100vw, 420px" /></a><p class="wp-caption-text"><em>Example of bc.ini</em></p></div></li>
<li><strong>Load</strong> — load the file into the storage; it loads spyware programs for collecting user data, as well as DLLs for web injects (saved under the names <strong>JUPITER.32</strong> and <strong>JUPITER.64</strong>), their configuration files, etc.<br />
<div style="width: 1010px" class="wp-caption aligncenter"><a href="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115522/kbot_virus_pic_31.png" class="magnificImage"><img loading="lazy" decoding="async" src="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115522/kbot_virus_pic_31.png" alt="" width="424" height="715" class="alignnone size-full wp-image-96164" srcset="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115522/kbot_virus_pic_31.png 424w, https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115522/kbot_virus_pic_31-178x300.png 178w" sizes="(max-width: 424px) 100vw, 424px" /></a><p class="wp-caption-text"><em>Example of part of the configuration file for a web inject</em></p></div></li>
</ul>
<h2 id="obfuscation">Obfuscation</h2>
<p>To complicate the analysis of its malicious activity, KBOT uses a set of obfuscation tools. When it loads, the main bot module checks whether the imported functions are patched for breakpoints; if so, it reloads the imported DLLs into memory, zeroes the names of the imported functions, and uses string obfuscation. The encrypted strings are stored in a special array of structures; to access them, the decryption function is called with the number of the string structure in the array. The strings are encrypted using the RC4 algorithm, and the decryption key is stored in the structure.</p>
<div style="width: 1010px" class="wp-caption aligncenter"><a href="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115522/kbot_virus_pic_32.png" class="magnificImage"><img loading="lazy" decoding="async" src="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115522/kbot_virus_pic_32.png" alt="" width="368" height="289" class="alignnone size-full wp-image-96162" srcset="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115522/kbot_virus_pic_32.png 368w, https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115522/kbot_virus_pic_32-300x236.png 300w" sizes="(max-width: 368px) 100vw, 368px" /></a><p class="wp-caption-text"><em>Example of an array of structures with a description of the strings</em></p></div>
<p>Access to the string:<br />
<a href="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115522/kbot_virus_pic_36.png" class="magnificImage"><img loading="lazy" decoding="async" src="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115522/kbot_virus_pic_36.png" alt="" width="460" height="21" class="alignnone size-full wp-image-96161" srcset="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115522/kbot_virus_pic_36.png 460w, https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115522/kbot_virus_pic_36-300x14.png 300w" sizes="(max-width: 460px) 100vw, 460px" /></a></p>
<p>Decryption function:<br />
<a href="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115522/kbot_virus_pic_33.png" class="magnificImage"><img loading="lazy" decoding="async" src="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115522/kbot_virus_pic_33.png" alt="" width="515" height="580" class="alignnone size-full wp-image-96163" srcset="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115522/kbot_virus_pic_33.png 515w, https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115522/kbot_virus_pic_33-266x300.png 266w" sizes="(max-width: 515px) 100vw, 515px" /></a></p>
<h3 id="obfuscation-of-the-dll-that-performs-the-web-injects">Obfuscation of the DLL that performs the web injects</h3>
<p>The malware suspends threads of the well-known vendor&#8217;s security solution (like the Carberp Trojan), and in the context of its process finds threads whose code was run from DLLs located at the path mask <strong>*\\Trusteer\\Rapport\\*.dll</strong></p>
<p><a href="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115522/kbot_virus_pic_34.png" class="magnificImage"><img loading="lazy" decoding="async" src="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115522/kbot_virus_pic_34.png" alt="" width="692" height="395" class="alignnone size-full wp-image-96165" srcset="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115522/kbot_virus_pic_34.png 692w, https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115522/kbot_virus_pic_34-300x171.png 300w" sizes="(max-width: 692px) 100vw, 692px" /></a></p>
<p>Next, the malware scans the contents of the DLL for signatures of interest to it. If any are present, it suspends execution of the thread, patches the context so that it performs the <strong>Sleep </strong>function, and resumes the thread:</p>
<p><a href="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115522/kbot_virus_pic_35.png" class="magnificImage"><img loading="lazy" decoding="async" src="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115522/kbot_virus_pic_35.png" alt="" width="419" height="243" class="alignnone size-full wp-image-96160" srcset="https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115522/kbot_virus_pic_35.png 419w, https://media.kasperskycontenthub.com/wp-content/uploads/sites/43/2020/02/10115522/kbot_virus_pic_35-300x174.png 300w" sizes="(max-width: 419px) 100vw, 419px" /></a></p>
<p>KBOT then scans the code of the imported functions for patches. If the code is patched (for example, a 0xcc breakpoint has been added), it reloads the imported libraries into memory and resolves imports.</p>
<h2 id="conclusion">Conclusion</h2>
<p>The KBOT virus poses a serious threat, because it is able to spread quickly in the system and on the local network by infecting executable files with no possibility of recovery. It significantly slows down the system through injects into system processes, enables its handlers to control the compromised system through remote desktop sessions, steals personal data, and performs web injects for the purpose of stealing users&#8217; bank data.</p>
