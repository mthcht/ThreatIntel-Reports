	<section class="section--content-article-paragraph">
		<p>Telsy Threat Intelligence team has observed a spear-phishing campaign conducted by cyber-espionage group <em><strong>SideCopy</strong></em> against critical government entities in India. </p>
<p> </p>
<h2>SideCopy APT: from Windows to *nix</h2>
<p>As previously published by “<a href="https://s3.amazonaws.com/talos-intelligence-site/production/document_files/files/000/095/591/original/062521_SideCopy_%281%29.pdf?1625657388">TALOS Cisco Security Research</a>” also in this campaign, in addition to the military themes, <strong><em>SideCopy</em></strong> used publications, invitations to submit documents/proposals and reproduced phishing portals posing as Indian government webmail to trick victims into divulging their e-mail credentials.</p>
<p><em><strong>SideCopy</strong></em>&#8216;s delivery infrastructure consists of using compromised websites to deliver malicious artefacts to specific victims. In this campaign, the portal “<em>hxxp://assessment.mojochamps.com</em>” was compromised, the <em>WebShell</em> named “<em><strong>WSO version 4.2.5</strong></em>” was uploaded, and the infection chain began to spread. </p>
<p>The infection chain for <strong><em>Windows</em> </strong>systems has remained relatively consistent with minor variations, but unlike previous observations an infection chain for <strong><em>*nix</em></strong> systems has been introduced.  <strong><em>SideCopy</em> </strong>continued to send spear-phishing e-mails with malicious file attachments ranging from WEB links to LNKs that installed remote access trojans (RATs) on infected systems.</p>
<p>In addition, <em><strong>SideCopy</strong> </em>used the BackNet agent in some infection chains. <a href="https://github.com/Vinatechvn/backnet">BackNet</a> is a Python Remote Access Tool. It is made of two main programs:</p>
<p>&#8211; A Command and Control server, which is a Web interface to administer the agents</p>
<p>&#8211; An agent program, which is run on the compromised host, and ensures communication with the Command and Control. </p>
<p>The agent can be compiled to native executables using pyinstaller and is therefore compatible with both <em>Windows</em> and <em>*nix</em> operating systems.</p>
<p>The portal “<em>hxxp://assessment.mojochamps.com</em>”, compromised by the threat actor, had malconfigured open directories that allowed access to directories and files saved by the cyber-espionage group.</p>
<p>The analysis of the files on the compromised website made it possible to draw up a timeline of the activities conducted by the <em><strong>SideCopy</strong> </em>group. Between the upload of the first WebShell and the last reported activity, which appears to be the creation of the Indian government&#8217;s webmail phishing page, there were various activities such as uploading PHP and ELF files along with decoy documents.</p>
<p>The following storyline omits the decoy documents upload. </p>
<h2><img fetchpriority="high" decoding="async" class="size-full wp-image-6142" style="font-size: 16px; font-weight: 400;" src="https://www.telsy.com/wp-content/uploads/2022/01/img1-3.png" alt="decoy documents" width="1541" height="636" srcset="https://www.telsy.com/wp-content/uploads/2022/01/img1-3.png 1541w, https://www.telsy.com/wp-content/uploads/2022/01/img1-3-300x124.png 300w, https://www.telsy.com/wp-content/uploads/2022/01/img1-3-1024x423.png 1024w, https://www.telsy.com/wp-content/uploads/2022/01/img1-3-768x317.png 768w, https://www.telsy.com/wp-content/uploads/2022/01/img1-3-1536x634.png 1536w" sizes="(max-width: 1541px) 100vw, 1541px" /></h2>
<p>Depending on the context and modus operandi, all PHP and other files are consistent with each other, which makes it possible that the compromised site was used by the same threat actor to target only India.</p>
<p>Typically, the purpose of the PHP pages was to record the source IP and user agent of the visitor in a text file and then redirect the user to the malicious file or a decoy file depending on the purpose of the page.</p>
<p> </p>
<p><img decoding="async" class="size-large wp-image-6144" src="https://www.telsy.com/wp-content/uploads/2022/01/img2-4-1024x456.png" alt="Map of visitors' IPs" width="799" height="356" srcset="https://www.telsy.com/wp-content/uploads/2022/01/img2-4-1024x456.png 1024w, https://www.telsy.com/wp-content/uploads/2022/01/img2-4-300x134.png 300w, https://www.telsy.com/wp-content/uploads/2022/01/img2-4-768x342.png 768w, https://www.telsy.com/wp-content/uploads/2022/01/img2-4-1536x684.png 1536w, https://www.telsy.com/wp-content/uploads/2022/01/img2-4.png 1767w" sizes="(max-width: 799px) 100vw, 799px" /></p>
<p><em>Map of visitors&#8217; IPs</em></p>
<p> </p>
<p>Analysis of the log files generated by the PHP pages was able to identify around 400 unique IPs, most of which were concentrated in India.
