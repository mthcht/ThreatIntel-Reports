<div class='articlebody clear cf' id='articlebody'><div class="separator" style="clear: both;"><a href="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEhK7CVaeylGP6ELjFK5-PM3mD8cukOtILLhSIr0nulTNsFmgk7FjWwUxk6f0ZtjYPMRo3Fri3n8-xh_s69WD_KPY1fmC7dYiUkBTahfnYIYXWzg9SxNP76u5N-PjBJs4ySowUgmuM3RG6gMk0AsDzJQ-hWLwNfadyknVmbL83DXJE1NDHo8JAAzF4Ue4GzE/s728-rw-e365/recall.png" style="clear: left; display: block; float: left;  text-align: center;"><img data-src="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEhK7CVaeylGP6ELjFK5-PM3mD8cukOtILLhSIr0nulTNsFmgk7FjWwUxk6f0ZtjYPMRo3Fri3n8-xh_s69WD_KPY1fmC7dYiUkBTahfnYIYXWzg9SxNP76u5N-PjBJs4ySowUgmuM3RG6gMk0AsDzJQ-hWLwNfadyknVmbL83DXJE1NDHo8JAAzF4Ue4GzE/s728-rw-e365/recall.png" src="data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAQAAAC1HAwCAAAAC0lEQVR42mP8Xw8AAoMBgDTD2qgAAAAASUVORK5CYII=" alt="Windows Copilot+ Recall" border="0" data-original-height="380" data-original-width="728"  title="Windows Copilot+ Recall" /></a></div>
<p>Microsoft is further delaying the release of its controversial Recall feature for Windows Copilot+ PCs, stating it's taking the time to improve the experience.</p>
<p>The development was <a href="https://www.theverge.com/2024/10/31/24284572/microsoft-recall-delay-december-windows-insider-testing" rel="noopener" target="_blank">first reported</a> by The Verge. The artificial intelligence-powered tool was initially slated for a preview release starting in October.</p>
<p>"We are committed to delivering a secure and trusted experience with Recall," the company <a href="https://blogs.windows.com/windowsexperience/2024/06/07/update-on-the-recall-preview-feature-for-copilot-pcs/" rel="noopener" target="_blank">said</a> in an updated statement released Thursday.</p>
<p>"To ensure we deliver on these important updates, we're taking additional time to refine the experience before previewing it with Windows Insiders. Originally planned for October, Recall will now be available for preview with Windows Insiders on Copilot+ PCs by December"</p>
<p>Microsoft unveiled Recall earlier this May, describing it as a way for users to explore a "visual timeline" of their screens over time and help find things from apps, websites, images, and documents. The search experience was meant to give the computers a "photographic memory" of sorts by logging all computing activities.</p>
<div class='dog_two clear'><center class='cf'><a href='https://thehackernews.uk/cis-nov' rel='nofollow noopener sponsored' target='_blank' title='Cybersecurity'><img class='lazyload' alt="Cybersecurity" src="data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAQAAAC1HAwCAAAAC0lEQVR42mP8Xw8AAoMBgDTD2qgAAAAASUVORK5CYII=" data-src="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEiAxSbAOIwY5p0wWv5znF6Nj42k-fIocSD-CC_fgf7B4WQKPZbJCilURnF5BAgXpuwEEjcBU2BeRdKaag8fw81D37T0OJG7Arl683j5xIhSrEv-88wJKyGgPtRSH1A-5Sz6Oa97Zg8gS0UhfS1E-6PfJwRE2o2yqakqaiVyW8RXxs4Pgxi3c7MA2z3jASGT/s728-e100/cis-d.png" width="727" height="90"/></a></center></div>
<p>But since its initial preview, the feature has been at the receiving end of various privacy and security concerns, prompting the company to disable the feature by default, <a href="https://blogs.windows.com/windowsexperience/2024/09/27/update-on-recall-security-and-privacy-architecture/" rel="noopener" target="_blank">rearchitect the system</a> with improved controls to prevent unauthorized access, and make it opt-in.</p>
<div class="separator" style="clear: both;"><a href="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEhqynEZDjtqexzOOoiDEzC-rBwrjkSd-qqElMjKAuV_xk8Q6jb-eOFN5dbM9kLd0R8QIgDbFqZ3s__b2lKlHrIhuJITdUVrSaWCRLX3JgsjPSrYr_TS5VzFSp_9aX2aCGlhgtWdx5S6Ntg51MbhjAfKJXmYT9VXBotFoofrrmTAcI_Wh15QzVz6f-J7RWe9/s728-rw-e365/1000074578.jpg" style="display: block;  text-align: center; clear: left; float: left;"><img data-src="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEhqynEZDjtqexzOOoiDEzC-rBwrjkSd-qqElMjKAuV_xk8Q6jb-eOFN5dbM9kLd0R8QIgDbFqZ3s__b2lKlHrIhuJITdUVrSaWCRLX3JgsjPSrYr_TS5VzFSp_9aX2aCGlhgtWdx5S6Ntg51MbhjAfKJXmYT9VXBotFoofrrmTAcI_Wh15QzVz6f-J7RWe9/s728-rw-e365/1000074578.jpg" src="data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAQAAAC1HAwCAAAAC0lEQVR42mP8Xw8AAoMBgDTD2qgAAAAASUVORK5CYII=" alt="" border="0" data-original-height="5174" data-original-width="7762" /></a></div>
<p>"The development of Copilot+ PCs, Recall and Windows will continue to be guided by <a href="https://www.microsoft.com/en-us/microsoft-cloud/resources/secure-future-initiative" rel="noopener" target="_blank">SFI</a> [Secure Future Initiative]," it <a href="https://thehackernews.com/2024/06/microsoft-delays-ai-powered-recall.html" rel="noopener" target="_blank">said</a> back in June.</p>
<p>"This is reflected in additional security protections we are providing for Recall content, including "just in time" decryption protected by Windows Hello Enhanced Sign-in Security (ESS), so Recall snapshots will only be decrypted and accessible when the user authenticates."</p>

// Generic function to display a random banner
function displayRandomBanner(bannerArray, containerId) {
    try {
        const container = document.getElementById(containerId);
        if (!container) {
            console.error(`Container with ID '${containerId}' not found`);
            return;
        }

        const randomIndex = Math.floor(Math.random() * bannerArray.length);
        const selectedBanner = bannerArray[randomIndex];
        
        const bannerHTML = `
            <a href="${selectedBanner.href}" target="_blank" rel="noopener">
                <img src="${selectedBanner.imgSrc}" 
                     class="no-lazy" 
                     alt="Cybersecurity" 
                     style="width:100%;">
            </a>`;
        
        container.innerHTML = bannerHTML;
    } catch (error) {
        console.error('Error displaying banner:', error);
    }
}
