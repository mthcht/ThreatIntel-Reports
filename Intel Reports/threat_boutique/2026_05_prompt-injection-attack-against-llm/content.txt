                            <h1 class="title-post" itemprop="name">Prompt Injection: Attack against LLM</h1>
                    <div class="date">
            <span itemprop="datePublished"><a href="https://threat.boutique/archive/2026-05" title="Show all posts made on this month">30 May 2026</a></span>
            - Posted in            <span itemprop="articleSection"><a href="https://threat.boutique/category/threat-analyze">Threat Analyze</a></span> by            <span itemprop="author"><a href="https://threat.boutique/author/b3vSclAuunBMsdt">Jok3r</a></span> -

        </div>
                    <div class="featured-image">
                <a href="https://threat.boutique/2026/05/prompt-injection-attack-against-llm"><img src="https://threat.boutique/content/images/20260530000848-uTYPc.jpg" alt="Prompt Injection: Attack against LLM"/></a>
            </div>
                                        <div class="post-body post-1780085280" itemprop="articleBody">
            <p><strong>Background:</strong>
Prompt injection is one of the most well-known attacks against LLMs. The primary goal of a threat actor in such attacks is to extract secrets and other sensitive data from the environment trusted by the LLM.</p>

<p><strong>Prompt injection types examples:</strong>
<strong>Direct injection:</strong> a case where a user injects harmful prompts through user-controlled input to retrieve information.
<strong>Indirect injection:</strong> a case where hidden metadata or text is fed to an LLM, causing unexpected output.
Of course, other attacks exist too, but many of them rely on these two types.</p>

<p><strong>Prompt Attack Example:</strong>
In this example attacker is trying to use simple native language to send malicious prompt to LLM
<img src="https://threat.boutique/content/images/20260530002707-1.png" alt="enter image description here" /></p>

<p>Now when attacker will use specific technique to retrieve secrets . The model will return the sensitive data .
<img src="https://threat.boutique/content/images/20260530002939-3.png" alt="enter image description here" /></p>

<p><strong>How protection works under the hood:</strong>
Like many protections seen at the network perimeter, input data reaches the LLM only after passing through different filters .
Now let's understand those layers
 1. Instruction - These are specific prompts written in natural language that instruct the model on what it should or should not do. For example, such instructions may tell the model not to return data if doing so could harm human health.
 2. Specific models/layers - These models interpret the potential offensive meaning of a prompt and act as a Data Loss Prevention (DLP) system for the LLM, helping prevent the leakage of sensitive or inappropriate information.</p>

<p>Of course, these layers are not the only elements that can be included within LLM protection parameters, but they are among the simplest and most fundamental.</p>

<p><strong>Prevention mechanisms:</strong>
1. Use DLP on your LLM models
2. Sanitize each request and response data .
3. Keep least privileged principle for the LLM model access</p>

<p><strong>Conclusion:</strong>
Prompt injection attacks are a real threat to LLMs. Simple layers like filtering, DLP models, and strict access control form the foundation of defense. Combining these methods is key to protecting sensitive data from evolving prompt injection techniques.</p>
