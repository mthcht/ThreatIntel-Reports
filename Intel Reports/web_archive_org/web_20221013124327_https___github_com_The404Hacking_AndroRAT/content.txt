            <article class="markdown-body entry-content container-lg" itemprop="text"><h1 dir="auto"><a id="user-content-androrat" class="anchor" aria-hidden="true" href="#androrat"><svg class="octicon octicon-link" viewbox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path fill-rule="evenodd" d="M7.775 3.275a.75.75 0 001.06 1.06l1.25-1.25a2 2 0 112.83 2.83l-2.5 2.5a2 2 0 01-2.83 0 .75.75 0 00-1.06 1.06 3.5 3.5 0 004.95 0l2.5-2.5a3.5 3.5 0 00-4.95-4.95l-1.25 1.25zm-4.69 9.64a2 2 0 010-2.83l2.5-2.5a2 2 0 012.83 0 .75.75 0 001.06-1.06 3.5 3.5 0 00-4.95 0l-2.5 2.5a3.5 3.5 0 004.95 4.95l1.25-1.25a.75.75 0 00-1.06-1.06l-1.25 1.25a2 2 0 01-2.83 0z"></path></svg></a><a href="https://web.archive.org/web/20221013124327/https://github.com/The404Hacking/AndroRAT">AndroRAT</a></h1>
<p dir="auto">Remote Administration Tool for Android</p>
<p dir="auto">Androrat is a client/server application developed in Java Android for the client side and in Java/Swing for the Server.</p>
<blockquote>
<p dir="auto">The name Androrat is a mix of Android and RAT (Remote Access Tool).</p>
</blockquote>
<p dir="auto">It has been developed in a team of 4 for a university project. It has been realised in one month. The goal of the application is to give the control of the android system remotely and retrieve informations from it.</p>
<h1 dir="auto"><a id="user-content-technical-matters" class="anchor" aria-hidden="true" href="#technical-matters"><svg class="octicon octicon-link" viewbox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path fill-rule="evenodd" d="M7.775 3.275a.75.75 0 001.06 1.06l1.25-1.25a2 2 0 112.83 2.83l-2.5 2.5a2 2 0 01-2.83 0 .75.75 0 00-1.06 1.06 3.5 3.5 0 004.95 0l2.5-2.5a3.5 3.5 0 00-4.95-4.95l-1.25 1.25zm-4.69 9.64a2 2 0 010-2.83l2.5-2.5a2 2 0 012.83 0 .75.75 0 001.06-1.06 3.5 3.5 0 00-4.95 0l-2.5 2.5a3.5 3.5 0 004.95 4.95l1.25-1.25a.75.75 0 00-1.06-1.06l-1.25 1.25a2 2 0 01-2.83 0z"></path></svg></a>Technical matters</h1>
<ul dir="auto">
<li>The android application is the client for the server which receive all the connections.</li>
<li>The android application run as a service(not an activity) that is started during the boot. So the user does not need to interact with the service (Even though there is a debug activity that allow to configure the IP and the port to connect to).</li>
<li>The connection to the server can be triggered by a SMS or a call (this can be configured)</li>
</ul>
<h3 dir="auto"><a id="user-content-all-the-available-functionalities-are" class="anchor" aria-hidden="true" href="#all-the-available-functionalities-are"><svg class="octicon octicon-link" viewbox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path fill-rule="evenodd" d="M7.775 3.275a.75.75 0 001.06 1.06l1.25-1.25a2 2 0 112.83 2.83l-2.5 2.5a2 2 0 01-2.83 0 .75.75 0 00-1.06 1.06 3.5 3.5 0 004.95 0l2.5-2.5a3.5 3.5 0 00-4.95-4.95l-1.25 1.25zm-4.69 9.64a2 2 0 010-2.83l2.5-2.5a2 2 0 012.83 0 .75.75 0 001.06-1.06 3.5 3.5 0 00-4.95 0l-2.5 2.5a3.5 3.5 0 004.95 4.95l1.25-1.25a.75.75 0 00-1.06-1.06l-1.25 1.25a2 2 0 01-2.83 0z"></path></svg></a>All the available functionalities are</h3>
<ul dir="auto">
<li>Get contacts (and all theirs informations)</li>
<li>Get call logs</li>
<li>Get all messages</li>
<li>Location by GPS/Network</li>
<li>Monitoring received messages in live</li>
<li>Monitoring phone state in live (call received, call sent, call missed..)</li>
<li>Take a picture from the camera</li>
<li>Stream sound from microphone (or other sources..)</li>
<li>Streaming video (for activity based client only)</li>
<li>Do a toast</li>
<li>Send a text message</li>
<li>Give call</li>
<li>Open an URL in the default browser</li>
<li>Do vibrate the phone</li>
</ul>
<h1 dir="auto"><a id="user-content-folders" class="anchor" aria-hidden="true" href="#folders"><svg class="octicon octicon-link" viewbox="0 0 16 16" version="1.1" width="16" height="16" aria-hidden="true"><path fill-rule="evenodd" d="M7.775 3.275a.75.75 0 001.06 1.06l1.25-1.25a2 2 0 112.83 2.83l-2.5 2.5a2 2 0 01-2.83 0 .75.75 0 00-1.06 1.06 3.5 3.5 0 004.95 0l2.5-2.5a3.5 3.5 0 00-4.95-4.95l-1.25 1.25zm-4.69 9.64a2 2 0 010-2.83l2.5-2.5a2 2 0 012.83 0 .75.75 0 001.06-1.06 3.5 3.5 0 00-4.95 0l-2.5 2.5a3.5 3.5 0 004.95 4.95l1.25-1.25a.75.75 0 00-1.06-1.06l-1.25 1.25a2 2 0 01-2.83 0z"></path></svg></a>Folders</h1>
<p dir="auto">The project contains the following folders:</p>
<ul dir="auto">
<li>doc: Will soonly contain all the documentation about the project</li>
<li>Experiment: Contain an <em>experimental</em> version of the client articulated around an activity wish allow by the way to stream video</li>
<li>src/Androrat: Contain the source code of the client that should be put on the android plateform</li>
<li>src/AndroratServer: Contain the sources of the Java/Swing server that can be run on any plateform</li>
<li>src/api: Contain all the different api used in the project (JMapViewer for the map, forms for swing, and vlcj for video streaming)</li>
<li>src/InOut: Contain the code of the content common for the client and the server which is basically the protocol implementation</li>
</ul>

<p dir="auto">All the actions with client can be made in the client window which is articulated around tabs. The default tab is called Home and provide various functionalities. First as we can see in the left scrollview all the informations about the client like sim infos, battery infos, network infos, sensors infos etc. On the right there is the options which allow remotely to change the configuration of the client like the ip and port to connect to, either or not wait a trigger to intent server connection etc. Finally quick actions can be perfomed in this tab like a toast message, do vibrate the phone or open an URL.</p>
