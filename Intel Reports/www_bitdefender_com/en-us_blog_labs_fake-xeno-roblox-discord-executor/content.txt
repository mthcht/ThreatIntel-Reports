Players frequently exchange mods, scripts, and unofficial tools through forums, Discord servers and file-sharing websites.</p><p>Attackers are all too aware of gamers’ habits. They can exploit this behavior by disguising malware as cheats or utilities that promise exclusive features, improved performance, or the ability to evade anti-cheat systems.</p><p>Bitdefender security researchers have identified a malware campaign targeting players searching for cheats for games such as Roblox. The campaign impersonates Xeno, a popular Roblox script executor used to automate actions and run custom scripts.</p><p>Because such tools are frequently detected or blocked by the game client, versions advertised as “undetected” can be particularly attractive to users seeking to bypass these restrictions.</p><p>The malicious packages are promoted through forums and Discord communities, either directly by the operators or through compromised and impersonated accounts.</p><p>Throughout the infection chain, the malware tries to maintain a veneer of legitimacy. Its components imitate files from a Xeno installation, while later stages use Windows-like DLL names, trusted-looking directories and display-related persistence entries.</p><p>The final malware stage is a sophisticated stealer and remote access trojan that uses anti-analysis and anti-sandboxing techniques, which means that it’s trying hard not to be analyzed by security researchers.</p><p>It can steal browser cookies, personal accounts such as Discord, Roblox and Minecraft, and payment-related information that could lead to financial damage.</p><p>ThreatLocker researchers previously <a href="https://www.threatlocker.com/blog/powercat-malware-campaign-fake-game-cheats-deliver-infostealer-targeting-discord-roblox-and-crypto-wallets">documented</a> this campaign under the name Powercat. Our insights revealed additional command-and-control domains and capabilities, which suggests that the malware remains under active development and continues to be used in cybercriminal operations.</p><p>The campaign has affected users since the beginning of the year. Activity increased significantly during the second half of March and has since maintained a relatively consistent infection rate.</p><figure class="kg-card kg-image-card kg-card-hascaption"><img src="https://blogapp.bitdefender.com/labs/content/images/2026/08/killchain_java.drawio.png" class="kg-image" alt="" loading="lazy" width="561" height="602"><figcaption><span style="white-space: pre-wrap;">Fig. 1. Java stealer killchain</span></figcaption></figure><h2 id="initial-access-fake-xeno-cheats-and-stage-1-execution">Initial Access: Fake Xeno Cheats and Stage 1 Execution</h2><p>For initial access, users are tricked into downloading fake game cheats, such as Xeno, a widely used cheat software for Roblox. The software packages often come either in the form of archives containing extraction and execution instructions or as self-extracting archives that automatically unpack and prepare the environment.</p><p>These archives use a directory structure that resembles a legitimate Xeno installation. File names are chosen to make the package look convincing to users expecting Roblox cheat software. Some files are indeed LUA scripts taken from a Xeno installation, while others, such as RbxAnalytics.png, are only small 10-byte files containing junk data.</p><figure class="kg-card kg-image-card kg-card-hascaption"><img src="https://blogapp.bitdefender.com/labs/content/images/2026/08/-A1A65453-44F4-4F08-8B22-D71DB67EB39E--20260708-094739-1.png" class="kg-image" alt="" loading="lazy" width="333" height="123"><figcaption><span style="white-space: pre-wrap;">Fig. 2. Mimicking a Xeno installation</span></figcaption></figure><p>The user is then told to run the main entry point located at <em>%LOCALAPPDATA%\Xeno\workspace\cache\xeno.exe</em>, believing it will launch the expected game cheat. In reality, this is not the legitimate Xeno binary, but the first stage of the malware masquerading as it.</p><p>First, xeno.exe checks whether a Java executable exists at %LOCALAPPDATA%\Java\jre\bin\javaw.exe. If the file is missing, it extracts a Java Runtime Environment to that path from an archive named instance.exe, using an embedded PowerShell command.</p><pre><code class="language-bash">powershell -NoProfile -WindowStyle Hidden -ExecutionPolicy Bypass -Command \"Add-Type -AssemblyName System.IO.Compression.FileSystem;[System.IO.Compression.ZipFile]::ExtractToDirectory(...)</code></pre>
<p>Next, xeno.exe reads the contents of <em>XenoIcon.jpg</em>, which contains the keys required by the second stage to validate its execution with the C2 server. Finally, it launches javaw.exe to execute a JAR file masquerading as <em>decompiler.exe</em>, passing the contents of XenoIcon.jpg as command-line arguments.</p><h2 id="stage-2-decompilerexe-a-jar-disguised-as-a-windows-executable">Stage 2: decompiler.exe, a JAR Disguised as a Windows Executable</h2><p>The decompiler.exe file is a JAR file masquerading as a Windows executable. Its Java bytecode is obfuscated with the demo version of Allatori, a legitimate commercial obfuscation tool that the malware authors have abused. This can be at least partially deobfuscated, although the flow obfuscation is not fully reversible.</p><p>The class and variable names are also characteristic of Allatori, making the decompiled code harder to read. The main function begins by printing a banner to the console.</p><figure class="kg-card kg-image-card kg-card-hascaption"><img src="https://blogapp.bitdefender.com/labs/content/images/2026/08/-FF1DD0FD-8D2E-4865-9B48-404CE9B56DF9--20260709-063310-1.png" class="kg-image" alt="" loading="lazy" width="385" height="397"><figcaption><span style="white-space: pre-wrap;">Fig. 3. Allatori banner</span></figcaption></figure><p>If the two required arguments are passed to the application, it starts collecting information about the environment in which it is running.</p><p>The malware looks for traces of debugging, artifacts that indicate sandbox execution, and information needed to validate the JAR execution.</p><p>After gathering these details, it sends a POST request to the C2 server containing the collected flag values.</p><p>These values are used to register the victim machine and determine whether it should receive additional payloads.</p><figure class="kg-card kg-image-card kg-card-hascaption"><img src="https://blogapp.bitdefender.com/labs/content/images/2026/08/-570BB6C5-ABCA-4E30-80D6-3BD4B77C4C7E--20260709-065550.png" class="kg-image" alt="" loading="lazy" width="646" height="199" srcset="https://blogapp.bitdefender.com/labs/content/images/size/w600/2026/08/-570BB6C5-ABCA-4E30-80D6-3BD4B77C4C7E--20260709-065550.png 600w, https://blogapp.bitdefender.com/labs/content/images/2026/08/-570BB6C5-ABCA-4E30-80D6-3BD4B77C4C7E--20260709-065550.png 646w"><figcaption><a href=""><span style="white-space: pre-wrap;">Fig. 4. Environment checking</span></a></figcaption></figure><p>For debug detection, the code checks runtime arguments such as <em>-xdebug</em>, <em>suspend=</em>, and <em>jdwp</em>, as well as modules appearing in stack traces, including <em>intellij</em>, <em>eclipse.jdt</em>, <em>netbeans</em>, and <em>bytecodeviewer</em>. Discord account retrieval</span></figcaption></figure><p>Roblox and Minecraft cookies are also processed to retrieve account and login information. Minecraft cookie parsing</span></figcaption></figure><p>Finally, the malware can extract tokens from Microsoft Store logins with the goal of stealing stored payment information. It locates .tbres files in the Token Broker or Cache directories and searches their contents for patterns that indicate the beginning of a token.</p><p>Any valid token found is sent to the C2 server.</p><figure class="kg-card kg-image-card kg-card-hascaption"><img src="https://blogapp.bitdefender.com/labs/content/images/2026/08/image-3.png" class="kg-image" alt="" loading="lazy" width="1186" height="507" srcset="https://blogapp.bitdefender.com/labs/content/images/size/w600/2026/08/image-3.png 600w, https://blogapp.bitdefender.com/labs/content/images/size/w1000/2026/08/image-3.png 1000w, https://blogapp.bitdefender.com/labs/content/images/2026/08/image-3.png 1186w" sizes="(min-width: 720px) 720px"><figcaption><span style="white-space: pre-wrap;">Fig. 31. Microsoft Store token theft</span></figcaption></figure><h1 id="impact-on-victims">Impact on Victims</h1><p>The malware can severely impact victims’ privacy because it gives attackers access to both stored personal information and real-time activity.</p><p>In addition to stealing browser cookies, account credentials, cryptocurrency-wallet data, and payment-related tokens, it can record keystrokes and mouse activity, capture screenshots, stream the desktop, access the webcam, and remotely browse or modify files.</p><p>This combination enables attackers to observe private conversations, collect sensitive images and documents, impersonate victims, take over online accounts, and possibly inflict financial loss.</p><p>Its remote-access and command-execution capabilities also mean that the compromise can continue beyond the initial theft of information, which can lead to data destruction or allow operators to use the infected system in other cyber-criminal activities.</p><h1 id="conclusions">Conclusions</h1><p>Gaming-related lures remain effective because they exploit users’ interest in gaining an advantage, accessing restricted functionality, or avoiding anti-cheat detection.</p><p>In this campaign, attackers used a convincing imitation of the Xeno Roblox script executor and promoted it through channels commonly used by gaming communities. Familiar filenames, copied scripts, legitimate-looking directories, and Windows-related persistence names helped the infection chain appear credible while concealing its malicious purpose.</p><p>The delivered malware is considerably more capable than a typical credential stealer. Its final stage combines browser and account theft with cryptocurrency-wallet targeting, payment-token collection, keylogging, screenshots, webcam access, desktop streaming, file operations, PowerShell command execution, and interactive shell access.</p><p>Persistence and self-update functionality allow the operators to maintain control over infected systems and deploy new versions, while newly observed infrastructure and capabilities indicate that the campaign remains active and continues to evolve.</p><p>Users can reduce their exposure by combining effective security controls with cautious online behavior.</p><p>Updated endpoint protection, reputation-based blocking, application-control policies, multi-factor authentication, and restrictions on software execution can prevent or limit many stages of the attack.</p><p>However, the most effective first line of defense remains avoiding unofficial cheats and executors, particularly those distributed through untrusted websites, archives, forums, or unsolicited Discord messages.</p><p>Recognizing these lures before execution can prevent account theft, financial loss, and complete system compromise. Discussing common gaming-related scams with younger users can also significantly reduce the risk of infection.</p><h1 id="iocs">IoCs</h1>
