          <h1>Rhode Island confirms data breach after Brain Cipher ransomware attack</h1>
          <div class="cz-news-story-title-section">
            <div class="cz-news-title-left-area">
                            By <h6><a rel='author' href='https://www.bleepingcomputer.com/author/bill-toulas/' class='author'><span itemprop="author" itemscope itemtype="https://schema.org/Person"><span itemprop="name">Bill Toulas</span></span></a></h6>
            </div>
	    <meta itemprop="articleSection" content="Security">
            <div class="cz-news-title-right-area">
              <ul>
                <li class="cz-news-date">December 16, 2024</li>
                <li class="cz-news-time">11:51 AM</li>
                
                <li class="cz-news-comment"><a href="#comment_form">0</a></li>
              </ul>
            </div>
          </div>
	  <div class="articleBody">
	   
<div style="text-align:center">
<figure class="image" style="display:inline-block"><img alt="Rhode Island" height="900" src="https://www.bleepstatic.com/content/hl-images/2024/12/16/rhode-statehouse.jpg" width="1600"><figcaption style="text-align: left;"><em>Rhode Island State House (Image:&nbsp;<a href="https://pixabay.com/photos/statehouse-rhode-island-capitol-5733377/" target="_blank" rel="nofollow noopener">MOHANN</a>)</em></figcaption></figure></div>

<p>Rhode Island is warning that its RIBridges system, managed by Deloitte, suffered a data breach exposing&nbsp;residents' personal information after the Brain Cipher ransomware gang hacked its systems.</p>

<p>RIBridges is a modern integrated eligibility system (IES) used in Rhode Island to manage and deliver public assistance programs, helping streamline the administration of various social services.</p>

<p>The incident was discovered on December 5, 2024, and following an evaluation by Deloitte, it is considered very likely that hackers stole files containing personally identifiable information and other data.</p>

<p>"On December 13, 2024, the State was informed by its vendor, Deloitte, that there was a major security threat to the RIBridges system," reads the <a href="https://governor.ri.gov/press-releases/governor-mckee-issues-update-cybersecurity-breach-ribridges-system" target="_blank" rel="nofollow noopener">announcement</a> published by the Rhode Island authorities on Saturday.</p>

<p>"In response, we have proactively taken the system offline so that the State and Deloitte can work to address the threat and restore the system as quickly as possible."</p>

<p>"Additionally, Deloitte confirmed that there is a high probability that a cybercriminal has obtained files with personally identifiable information from RIBridges."</p>

<p>Following Deloitte's discovery of "malicious code" in the system, RIBridges was taken offline, so citizens cannot currently access their accounts from the web portal or the mobile app.</p>

<p>This incident impacts applicants and beneficiaries of the following programs:</p>

<ul style="list-style-type:square"><li>Medicaid</li>
	<li>Supplemental Nutrition Assistance Program (SNAP)</li>
	<li>Temporary Assistance for Needy Families (TANF)</li>
	<li>Child Care Assistance Program (CCAP)</li>
	<li>Health coverage purchased through HealthSource RI</li>
	<li>Rhode Island Works (RIW)</li>
	<li>Long-Term Services and Supports (LTSS)</li>
	<li>General Public Assistance (GPA) Program</li>
	<li>At HOME Cost Share</li>
</ul><p>Although the data that has been exposed remains under evaluation, Deloitte says it may include names, addresses, dates of birth and Social Security numbers, and certain banking information.</p>

<p>Impacted households will receive a letter via mail, and affected residents can call the dedicated call center that started operation yesterday to support them.</p>

<p>General recommendations given by Rhode Island authorities include resetting passwords, placing a fraud alert and credit freeze on their banking accounts, and activating security measures provided by their banks.</p>

<p>Those who need to apply for any of the above programs may still do so via paper, following the <a href="https://dhs.ri.gov/apply-now" target="_blank" rel="nofollow noopener">instructions provided here</a>.</p>

<h2>Deloitte confirms&nbsp;ransomware attack</h2>

<p>This data breach warning comes after the ransomware group '<a href="https://www.bleepingcomputer.com/news/security/meet-brain-cipher-the-new-ransomware-behind-indonesia-data-center-attack/" target="_blank" rel="nofollow noopener">Brain Cipher</a>' claimed earlier this month to have attacked Deloitte and stolen data from the company.</p>

<p>A spokesperson rejected these allegations via a statement to BleepingComputer at the time, saying that the presented data is from a single client's system outside their corporate network.</p>

<p>BleepingComputer has contacted Deloitte again to ask about the details of this latest incident, and a spokesperson confirmed that it's the Brain Cipher ransomware attack.</p>

<p>"The State of Rhode system known as RIBridges is the "single client system" impacted by the Brain Cipher data breach," confirmed a Deloitte spokesperson.</p>

<p>Additionally, the auditing services giant has provided BleepingComputer with the following statement:</p>

<p>"Upon learning that a state system supported by Deloitte had been attacked by an international cybercriminal group, we launched an investigation in collaboration with our client and law enforcement officials," a Deloitte spokesperson told BleepingComputer.</p>

<p>"While that investigation is ongoing, we have shown over the past decade our unwavering commitment to the State of Rhode Island and the people they serve. We will continue to work around the clock to resolve this matter."</p>

function cz_strip_tags(input, allowed) {
  allowed = (((allowed || '') + '')
    .toLowerCase()
    .match(/<[a-z][a-z0-9]*>/g) || [])
    .join(''); // making sure the allowed arg is a string containing only tags in lowercase (<a><b><c>)
  var tags = /<\/?([a-z][a-z0-9]*)\b[^>]*>/gi,
    commentsAndPhpTags = /<!--[\s\S]*?-->|<\?(?:php)?[\s\S]*?\?>/gi;
  return input.replace(commentsAndPhpTags, '')
    .replace(tags, function($0, $1) {
      return allowed.indexOf('<' + $1.toLowerCase() + '>') > -1 ? $0 : '';
    });
}
function cz_br2nl(str) {
	var regex = /<br\s*[\/]?>/gi;
    //var pure_str = str.replace(regex,"\n");
    var pure_str = str.replace(regex,"");
    return cz_strip_tags(pure_str,'');
}
