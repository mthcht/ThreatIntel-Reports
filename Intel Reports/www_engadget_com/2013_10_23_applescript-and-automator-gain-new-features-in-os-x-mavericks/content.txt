If there&#x27;s something that&#x27;s repetitive that needs to be done, it&#x27;s a lot easier just to either use Automator to automate the process or write an AppleScript to dive in a little deeper. With OS X Mavericks, it appears that Apple has added some features that will help &#x22;self-developers&#x22; who want to add their own capabilities to their Macs and commercial apps. On the other hand, there are fewer scriptable items available in many of the new Apple apps...

iCloud Sync

To begin with, there&#x27;s a surprise for anyone who launches either Automator or AppleScript Editor. The first thing you&#x27;ll find is that both apps were updated with iCloud compatibility. AppleScripts that you&#x27;ve created or Automator workflows can now be moved into the cloud and synced to all of your Macs that are running OS X Mavericks. Sure, that&#x27;s a little thing, but it&#x27;s useful if you&#x27;re creating and updating scripts or workflows that need to be deployed to a handful of Macs automatically.



Notifications

Want to annoy yourself? AppleScript and Automator now includes a Display Notification command that you can use to send yourself notifications from your own scripts. That&#x27;s actually quite useful if you want to write a script or run an Automator action that&#x27;s going to ping you when it&#x27;s done through Notification Center. There&#x27;s got to be a way to use this to annoy coworkers...



Libraries

Now this is cool. Let&#x27;s say that you have code that can be used in a number of scripts. Now you can create an AppleScript Library, which is a script that contains a frequently used routine. Store that in ~\Library\Script Libraries\, and now any other script can use that code by simply calling it with a new use clause. Write once, use many times. Blogger Don Southard over at MacStories has a good example of how to use libraries in his writeup of scripting and automation improvements in Mavericks.

Code Signing

This may not sound like a big thing, but it&#x27;s huge. Apple developers can now generate signed copies of applets and droplets as part of the export process in both AppleScript and Automator. Signing these applets means that users launching them will not get the usual Gatekeeper security warning, and adds an incentive for developers to include easy automation tools in their solutions.

Speakable-Workflows

Now here&#x27;s a wonderful addition for those who are creating accessible solutions. If Speakable Items is activated in the Accessibility system preferences, Automator adds a new option to the save dialog to save applets as Speakable Items. With that one click, those items are saved to the Speakable Items architecture and can be executed by speaking the name of the applet.

Now, about those new apps...

On the bad side, some of the new apps appear to be missing a lot of commands in their dictionaries. For example, opening the dictionary of Pages &#x27;09 displayed the following:



Compare that to the new dictionary for the current iteration of Pages:



What&#x27;s missing? Well, a lot. The Pages Application Suite used to let you do things like script the addition of a chart or table to a document; the Graphics Suite made it easy to script changes to things like the alpha threshold of an image; and the Text Suite even allowed scripting of things like inserting a table of content to a Pages document or fine-tuning the look of character styles. Can&#x27;t do that with the new Pages... Hopefully Apple will add these capabilities back in an update to Pages and the other iWork apps. (Thanks to reader Peter P. for noting this omission from Pages.)

This is just what I&#x27;ve been able to find -- or not find -- in a cursory look at Maverick&#x27;s automation tools. As more capabilities and deletions become apparent, this post will be updated. power users love to play with scripting and automation. If there&#39;s something that&#39;s repetitive that needs to be done, it&#39;s a lot easier just to either use Automator to automate the process or write an AppleScript to dive in a little deeper. With <a href="http://tuaw.com/tag/osxmavericks" rel="nofollow noopener" target="_blank" data-ylk="slk:OS X Mavericks;elm:context_link;itc:0;sec:content-canvas" class="link ">OS X Mavericks</a>, it appears that Apple has added some features that will help &quot;self-developers&quot; who want to add their own capabilities to their Macs and commercial apps. On the other hand, there are fewer scriptable items available in many of the new Apple apps...</p><p><strong>iCloud Sync</strong></p><p>To begin with, there&#39;s a surprise for anyone who launches either Automator or AppleScript Editor. The first thing you&#39;ll find is that both apps were updated with iCloud compatibility. AppleScripts that you&#39;ve created or Automator workflows can now be moved into the cloud and synced to all of your Macs that are running OS X Mavericks. Sure, that&#39;s a little thing, but it&#39;s useful if you&#39;re creating and updating scripts or workflows that need to be deployed to a handful of Macs automatically.</p><figure class=caas-figure><div><div><div class="caas-img-container caas-img-loader noheight"><img class="caas-img caas-lazy has-preview" alt data-src=https://s.yimg.com/ny/api/res/1.2/g2PBzFWLvIXykpAD3Dk6tg--/YXBwaWQ9aGlnaGxhbmRlcjt3PTk2MA--/https://o.aolcdn.com/images/dar/5845cadfecd996e0372f/03cdf0ff79d955b3048aa4f53c64b502c60af0dc/aHR0cDovL28uYW9sY2RuLmNvbS9oc3Mvc3RvcmFnZS9hZGFtL2EzNDNjZTI3ZTgxYzA2MGI1NmU4NWEwYWYwMzg5NjdhL2lDbG91ZEZvckFwcGxlU2NyaXB0LnBuZw==><noscript><img alt src=https://s.yimg.com/ny/api/res/1.2/g2PBzFWLvIXykpAD3Dk6tg--/YXBwaWQ9aGlnaGxhbmRlcjt3PTk2MA--/https://o.aolcdn.com/images/dar/5845cadfecd996e0372f/03cdf0ff79d955b3048aa4f53c64b502c60af0dc/aHR0cDovL28uYW9sY2RuLmNvbS9oc3Mvc3RvcmFnZS9hZGFtL2EzNDNjZTI3ZTgxYzA2MGI1NmU4NWEwYWYwMzg5NjdhL2lDbG91ZEZvckFwcGxlU2NyaXB0LnBuZw== class=caas-img></noscript></div></div></div></figure><p><strong>Notifications</strong></p><p>Want to annoy yourself? AppleScript and Automator now includes a <code>Display Notification</code> command that you can use to send yourself notifications from your own scripts. That&#39;s actually quite useful if you want to write a script or run an Automator action that&#39;s going to ping you when it&#39;s done through Notification Center. There&#39;s got to be a way to use this to annoy coworkers...</p><figure class=caas-figure><div><div><div class="caas-img-container caas-img-loader noheight"><img class="caas-img caas-lazy has-preview" alt data-src=https://s.yimg.com/ny/api/res/1.2/55Bfgl4OXARVu.df56uICQ--/YXBwaWQ9aGlnaGxhbmRlcjt3PTk2MA--/https://o.aolcdn.com/images/dar/5845cadfecd996e0372f/036f2b7b4d46bdc8d19394860c4015d746be0355/aHR0cDovL28uYW9sY2RuLmNvbS9oc3Mvc3RvcmFnZS9hZGFtL2Q2OGI5ZDQyZjA1M2FkY2UyOWJkMTk4OGUxZWZmZDczL05vdGlmaWNhdGlvbnMucG5n><noscript><img alt src=https://s.yimg.com/ny/api/res/1.2/55Bfgl4OXARVu.df56uICQ--/YXBwaWQ9aGlnaGxhbmRlcjt3PTk2MA--/https://o.aolcdn.com/images/dar/5845cadfecd996e0372f/036f2b7b4d46bdc8d19394860c4015d746be0355/aHR0cDovL28uYW9sY2RuLmNvbS9oc3Mvc3RvcmFnZS9hZGFtL2Q2OGI5ZDQyZjA1M2FkY2UyOWJkMTk4OGUxZWZmZDczL05vdGlmaWNhdGlvbnMucG5n class=caas-img></noscript></div></div></div></figure><p><strong>Libraries</strong></p><p>Now this is cool. Let&#39;s say that you have code that can be used in a number of scripts. Now you can create an AppleScript Library, which is a script that contains a frequently used routine. Store that in <code>~&#92;Library&#92;Script Libraries&#92;</code>, and now any other script can use that code by simply calling it with a new <code>use</code> clause. Write once, use many times. Blogger Don Southard over at MacStories has a good example of how to use libraries in <a href="http://www.macstories.net/stories/applescript-automator-and-automation-improvements-in-mavericks/" rel="nofollow noopener" target="_blank" data-ylk="slk:his writeup of scripting and automation improvements in Mavericks;elm:context_link;itc:0;sec:content-canvas" class="link ">his writeup of scripting and automation improvements in Mavericks</a>.</p><p><strong>Code Signing</strong></p><p>This may not sound like a big thing, but it&#39;s huge. Apple developers can now generate signed copies of applets and droplets as part of the export process in both AppleScript and Automator. Signing these applets means that users launching them will not get the usual Gatekeeper security warning, and adds an incentive for developers to include easy automation tools in their solutions.</p><p><strong>Speakable-Workflows</strong></p><p>Now here&#39;s a wonderful addition for those who are creating accessible solutions. If Speakable Items is activated in the Accessibility system preferences, Automator adds a new option to the save dialog to save applets as Speakable Items. With that one click, those items are saved to the Speakable Items architecture and can be executed by speaking the name of the applet.</p><p><strong>Now, about those new apps...</strong></p><p>On the bad side, some of the new apps appear to be missing a lot of commands in their dictionaries. Well, a lot. The Pages Application Suite used to let you do things like script the addition of a chart or table to a document; the Graphics Suite made it easy to script changes to things like the alpha threshold of an image; and the Text Suite even allowed scripting of things like inserting a table of content to a Pages document or fine-tuning the look of character styles. Can&#39;t do that with the new Pages... Hopefully Apple will add these capabilities back in an update to Pages and the other iWork apps. (T<em>hanks to reader Peter P. for noting this omission from Pages.</em>)</p><p>This is just what I&#39;ve been able to find -- or not find -- in a cursory look at Maverick&#39;s automation tools.
